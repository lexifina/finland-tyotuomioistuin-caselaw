# TT:1996-16

## Suomeksi

Työntekijöiden oltua lomautettuina työnantaja irtisanoi heidän työsopimuksensa ja samalla kutsui heidät työhön irtisanomisajaksi vähennettynä lomautuksen ennakkoilmoitusajalla. Työnantajalla oli oikeus vähentää saamatta jäänyttä irtisanomisajan palkkaa vastaavasta korvauksesta lomautuksen ennakkoilmoitusajalta maksettu palkka.
 Kantaja Puu- ja erityisalojen liitto ry Vastaajat Puusepänteollisuuden Liitto ry Eskopuu Oy
TUOMIO

 TYÖEHTOSOPIMUKSEN MÄÄRÄYKSET
 Asianosaisliittojen välillä 17.12.1993  31.1.1995 voimassa olleessa puusepänteollisuuden työehtosopimuksessa on muun muassa seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 3 §
 Keskusjärjestöjen väliset sopimukset
 Tämän työehtosopimuksen osana noudatetaan seuraavia keskusjärjestöjen välillä solmittuja sopimuksia niihin myöhemmin tehtyine muutoksineen:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 4. Irtisanomissuojaa ja lomautusta koskeva yleissopimus soveltamisohjeineen (14.6.1991)
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Edellä mainitussa irtisanomissuojaa ja lomautusta koskevassa yleissopimuksessa on muun muassa seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =

 3 §

 Irtisanomisajat
 Työnantajan on irtisanoessaan työsopimuksen noudatettava työsuhteen jatkuttua keskeytyksettä
 1. kahden kuukauden irtisanomisaikaa, jos työsuhde on jatkunut enintään 5 vuotta;
 2. kolmen kuukauden irtisanomisaikaa, jos työsuhde on jatkunut yli 5 vuotta mutta enintään 9 vuotta;
 3. neljän kuukauden irtisanomisaikaa, jos työsuhde on jatkunut yli 9 vuotta mutta enintään 12 vuotta;
 4. viiden kuukauden irtisanomisaikaa, jos työsuhde on jatkunut yli 12 vuotta mutta enintään 15 vuotta; ja
 5. kuuden kuukauden irtisanomisaikaa, jos työsuhde on jatkunut yli 15 vuotta.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 4 §
 Irtisanomisajan noudattamatta jättäminen
 Työnantaja, joka ei noudata irtisanomisaikaa, on velvollinen maksamaan työntekijälle täyden palkan irtisanomisajalta.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Mikäli irtisanomisajan noudattamatta jättäminen puolin tai toisin koskee vain osaa irtisanomisajasta, suoritusvelvollisuus koskee vastaavaa osaa irtisanomisajan palkasta.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 18 §
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Työnantajan korvausvelvollisuus eräissä poikkeuksellisissa tilanteissa
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Milloin lomauttaminen on tullut voimaan työntekijän saamatta hyväkseen työsopimuksen lakkaamista koskevaa irtisanomisaikaa ja työnantaja ennen lomauttamisen päättymistä irtisanoo työsopimuksen, on työntekijällä TSL 42 §:n 2 momentin nojalla oikeus saada korvaus irtisanomisajan palkan tai sen osan menettämisestä näin aiheutuvasta vahingosta.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Työnantajan vastuu edellä mainituissa tapauksissa määräytyy seuraavasti:
 Korvausvelvollisuutta vähentävät lomautusilmoitusajan palkka ja muualla mahdollisesti ansaittu palkka. Muilta osin irtisanomisajan tai sen osan menettämisestä aiheutuneesta vahingosta vastaa työnantaja. Tahallaan ansaitsematta jätetyn palkan vähentäminen tulee kyseeseen vain poikkeuksellisesti, esimerkiksi silloin, kun työnantaja olisi itse järjestänyt työntekijälle irtisanomisajaksi työtä.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 KANNE
 Vaatimukset
 Puu- ja erityisalojen liitto on vaatinut työtuomioistuinta velvoittamaan Eskopuu Oy:n maksamaan jäljempänä mainituille työntekijöille irtisanomisajan palkkaa 16 prosentin viivästyskorkoineen eräpäivästä seuraavasti: Esko Ala-Karjulalle 3 215 markkaa 1.7.1994 lukien, Ilpo Hukarille 3 131 markkaa 22.4.1994 lukien, Olavi Kiviaholle 4 002 markkaa 12.8.1994 lukien, Jorma Märsylälle 3 215 markkaa 1.7.1994 lukien, Ari Simpaselle 4 110 markkaa 12.8.1994 lukien ja Irene Ylihukalle 3 131 markkaa 22.4.1994 lukien.
 Kantajaliitto on vaatinut lisäksi Eskopuu Oy:n tuomitsemista maksamaan hyvityssakkoa työehtosopimuksen tieten rikkomisesta ja Puusepänteollisuuden Liiton tuomitsemista maksamaan hyvityssakkoa valvontavelvollisuuden laiminlyönnistä.
 Puu- ja erityisalojen liitto on lisäksi vaatinut vastaajien velvoittamista yhteisvastuullisesti korvaamaan kantajaliiton oikeudenkäyntikulut korkolain mukaisine viivästyskorkoineen kuukauden kuluttua siitä, kun tuomio on annettu.

 Perustelut
 Eskopuu Oy oli lomauttanut palveluksessaan olleet Esko Ala-Karjulan, Ilpo Hukarin, Olavi Kiviahon, Jorma Märsylän, Ari Simpasen ja Irene Ylihukan vuonna 1991 noudattaen kahden viikon ennakkoilmoitusaikaa.
 Työntekijöiden oltua yhdenjaksoisesti lomautettuina oli yhtiö irtisanonut työntekijät seuraavasti: Ala-Karjulan työsopimuksen 18.4.1994 päättymään 1.7.1994, Hukarin työsopimuksen 7.3.1994 päättymään 22.4.1994, Kiviahon työsopimuksen 25.4.1994 päättymään 12.8.1994, Märsylän työsopimuksen 18.4.1994 päättymään 1.7.1994, Simpasen työsopimuksen 25.4.1994 päättymään 12.8.1994 ja Ylihukan työsopimuksen 7.3.1994 päättymään 22.4.1994.
 Irtisanoessaan työntekijät oli työnantaja keskeyttänyt lomautuksen ja kutsunut työntekijät irtisanomisajaksi työhön. Työntekijöitä irtisanoessaan yhtiö oli tulkinnut työehtosopimuksen mukaisia irtisanomisaikoja siten, että jokaisen työntekijän irtisanomisaika oli jäänyt kaksi viikkoa liian lyhyeksi.
 Kun Eskopuu Oy oli keskeyttänyt lomautukset ja kutsunut työntekijät irtisanomisajaksi työhön, eivät irtisanomissuojasopimuksen 18 §:n "Työnantajan korvausvelvollisuus eräissä poikkeuksellisissa tilanteissa" -väliotsikoidun kohdan sopimusmääräykset tulleet sovellettaviksi.
 Edellä mainitut sopimusmääräykset samoin kuin niiden perustana oleva työsopimuslain 42 §:n 2 momentti koskivat tilannetta, jossa työntekijän työsopimus lomautuksen aikana irtisanottiin lomautuksen jatkuessa työsuhteen päättymiseen saakka. Tällöin työntekijällä oli oikeus saada korvaus siitä vahingosta, joka hänelle aiheutui sen johdosta, ettei työn-antaja lomautuksen sijasta ollut heti irtisanonut häntä, vaan ensin lomauttanut ja lomautuksen aikana irtisanonut työsopimuksen. Ilman eri määräystä ei työnantaja jälkimmäisessä tapauksessa olisi velvollinen maksamaan työntekijälle irtisanomisajalta palkkaa, koska työntekijän lomautus jatkui.
 Milloin työnantaja irtisanoi työntekijän siten, että lomautus keskeytettiin ja työntekijä kutsuttiin työhön irtisanomisajaksi, oli työntekijällä paitsi oikeus täyteen irtisanomisaikaan, myös oikeus saada palkka koko irtisanomisajalta.
 Eskopuu Oy:ssä oli joka kevät työllisyyshuippuja, kun ovia ja ikkunoita valmistavan yrityksen tuotantohuiput osuivat keväälle. Irtisanotuilla työntekijöillä oli teetetty heidän normaalia työtään. Irtisanomissuojasopimuksen 18 §:n kohta, jossa oli määräyksiä työnantajan korvausvelvollisuudesta eräissä poikkeuksellisissa tilanteissa, ei tullut tapauksessa sovellettavaksi, koska lomautusperuste oli lakannut olemasta ainakin irtisanomisajaksi.
 Keskusjärjestöt olivat 19.3.1993 tehdyssä muistiossa ottaneet kantaa tapauksessa, jossa lomautusperuste oli jatkunut irtisanomisajankin ja työnantaja oli järjestänyt työntekijöille jotain järkevää työtä irtisanomisajaksi. Työ oli ollut muuta kuin työntekijöiden normaalia työtä.
 Soveltamiskäytäntö puusepänteollisuuden työehtosopimuksen soveltamisalalla oli ollut sellainen, että jos työnantajalla oli ollut tarjota irtisanomisajaksi työtä, olivat työnantajat noudattaneet täysiä irtisanomisaikoja vähentämättä ennakkoilmoitusaikaa. Eskopuu Oy oli ajoittanut irtisanomiset siten, että työtä olisi ollut tarjota koko irtisanomisajaksi.
 Tässä tapauksessa ei irtisanomisajasta voitu vähentää lomautuksen ennakkoilmoitusaikaa. Kun työntekijät näin ollen eivät olleet saaneet hyväkseen täyttä työehtosopimuksen määräämää irtisanomisaikaa, oli työnantaja velvollinen maksamaan puuttuvan osan irtisanomisajan palkasta. Täysi irtisanomisajan palkka sisälsi myös irtisanomisaikaan kohdistuvan lomakorvauksen ja työajan lyhennyskorvauksen.
 Kun irtisanomisajan palkat olivat erääntyneet ennen korkolain muutosta, niille tuli maksaa korkoa 16 prosenttia. Saamiset olivat erääntyneet työsuhteen päättyessä tai korkeintaan kaksi viikkoa sen jälkeen.
 Työnantajaliitto oli laiminlyönyt valvontavelvollisuutensa, kun se oli hyväksynyt työnantajan menettelyn.

 VASTAUS
 Vaatimukset
 Puusepänteollisuuden Liitto ja Eskopuu Oy ovat vaatineet kanteen hylkäämistä.
 Mainitut vastaajat ovat lisäksi vaatineet kantajaliiton velvoittamista korvaamaan vastaajien oikeudenkäyntikulut laillisine korkoineen kuukauden kuluttua siitä, kun tuomio on annettu.

 Perustelut
 Eskopuu Oy oli lomauttanut vuonna 1991 kanteessa mainitut työntekijät kahden viikon ilmoitusaikaa noudattaen. Työntekijöiden oltua yhtäjaksoisesti lomautettuina oli työnantaja irtisanonut heidät siten kuin kanteessa on todettu. Työntekijät olivat olleet työssä irtisanomisaikansa vähennettynä lomautusilmoitusajalla.
 Vastaajat olivat kantajaliiton kanssa samaa mieltä siitä, ettei irtisanomisajasta voitu vähentää lomautusilmoitusaikaa. Tästä ei tapauksessa kuitenkaan ollut kysymys, vaan työnantajan kuittausoikeudesta irtisanomissuojaa ja lomautusta koskevan yleissopimuksen 18 §:n mukaan. Sopimuskohta koski työnantajan korvausvelvollisuutta eräissä poikkeuksellisissa tilanteissa. Sopimuskohdan mukaan työnantaja saattoi vähentää korvattavakseen tulevasta sopimuskohdan tarkoittamasta palkasta muun muassa lomautusilmoitusajan palkan. Myös keskusjärjestöt olivat 19.3.1993 päivätyssä neuvottelumuistiossa ottaneet kannan, että korvausvelvollisuutta vähentävänä tekijänä voitiin ottaa huomioon lomautusilmoitusajan palkka.
 Kanteessa mainituille työntekijöille oli keväällä 1994 työtilanteen tilapäisen elpymisen johdosta voitu tarjota irtisanomisaikana heidän työsopimuksensa tarkoittamaa työtä. Työntekijät olivat ansainneet irtisanomisajaltaan täysimääräisesti sen palkan, mitä työehtosopimuksen määräykset edellyttivät. Se seikka, että työnantaja oli ilmaissut asian epätarkasti "irtisanomisajan vähennyksenä", ei voinut vaikuttaa asian oikeudelliseen arviointiin. Lomautusilmoitus-ajan palkan vähennysoikeus säilyi riippumatta siitä, olivatko työntekijät irtisanomisaikanaan tekemättä työtä tai osan irtisanomisajastaan työssä.
 Eskopuu Oy oli menetellyt asiassa työehtosopimuksen mukaisesti.
 Kanteessa ilmoitetut vaatimukset olivat määriltään oikeat. Sen sijaan irtisanomisajan palkoille vaadittu 16 prosentin korko ei perustunut voimassaolevaan korkolakiin. Korko oli laskettava haasteen tiedoksiantopäivästä.

 TYÖTUOMIOISTUIMEN RATKAISU
 Perustelut
 Osana puusepänteollisuuden työehtosopimusta noudatetaan keskusjärjestöjen välillä sovittua irtisanomissuojaa ja lomautusta koskevaa yleissopimusta. Tämä sopimus sisältää muun muassa edelle jäljennetyt määräykset lomautettuna irtisanotun työntekijän oikeudesta saada eräin rajoituksin korvaus lomautuksen vuoksi saamatta jääneestä irtisanomisajan palkasta.
 Eskopuu Oy on lomauttanut kanteessa mainitut kuusi työntekijää vuonna 1991 noudattaen kahden viikon ennakkoilmoitusaikaa. Työntekijöiden oltua yhdenjaksoisesti lomautettuina on työnantaja irtisanonut heidät keväällä 1994 ja samalla kutsunut heidät osaksi irtisanomisaikaa työhön. Työntekijät ovat tehneet irtisanomisaikanaan tavanomaisia työtehtäviään. Erimielisyydessä on kysymys siitä, onko Eskopuu Oy:llä ollut tässä tilanteessa oikeus vähentää ennakkoilmoitusajalta maksettu palkka saamatta jäänyttä irtisanomisajan palkkaa vastaavasta korvauksesta, mikä menettely on tosiasiallisesti lyhentänyt palkallista irtisanomisaikaa lomautuksen ennakkoilmoitusajalla.
 Eskopuu Oy on ollut velvollinen soveltamaan myös lomautettuina irtisanottujen työntekijöiden osalta työehtosopimuksen mukaisia irtisanomisaikoja. Näin ollen työntekijöillä, joiden irtisanomisajoista on vähennetty kahden viikon lomautuksen ennakkoilmoitusaika, on oikeus saada korvaus tältä ajalta saamatta jääneestä irtisanomisajan palkasta.
 Irtisanomissuojasopimuksen 18 §:ssä on sovittu työnantajan oikeudesta tehdä eräitä vähennyksiä suoritettavasta korvauksesta. Tällaisia vähennyksiä on muun muassa lomautusilmoitusajalta maksettu palkka. Puu- ja erityisalojen liiton näkemyksen mukaan tätä vähennysoikeutta työnantajalla ei kuitenkaan ole ollut tässä tapauksessa, koska määräys koskee ainoastaan sellaisia tilanteita, joissa lomautus on jatkunut työsuhteen päättymiseen saakka, tai työnantaja on osoittanut työntekijöille irtisanomisaikana muuta kuin näiden tavan-omaista työtä.
 Irtisanomissuojasopimuksen 18 §:n mukaan työnantaja voi vähentää korvauksesta myös työntekijän tahallaan ansaitsematta jättämän palkan, jos työnantaja olisi itse järjestänyt irtisanomisajaksi työtä. Määräyksestä on pääteltävissä, että työnantaja voi kutsua myös lomautettuna olleen työntekijän työhön irtisanomisajaksi. Vuonna 1993 erään metalliteollisuuden sopimusalalla syntyneen erimielisyysasian yhteydessä Suomen Ammattiliittojen Keskusjärjestö SAK ry:n ja Teollisuuden ja Työnantajain Keskusliitto ry:n edustajat ovat tulkitessaan kyseistä sopimuskohtaa olleet yksimielisiä siitä, että määräys ei estä työnantajaa järjestämästä työtä vain osaksi irtisanomisaikaa. Metalliteollisuuden työehtosopimuksen sopijapuolet ovat sittemmin päätyneet erimielisyyskysymyksessä keskusliittojen yhteisen tulkinnan mukaiseen ratkaisuun.
 Työtuomioistuimessa todistajana kuullun kantajaliiton työehtosihteerin kertoman mukaan vastaavia erimielisyystapauksia ei aiemmin ole ollut käsiteltävänä alan liittojen välillä. Puu- ja erityisalojen liitossa riidanalaista määräystä on tulkittu niin, että lomautuksen ennakkoilmoitusajalta maksetun palkan vähentäminen tulee kyseeseen vain työntekijälle maksetusta korvauksesta, mutta vastaavaa vähennystä ei voida tehdä irtisanomisajasta tai irtisanomisajan palkasta. Jos työnantaja määrää työntekijän työhön irtisanomisaikana, se on todistajan mukaan velvollinen maksamaan palkan aina koko irtisanomisajalta siitä riippumatta, miten kauan työntekijä on työssä.
 Puusepänteollisuuden sopimusalalla ei kuitenkaan ole selvitetty sovitun keskusjärjestöjen käsityksestä poikkeavasta tulkinnasta eikä alalla myöskään ole syntynyt kantajaliiton tulkintaa tukevaa soveltamiskäytäntöä.
 Edellä lausutusta on yhteenvetona todettavissa, että irtisanomissuojaa ja lomautusta koskevan yleissopimuksen 18 §:n mukaan työnantaja voi kutsua lomautettuna irtisanotun työntekijän työhön irtisanomisajaksi, tai myös vain osaksi irtisanomisaikaa, jolloin kyseisen 18 §:n mukainen korvausvelvollisuus vastaavasti vähenee. Määräyksen sanamuodosta tai muustakaan työtuomioistuimelle esitetystä selvityksestä ei ole johdettavissa rajoituksia sen suhteen, minkälaista työtä työnantaja korvausvastuun vähentämiseksi voi tarjota. Sikäli kun lomautettuna irtisanottu työntekijä ei työskentele koko irtisanomisaikaa, työnantajan on maksettava korvaus saamatta jääneen irtisanomisajan palkan osan menetyksestä. Tästä korvauksesta työnantajalla on irtisanomissuojasopimuksen 18 §:n nojalla oikeus tehdä määräyksessä sovitut vähennykset, muun muassa lomautuksen ennakkoilmoitusajalta maksettu palkka.
 Eskopuu Oy ei siten ole rikkonut työehtosopimuksen määräyksiä kieltäytyessään maksamasta vaadittuja palkkoja tai niitä vastaavia korvauksia. Puusepänteollisuuden liitto ei liioin ole laiminlyönyt työehtosopimuslain mukaista valvontavelvollisuuttaan.
 Jutun hävitessään Puu- ja erityisalojen liitto on velvollinen korvaamaan vastaajien oikeudenkäyntikulut. Liitto on myöntänyt vastaajien yhteisten oikeudenkäyntikulujen kohtuulliseksi määräksi vaaditut 18 361 markkaa.

 Tuomiolauselma
 Kanne hylätään.
 Puu- ja erityisalojen liitto velvoitetaan korvaamaan Puusepänteollisuuden Liiton ja Eskopuu Oy:n yhteiset oikeudenkäyntikulut 18 361 markalla, jolle on maksettava viivästyskorkoa korkolain 4 §:n 3 momentissa tarkoitetun korkokannan mukaan siitä lähtien, kun kuukausi on kulunut työtuomioistuimen tuomion antopäivästä.
 Asian ratkaisemiseen ovat osallistuneet Orasmaa puheenjohtajana sekä Kallio, Niskanen, Tuulensuu, Kolula ja Orpana jäseninä. Esittelijä on ollut Niemitalo.
 Tuomio on yksimielinen.

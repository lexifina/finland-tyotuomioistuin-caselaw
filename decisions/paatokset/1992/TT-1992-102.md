# TT:1992-102

## Suomeksi

Kysymys siitä, oliko virkamatkaan sisältynyt sunnuntai, jolloin virkamies ei ollut tehnyt työtä, katsottava työaikalaskennassa virkaehtosopimuksessa tarkoitetuksi keskeytyspäiväksi vai laskentapäiväksi.(Ään.)
 Kantaja STTK:n Julkisten alojen ammattijärjestö STTK-J r.y Vastaaja Valtiovarainministeriö
TUOMIO

 VIRKAEHTOSOPIMUKSEN MÄÄRÄYKSET
 Puolustusvoimien virkamiesten työajasta 27.12.1989 tehdyssä virkaehtosopimuksessa on muun ohella seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =

 I TYÖAIKA
 = = = = = = = = = = = = = = = = = = = = = = = = =
 7 §. Työajaksi laskettava aika
 Työajaksi lasketaan, mikäli työajan laskemisesta ei ole erikseen toisin säädetty, määrätty, tai sovittu, a) viikko- tai päiväpalvelusohjelman taikka muun vastaavan määräyksen mukainen työaika vähennettynä lepoajalla (ruokailutauko) edellyttäen, että virkamiehellä on tauon aikana oikeus ja tosiasiallinen mahdollisuus poistua palvelustehtävästään, sekä b) kaikki se aika, minkä virkamies on esimiehen käskystä ollut työssä, vaikka se poikkeaisikin a) -kohdan määräyksistä.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 III KORVAUKSET JA LISÄT
 = = = = = = = = = = = = = = = = = = = = = = = = =
 16 §. Ylityökorvaus ja lisätyökorvaus keskeytyneessä työjaksossa
 1. Mikäli virkamies ei ole ollut työssä koko työjaksoa sen johdosta, että virkasuhde on katkennut tai ettei hän ole voinut olla työssä loman, sairauden tai muun hyväksyttävän syyn vuoksi taikka virkamies on tullut työhön kesken työjakson, lasketaan ylityökorvaus ja 15 §:n 1-4 momentissa tarkoitettu lisätyökorvaus keskeytyksen ulkopuolella olevien päivien eli laskentapäivien perusteella soveltaen suhteellisten työtuntinormien taulukkoja (Liite).
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Puolustusministeriön antamissa puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen soveltamisohjeissa on muun ohella seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 7 § Työajaksi laskettava aika
 = = = = = = = = = = = = = = = = = = = = = = = = =
 11. Virka- tai komennusmatkalla matkustamiseen käytettyä aikaa ei lasketa työajaksi, ellei tässä pykälässä ole toisin määrätty.
 Virka- tai komennusmatkalla matkustamiseen käytetty aika lasketaan työajaksi siltä osin kuin virkamies on matkustamisen aikana suorittanut virkatehtäviä kuten vartiointia tai laitteiden tarkkailua.
 Jos virkamies on virka- tai komennusmatkaan käytettynä vuorokautena ollut työssä, mutta vähemmän kuin 8 tuntia, otetaan matkustamiseen kulunut aika huomioon työajan lisäyksenä siihen saakka, että se yhdessä työssäoloajan kanssa on 8 tuntia vuorokaudessa. Matkustamiseen käytettyä aikaa ei oteta huomioon työajan lisäyksenä sellaisen komennusmatkan vuorokaudelta, joka suoritetaan siirryttäessä virantoimituspaikalta toiselle.
 Työajan lisäykseksi laskettavalta matkustusajalta ei makseta iltatyölisää, yötyölisää, lauantaityökorvausta, aattopäivänlisää eikä sunnuntaityökorvausta.
 Virka- tai komennusmatkaan käytetty vuorokausi on työaikasopimuksen 16 §:ssä tarkoitettu keskeytyspäivä, ellei siltä tämän momentin perusteella lasketa työaikaa.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 III KORVAUKSET JA LISÄT
 = = = = = = = = = = = = = = = = = = = = = = = = =
 16 § Ylityökorvaus ja lisätyökorvaus keskeytyneessä työjaksossa
 = = = = = = = = = = = = = = = = = = = = = = = = =
 2. Laskentapäiviä ovat työpäivien, myös osapäivien, lisäksi virka- tai komennusmatkaan kulunut vuorokausi, mikäli virkamies on samalla joutunut hoitamaan virkatehtäviään, viikkolepopäivät, työjaksoon sijoitetut vapaapäivät sekä työtapaturman sattumispäivä ja sairastumispäivä samoin kuin luvatta palveluksesta poissaolopäivät.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 3. Keskeytyspäiviä ei oteta mukaan työaikalaskentaan. Tällaisia keskeytyspäiviä ovat muun muassa vuosiloma- ja virkavapauspäivät, vuosilomaan sisältyvät sunnuntait, uudenvuodenpäivä, pitkäperjantai, toinen pääsiäispäivä, joulupäivä, tapaninpäivä, juhannusaatto, vapunpäivä, itsenäisyyspäivä ja jouluaatto sekä muu kuin edellä 2 momentissa tarkoitettu virka- tai komennusmatkaan kulunut vuorokausi.

 KANNE
 Kanteen perustelut
 STTK:n Julkisten alojen ammattijärjestö STTK-J on valtiovarainministeriötä vastaan ajamassaan kanteessa lausunut, että sotilasmestari Pauanne toimi Pudasjärven linkkialueen päällikkönä Pohjois-Suomen sotilasläänin esikunnan viestiosaston alaisuudessa. Hänen sijoituspaikkansa oli Pudasjärven viestiasema Pudasjärvellä. Pauanne oli ollut laiteasennuskomennuksen vuoksi virkamatkalla Rovaniemellä 11.6. - 20.6.1990. Mainittuna aikana laiteasennustyöryhmään oli kuulunut kolme henkilöä viestikeskuskorjaamolta Riihimäeltä ja viisi henkilöä Pohjois-Suomen sotilasläänin esikunnan viestiosastosta. Pohjois-Suomen sotilasläänin esikunnan asennushenkilöstö oli koostunut Pudasjärven ja Rovaniemen linkkialueiden henkilöstöstä.
 Asian johdosta oli käyty paikallisneuvottelu pääesikunnan ja Päällystöliitto r.y:n välillä 29.8.1991. Tuolloin Päällystöliiton edustaja oli uudistanut paikallisen luottamusmiehen 25.4.1991 pidetyssä välittömässä neuvonpidossa esittämän kannan, jonka mukaan virka- tai komennusmatkaan kulunut vuorokausi oli keskeytyspäivä, mikäli virkamies ei ollut samalla joutunut hoitamaan virkatehtäviä. Tämän mukaisesti kysymyksessä ollut sunnuntai 17.6.1990 oli merkittävä keskeytyspäiväksi.
 Asiassa 11.12.1991 käydyissä keskusneuvotteluissa STTK:n Julkisten alojen ammattijärjestö STTK-J oli vaatinut, että Pauanteen virkamatkaan sisältynyt sunnuntaipäivä oli katsottava puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen 16 §:n mukaiseksi keskeytyspäiväksi. Perustelujen osalta ammattijärjestö oli viitannut virkaehtosopimuksen soveltamisohjeiden sanamuotoon. Valtiovarainministeriön taholta neuvottelussa oli todettu, että ministeriön kannan mukaan viikkolepopäivät olivat puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen ja sen soveltamisohjeiden mukaan laskentapäiviä myös virkamatkalla.
 Pauanne oli kiistatta ollut virkamatkalla myös sunnuntaina 17.6.1990, eikä hänelle tältä päivältä ollut laskettu työaikaa. Kysymyksessä oli siten virkaehtosopimuksen 16 §:ssä tarkoitettu keskeytyspäivä kuten soveltamisohjeiden 7 §:n 11 momentin viimeisessä kappaleessa oli todettu. Pauanteen kohdalla sunnuntai 17.6.1990 oli ollut virkaehtosopimuksen soveltamisohjeiden 16 §:n 3 momentin mukainen muu kuin edellä 2 momentissa tarkoitettu virka- tai komennusmatkaan kulunut vuorokausi, koska Pauanne ei tuolloin ollut joutunut hoitamaan virkatehtäviä, joten päivää ei katsottu laskentapäiväksi.
 Kanteessa esitetyt vaatimukset
 STTK:n Julkisten alojen ammattijärjestö STTK-J on vaatinut työtuomioistuinta vahvistamaan, että sotilasmestari Pauanteen 11.6. - 20.6.1990 suorittamaan virkamatkaan kuulunut sunnuntai 17.6.1990 on puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen 16 §:n mukainen keskeytyspäivä eikä laskentapäivä.

 VASTINE
 Vastineen perustelut
 Valtiovarainministeriö on kanteeseen vastatessaan lausunut, että puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen 16 §:n soveltamista oli tarkennuttu virkaehtosopimuksen soveltamisohjeiden 16 §:n 2 ja 3 momentissa. Soveltamisohjeiden 16 §:n 2 momentissa oli todettu muun muassa, että laskentapäiviä olivat työpäivien, myös osapäivien lisäksi virka- tai komennusmatkaan kulunut vuorokausi, mikäli virkamies oli samalla joutunut hoitamaan virkatehtäviään, viikkolepopäivät, työjaksoon sijoitetut vapaapäivät sekä työtapaturman sattumispäivä ja sairastumispäivä samoin kuin luvatta palveluksesta poissaolopäivät. Soveltamisohjeiden 16 §:n 3 momentissa oli tarkemmat ohjeet siitä, miten niin sanotut keskeytyspäivät otettiin huomioon työaikalaskennassa. Tässä momentissa oli ohjeellinen luettelo niistä keskeytyspäivistä, joita ei otettu mukaan työaikalaskentaan. Luettelossa oli viimeisenä kohtana mainittu myös muu kuin edellä 2 momentissa tarkoitettu virka- tai komennusmatkaan kulunut vuorokausi.
 Pauanne oli ollut virkamatkalla Rovaniemellä 11.6. 20.6.1990. Sunnuntaiksi 17.6.1990 hän oli saanut luvan jäädä komennuspaikkakunnalle Rovaniemelle. Työaikataulukkoon päivä oli merkitty laskentapäiväksi, mutta Pauanne itse oli katsonut sunnuntaipäivän keskeytyspäiväksi.
 Virkaehtosopimuksen soveltamisohjeiden 16 §:n 2 momentissa mainitulla virka- tai komennusmatkaan kuluneella vuorokaudella tarkoitettiin sellaista varsinaiseen työntekoon käytettyä matka-aikaa, jolloin virkamies oli samalla joutunut koko ajan hoitamaan virkatehtäviään. Tällainen matkavuorokausi luettiin laskenta-ajaksi. Soveltamisohjeiden 16 §:n 3 momentin mukainen muu matkustamiseen käytetty aika oli keskeytysaikaa. Tätä käsitystä tuki myös soveltamisohjeiden 7 §:n 11 momentin toisen kappaleen sisältö, jossa todettiin, että virka- tai komennusmatkalla matkustamiseen käytetty aika laskettiin työajaksi vain siltä osin kuin matkustamisen aikana oli suoritettu virkatehtäviä kuten vartiointia tai laitteiden tarkkailua.
 Virkaehtosopimuksen soveltamisohjeiden 16 §:n 2 momentissa oli nimenomaisesti mainittu, että työpäivien lisäksi laskentapäiviä olivat muun muassa viikkolepopäivät. Pauanteen kysymyksessä olevaan virkamatkaan sisältyvistä päivistä 11.6. - 16.6.1990 (maanantai-lauantai) olivat olleet normaaleja työpäiviä ja sunnuntai 17.6.1990 tavanomainen viikkolepopäivä. Tämän jälkeiset päivät olivat olleet normaaleja työpäiviä, jotka kaikki olivat soveltamisohjeiden 16 §:n 2 momentin tarkoittamia laskentapäiviä. Sunnuntai 17.6.1990 oli normaali puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen ja sen soveltamisohjeiden mukainen laskentapäivä. Viikkolepopäivän luonne laskentapäivänä ei muuttunut, vaikka se sisältyikin virka- tai koulutusmatkaan. Käytäntö tältä osin oli vakiintunut puolustusvoimissa.
 Vastineessa esitetyt vaatimukset
 Valtiovarainministeriö on vaatinut kanteen hylkäämistä.

 OIKEUDENKÄYNTIKULUVAATIMUKSET
 Asianosaiset ovat vaatineet oikeudenkäyntikulujensa korvaamista 16 prosentin korkoineen tuomion antopäivästä lukien.

 TYÖTUOMIOISTUIMEN RATKAISU
 Perustelut
 Pohjois-Suomen sotilasläänin esikunnan viestiosaston alaisuudessa Pudasjärven linkkialueen päällikkönä toimiva sotilasmestari Pauanne, jonka sijoituspaikka on Pudasjärvellä sijaitseva viestiasema, on ollut laiteasennuskomennuksen vuoksi virkamatkalla Rovaniemellä 11.6. 20.6.1990. Kantajan ilmoituksen mukaan virkamatkaa koskeva virkamatkaesitys on tehty yhdenjaksoisena ja sellaisena se on hyväksytty viestiosastossa.
 Kysymyksessä olevaan laiteasennustyöryhmään kuuluvat henkilöt ovat tehdyn sopimuksen mukaisesti työskennelleet lauantaina 16.6.1990 kahdeksan tuntia. Sunnuntaina 17.6.1990 ne työryhmään kuuluneet henkilöt, jotka eivät asuneet Rovaniemellä, ovat olleet majoittuneina hotelliin Rovaniemellä. Edellä todettu menettely on johtunut tarpeesta saada suunniteltu laiteasennustyö tehdyksi aikataulun mukaisesti.
 Asianosaisten välillä vallitsee erimielisyys siitä, onko sunnuntai 17.6.1990 katsottava puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen 16 §:ssä tarkoitetuksi laskentapäiväksi vai keskeytyspäiväksi.
 Mainittu virkaehtosopimuksen 16 § koskee ylityö- ja lisätyökorvauksen laskemista keskeytyneessä työjaksossa. Pykälän 1 momentissa on todettu, että mikäli virkamies ei ole ollut työssä koko työjaksoa sen johdosta, että virkasuhde on katkennut tai ettei hän ole voinut olla työssä loman, sairauden tai muun hyväksyttävän syyn vuoksi taikka virkamies on tullut työhön kesken työjakson, lasketaan ylityökorvaus ja lisätyökorvaus keskeytyksen ulkopuolella olevien päivien eli laskentapäivien perusteella soveltaen virkaehtosopimuksen liitteenä olevien suhteellisten työtuntinormien taulukkoja.
 STTK:n Julkisten alojen ammattijärjestö STTK-J on katsonut, että kysymyksessä olevaa sunnuntaipäivää on pidettävä virkaehtosopimuksen 16 §:n mukaisena keskeytyspäivänä. Kantansa tueksi järjestö on viitannut muun muassa puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen soveltamisohjeiden 7 §:n 11 momenttiin. Virkaehtosopimuksen 7 § sisältää työajaksi laskettavaa aikaa koskevat määräykset. Soveltamisohjeiden 7 §:n 11 momentin ensimmäisessä kappaleessa on todettu, että virka- tai komennusmatkalla matkustamiseen käytettyä aikaa ei lasketa työajaksi, ellei tässä pykälässä ole toisin määrätty. Edelleen momentissa on todettu se, missä tapauksissa virka- tai komennusmatkalla itse matkustamiseen kulunut aika luetaan työajaksi. Momentin viimeisen kappaleen mukaan virka- tai komennusmatkaan käytetty vuorokausi on työaikasopimuksen 16 §:ssä tarkoitettu keskeytyspäivä, ellei siltä tämän momentin perusteella lasketa työaikaa.
 Kanteessa on viimeksi mainittuun määräykseen viitaten katsottu, että Pauanteen kohdalla riidanalainen sunnuntaipäivä on ollut virkamatkapäivä, jolta ei ole laskettu työaikaa, joten se tällä perusteella on ollut virkaehtosopimuksen 16 §:n mukainen keskeytyspäivä. Huomioon ottaen sen, että kysymyksessä olevassa soveltamisohjeiden momentissa on käsitelty itse matkustamiseen käytetyn ajan lukemista työajaksi, on kysymyksessä oleva soveltamisohjeiden määräys työtuomioistuimen mielestä ymmärrettävä siten, että tässä mainitulla virka- tai komennusmatkaan käytetyllä vuorokaudella tarkoitetaan sellaista vuorokautta, jonka aikana on ollut kysymys myös matkustamisesta. Tällaisesta tilanteesta ei ole kysymys kanteessa tarkoitetussa tapauksessa.
 Virkaehtosopimuksen soveltamisohjeiden 16 §:n 2 momentissa on todettu, mitkä päivät ovat laskentapäiviä. Tässä esitetyn mukaan laskentapäiviä ovat työpäivien lisäksi muun muassa virka- tai komennusmatkaan kulunut vuorokausi, mikäli virkamies on samalla joutunut hoitamaan virkatehtäviään, ja viikkolepopäivät. Pykälän seuraavassa momentissa on todettu, että keskeytyspäiviä ei oteta mukaan työaikalaskentaan. Tällaisina keskeytyspäivinä on soveltamisohjeiden kysymyksessä olevassa kohdassa mainittu muun muassa muu kuin edellä 2 momentissa tarkoitettu virka- tai komennusmatkaan kulunut vuorokausi.
 Valtiovarainministeriö on katsonut, että kysymyksessä oleva sunnuntaipäivä on ollut Pauanteen virkaehtosopimuksen mukainen viikkolepopäivä ja että kysymyksessä oleva päivä tulee näin ollen katsoa laskentapäiväksi.
 Asiassa esitetyn selvityksen mukaan kysymyksessä oleva sunnuntaipäivä on ensin merkitty työaikataulukkoon Pauanteelle keskeytyspäiväksi, mutta myöhemmin se on korjattu laskentapäiväksi. Selvitystä ei ole esitetty siitä, että kysymyksessä oleva sunnuntaipäivä olisi jo ennen virkamatkaa merkitty työaikataulukkoon viikkolepopäiväksi, vaan kanteessa tarkoitettu tilanne on johtunut laiteasennustyön suorittamisen edellyttämästä aikataulusta. Näin ollen työtuomioistuin muun selvityksen puuttuessa katsoo, että kysymyksessä oleva sunnuntaipäivä on ollut sellainen virkaehtosopimuksen soveltamisohjeiden 16 §:n 3 momentissa tarkoitettu muu kuin 2 momentin mukainen virka- tai komennusmatkaan kulunut vuorokausi, joka tulee katsoa keskeytyspäiväksi.

 Tuomiolauselma
 Työtuomioistuin vahvistaa, että sotilasmestari Pauanteen 11.6. ja 20.6.1990 välisenä aikana suorittamaan virkamatkaan kuulunut sunnuntai 17.6.1990 on puolustusvoimien virkamiesten työajasta tehdyn virkaehtosopimuksen 16 §:n mukainen keskeytyspäivä.
 Asian laatuun katsoen saa STTK:n Julkisten alojen ammattijärjestö STTK-J kuitenkin pitää oikeudenkäyntikulunsa omana vahinkonaan.
 Asian ratkaisemiseen ovat osallistuneet Huopaniemi puheenjohtajana sekä Tiitinen, Virtanen, Ekuri, Leivo ja Lehto-Kannisto jäseninä.

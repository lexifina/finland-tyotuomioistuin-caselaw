# TT:1992-114

## Suomeksi

Työehtosopimukseen osallisten liittojen välillä aikaisemmin tehdyn sopimuksen mukaisesti yhtiön ajojärjestelijöiden työ oli luokiteltu kuuluvaksi palkkaluokituksen tasolle 3B. Näyttämättä oli jäänyt, että ajojärjestelijöiden työtehtävissä olisi liittojen välillä tehdyn sopimuksen jälkeen tapahtunut sellaisia oleellisia muutoksia, että heidän palkkauksensa olisi tarkistettava vaativuusluokituksen tason 3C mukaiseksi.

 TYÖEHTOSOPIMUKSEN MÄÄRÄYKSET
 Asianosaisliittojen välillä 30.1.1990 allekirjoitetun konttoritoimihenkilöitä ja liikenteenjärjestelytoimihenkilöitä koskevan työehtosopimuksen palkkausjärjestelmää koskevassa liitteessä on muun ohella seuraavat määräykset:

2

 PALKKAUSJÄRJESTELMÄ
 Toimihenkilön palkka määräytyy toisaalta hänen suorittamiensa tehtävien vaativuuden ja asianomaisen vaativuustason ohjepalkan mukaan sekä toisaalta hänen kykynsä, koulutuksensa, kokemuksensa, työsuoritustensa ja muun henkilökohtaisen pätevyytensä perusteella. Näitä tekijöitä koskevia määräyksiä on koottu erilliseen vaativuusluokitustaulukkoon.
 2.1 Tehtävän vaativuus
 Toimihenkilön tehtävät luokitellaan tämän palkkausjärjestelmän mukaisesti.
 2.2 Toimenkuvaus
 Toimenkuvalla tarkoitetaan palkkausjärjestelmää sovellettaessa vaativuusluokituksen toteuttamiseen ja palkan määräytymiseen tarvittavaa selostusta toimen sisällöstä.
 Vaativuusluokitus tehdään toimenkuvausten perusteella. Toimenkuvaus tehdään erityiselle toimenkuvauslomakkeelle. Toimenkuvauslomake siihen liittyvine toimintaohjeineen on tämän palkkausjärjestelmän lopussa.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 2.3 Vaativuusluokitus
 Vaativuusluokitus jakautuu kahteen pääosaan, vaativuustasojen yleiskuvauksiin ja vaativuusryhmiin kuuluviin työtehtäviin.
 Määriteltäessä toimihenkilön vaativuusluokkaa, on ensin selvitettävä hänen työtehtävänsä nimikkeestä riippumatta. Luokitellaan tehtävä, ei henkilöä. Tämän jälkeen arvioidaan vaativuustasojen yleiskuvausten perusteella, minkä luokan vaativuustasoa tehtävä lähinnä vastaa. Lähtökohdat vaativuusluokitusta suoritettaessa saattavat vaihdella yrityksen toimialan, koon ja organisaation mukaan.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 2.4 Karkealuokitus
 Karkealuokitus tapahtuu vertaamalla toimenkuvausta kokonaisuutena järjestelmän yleismääritelmiin, jolloin toimi sijoittuu sille tasolle, jonka määritelmää se lähinnä vastaa. Järjestelmän lähtökohtana on, että enin osa toimista voidaan tällä tavalla yleismääritelmien avulla suoraan sijoittaa oikealle karkealuokitustasolle.
 Karkealuokituksen yleismääritelmät
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Taso 3 Tehtävissä vaaditaan erikoistietoja ja/tai -taitoja, jotka on saatu koulutuksella ja/tai työkokemuksella. Tehtävissä tarvitaan yrityksen erilaisten osatoimintojen tuntemusta ja yhdistämiskykyä tai koordinointia yrityksen ulkopuolelle. Harkinta tapahtuu monipuolisten menettelytapasääntöjen tuntemuksen perusteella tai välittömän yleisluontoisen työjohdon ohjauksessa. Harkintatilanne vaihtelee ja päätöksenteossa tarvitaan oma-aloitteista päättelyä, mutta käytännöllä ja menettelytavoilla on kuitenkin selvä esikuva.

 2.5 Hienoluokitus
 Toimen lopullinen vaativuustaso määräytyy siten, että tasojen 2, 3 ja 4 karkealuokitustasoon kuuluvia toimia verrataan keskenään.
 Hienoluokituksen määritelmät
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Taso B Hoitaa tehtäviä, jotka eivät ole vaativampia tai helpompia kuin saman karkealuokitustason tehtävät yrityksessä keskimäärin.
 Taso C Hoitaa tehtäviä, jotka ovat vaativampia kuin saman karkealuokitustason tehtävät yrityksessä keskimäärin.
 Hienoluokituksessa voidaan erikseen ottaa huomioon muita vaativuustekijöitä. Nämä tulee tarvittaessa yrityskohtaisesti määritellä. Tästä johtuva vertailu voi perustua ensin suoritetun keskinäisen vertailun jälkeen tapahtuvaan vaativuustekijäkohtaiseen tarkistukseen.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 2.6 Esimiestehtävät
 Toimihenkilön katsotaan olevan esimiestehtävässä, mikäli toimeen kuuluu toisiin toimihenkilöihin tai työntekijöihin kohdistuvaa toimivaltaa. Esimies, jolla on työntekijäalaisia, on rinnastettavissa muihin esimiehiin. Esimiesasemassa olevan toimihenkilön tehtävän vaativuustasoa korotetaan esimiesaseman perusteella yhdellä hienoluokitustasolla.

 2.11 Toimien muutokset
 Toimen muuttuessa oleellisesti ja pysyvästi on työnantajan tehtävä vaativuusluokituksen tarkastus ja toimeenpantava toimen muutoksen mahdollisesti edellyttämät korjaukset.

 KANNE
 Kanteen perustelut
 Erityisalojen Toimihenkilöliitto ERTO on Autoliikenteen Työnantajaliittoa vastaan ajamassaan kanteessa lausunut, että Markku Lahtinen, Marjo Pentti, Timo Pirinen, Teuvo Poutiainen, Kauko Toivo ja Mikko Tähkävuori toimivat ajojärjestelijöinä Kiitolinja Oy:n Tampereen toimipisteessä. Työehtosopimukseen osallisten liittojen välillä 20.3.1986 tehdyn luokitusta koskevan sopimuksen mukaan ajojärjestelijät oli luettu palkkaryhmään 3B. Ajojärjestelijöiden työtehtävien vaativuuden lisäännyttyä huomattavasti tehdyn sopimuksen jälkeen oli työpaikalla aloitettu keväällä 1991 neuvottelut palkkaluokituksen tarkistamiseksi.
 Paikalliset neuvottelut palkkaluokituksen tarkistamisesta oli käyty 13.5.1991. Työnantaja oli neuvotteluissa esittänyt toimen vaativuusluokituksen säilyttämistä entisenä. Työehtosopimukseen osallisten välillä syntyneestä palkkaluokittelua koskevasta erimielisyydestä oli neuvoteltu 18.9.1991. Neuvotteluissa Erityisalojen Toimihenkilöliitto ERTO oli vaatinut ajojärjestelijöitä sijoitettavaksi nykyisten tehtäväkuvausten perusteella palkkaryhmään 3C. Työnantajaliitto oli katsonut edelleen vaativuusluokan 3B riittäväksi.
 Kiitolinja Oy:n Tampereen toimipisteen luottamusmies oli laatinut Kiitolinja Oy:n ajojärjestelijöiden vaativuusluokitusta koskevan muistion, joka oli ollut esillä muun muassa liittojen välisessä neuvottelussa. Tässä luottamusmiehen laatimassa muistiossa oli todettu muun muassa seuraavaa:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Vuonna 1986 oli Kiitolinja Oy:n Tampereen konttorin toimipaikan ajojärjestelijöiden työ pienimuotoista ja päätöksiin oli mahdollista saada aluejohtajan tuki. Poikkeavissa ja ongelmatilanteissa voi tarvittaessa pyytää aluejohtajaa apuun yhteydenpidossa liikennöitsijöihin ja asiakkaisiin.
 Liikennöitsijöiden kuljetuspäälliköt olivat vuonna -86 selvillä Tampereen vaihtuvista tilanteista ja heiltä oli silloin mahdollista pyytää neuvoa ja ohjeita menettelytavoille.
 Vuoden 1986 jälkeen on tehty useita muutoksia ajojärjestelytyöhön. Nämä kaikki ovat lisänneet ja keskittäneet ajojärjestelijöille vastuuta.
 Tällä hetkellä ajojärjestelijöille on jaettu omat vastuualueet, jotka sisältävät määrättyjen liikennöitsijöiden määrätyt linjat.
 Osittain ajojärjestelytyön kiireellisen luonteen vuoksi ja osittain siksi, että vain k.o. linjasta vastuussa oleva ajojärjestelijä on selvillä tilanteista, joutuu ajojärjestelijä tekemään nopeita ja itsenäisiä päätöksiä myös poikkeavissa ja ongelmatilanteissa.
 Päätökset koskevat Kiitolinjaa ja asiakkaita sekä liikennöitsijöitä että kuljettajia ja esim. kuljettajien työaikojen muutoksia.
 Tällä hetkellä liikennöitsijöiden kuljettajat saavat Tampereella reittinsä ja työnsä k.o. ajojärjestelijöiltä, jolle kuljettaja on suoraan vastuussa.
 Suurin yksittäinen muutos ajojärjestelijöiden toimenkuvaan tapahtui 25.4.1988, kun kuljetusliike Sillankorva palkkasi Tampereelle kuljettajat, ns. vaihtomiehet, joiden töiden, työaikojen, vuosi- ja sairaslomitusten järjestelyt hoitaa Kiitolinjan paikallinen ajojärjestelijä.
 Nykyisin on ajojärjestelijöille keskitetty samanlaisia tehtäviä ja yhtä suuri vastuu kuin liikennöitsijöiden omille kuljetuspäälliköille.

 Kanteessa esitetyt vaatimukset
 Erityisalojen Toimihenkilö ERTO on vaatinut työtuomioistuinta vahvistamaan Lahtisen, Pentin, Pirisen, Poutiaisen, Toivon ja Tähkävuoren vaativuusluokitukseksi työehtosopimuksen mukaisen 3C-luokituksen paikallisneuvottelupäivästä 13.5.1991 lukien.

 VASTINE
 Vastineen perustelut
 Autoliikenteen Työnantajaliitto on kanteeseen vastatessaan lausunut, että Kiitolinja Oy toimi osana Suomen kaupan ja teollisuuden kuljetus- ja jakelujärjestelmää. Yhtiöllä oli käytössään viiden oman tavaraterminaalin lisäksi eri liikennöitsijöiden omat terminaalit.
 Ajojärjestelyssä työpäivä aloitettiin soittamalla hoidettavan linjan kuljetusliikkeen kuljetuspäällikölle, jolta tiedusteltiin kysymyksessä olevana päivänä käytössä oleva kalusto ja miehitys Tampereella. Kuljetuspäälliköltä saatiin tieto autojen purkupaikoista ja tavaramääristä sekä siitä, mihin autot suuntakuormattiin. Päivän aikana ajojärjestelijä otti vastaan asiakkailta tulleita noutotilauksia ja mahdollisia lähetyksiin kohdistuvia kyselyitä.
 Kun runkoauto oli purkanut lastinsa ja se oli tyhjä, soitti kuljettaja ajojärjestelijälle, jolta hän sai tietää ne asiakkaat, joilta tavaraa oli noudettava. Samalla hän sai myös tiedon noudettavasta tavaramäärästä. Noudot suoritettuaan kuljettaja lähti matkaan kotipaikkakunnalleen tai jos autoon jäi tilaa, hän tuli terminaaliin, josta hän lastasi kappaletavaraa. Kun edellä mainitut tehtävät oli hoidettu, ajojärjestelijä ilmoitti kuljetusliikkeen kuljetuspäällikölle suoritetut tehtävät. Ennen työvuoron päättymistä ajojärjestelijä kertoi iltavuoron ajojärjestelijälle, mitkä autot mihinkin suuntaan piti lastata. Mahdollisissa epäselvyystilanteissa aluejohtaja tai terminaalipäällikkö antoi ajojärjestelijöille ohjeet tai hoiti asian itse.
 Ajojärjestelijöiden palkkaryhmän tarkistamisesta syntyneen erimielisyyden johdosta käydyissä paikallisissa neuvotteluissa 13.5.1991 työnantaja ja työntekijäpuoli olivat olleet yksimielisiä siitä, että Lahtisen, Pentin, Pirisen ja Toivon laatimat uudet toimenkuvauslomakkeet vastasivat heidän toimenkuvaansa lukuun ottamatta heidän väitettyä esimiesasemaansa. Samasta asiasta osapuolet olivat jääneet erimielisiksi myös Poutiaisen ja Tähkävuoren kohdalla. Lisäksi kahden viimeksi mainitun työntekijän kohdalla oli vallinnut erimielisyyttä heidän toimenkuvauksiinsa merkityistä eri töiden aikaosuuksista. Poutiainen ja Tähkävuori olivat toimenkuvauslomakkeisiin merkinneet ajojärjestelytyön osuudeksi 45 prosenttia ja tilausten vastaanoton ja selvittelyn osuudeksi 55 prosenttia. Työnantajan käsityksen mukaan ajojärjestelytyön osuus heidän kohdallaan oli 30 prosenttia ja muun työn osuus 70 prosenttia.
 Liittojen välisissä erimielisyysneuvotteluissa Erityisalojen Toimihenkilöliitto ERTO oli katsonut, että Kiitolinja Oy:n Tampereen toimipisteen ajojärjestelijöiden tehtävät ja vastuu olivat muuttuneet oleellisesti siten, että heidät tulisi sijoittaa palkkaryhmään 3C. Autoliikenteen Työnantajaliiton taholta neuvotteluissa oli katsottu, että asiassa ei ollut esitetty mitään sellaista seikkaa, joka edellyttäisi luokituksen muuttamista.
 Vuoden 1986 jälkeen tehdyt ajojärjestelijöiden töihin liittyvät muutokset olivat olleet lähinnä henkilöstömuutoksia ajojärjestelytyön helpottamiseksi ja selkiyttämiseksi. Työt oli jaettu linjoittain siten, että yhdelle ajojärjestelijälle oli keskitetty tietyn kuljetusliikkeen ajot. Koska kuljetuspäälliköt olivat nykyisin tiiviisti yhteydessä Kiitolinja Oy:n aluejohtajaan tai terminaalipäällikköön, kuljetuspäälliköt olivat varsin hyvin selvillä varsinaisista kuljetustapahtumista.
 Ajojärjestelijöiden työn luonteeseen kuuluivat nopeasti ja jatkuvasti muuttuvat tilanteet. Ajojärjestelijä oli aina ongelmatilanteissa voinut kysyä neuvoa esimieheltään terminaalipäälliköltä, aluejohtajalta tai kuljetusliikkeen kuljetuspäälliköltä. Ajotilausten välittäminen kuljettajille oli yksi keskeinen ajojärjestelytehtävä. Kuljetusliike oli velvoittanut omat kuljettajansa suorittamaan heille annetut kuljetustehtävät.
 Keskeistä syntyneessä erimielisyydessä oli se, olivatko ajojärjestelijät kuljettajiin nähden esimiesasemassa vai eivät. Työnantaja oli kiistänyt esimiesaseman muun muassa sillä perusteella, että kuljetusliikkeet eivät olleet sopineet Kiitolinja Oy:n kanssa esimiesvastuun siirrosta ajojärjestelijöille. Ajojärjestelijät eivät voineet laatia tai muuttaa kuljettajien työaikoja eivätkä käyttää muuta työnjohtovaltaa. Ajojärjestelijöillä oli ainoastaan oikeus välittää ajoja kuljettajille. Paikkaansa ei pitänyt se, että Kiitolinja Oy:n Tampereen toimipisteen ajojärjestelijät hoitaisivat Kuljetusliike Esko Sillankorva Oy:n Tampereelle palkkaamien kuljettajien eli niin sanottujen vaihtomiesten työaikojen sekä vuosi- ja sairaslomitusten järjestelyjä.
 Kiitolinja Oy:n Tampereen toimipaikan ajojärjestelijöiden työtehtävissä ei siten ollut tapahtunut sellaisia muutoksia, joilla olisi merkitystä heidän vaativuusluokitukseensa.

 TYÖTUOMIOISTUIMEN RATKAISU
 Perustelut
 Markku Lahtinen, Marjo Pentti, Timo Pirinen, Teuvo Poutiainen, Kauko Toivo ja Mikko Tähkävuori toimivat ajojärjestelijöinä Kiitolinja Oy:n Tampereen toimipisteessä. Työehtosopimukseen osallisten liittojen välillä 20.3.1986 käydyssä palkkaluokitusta koskevassa neuvottelussa ajojärjestelijän tehtävät on luokiteltu kuuluviksi vaativuusluokkaan 3B. Ajojärjestelijät ovat keväällä 1991 esittäneet palkkaluokituksen tarkistamista siten, että ajojärjestelijöiden tehtävät katsottaisiin työn vaativuuden lisääntymisen johdosta kuuluviksi palkkaryhmään 3C.
 Liitteen 2.6 kohdan mukaan esimiesasemassa olevan toimihenkilön tehtävän vaativuustasoa korotetaan esimiesaseman perusteella yhdellä hienoluokitustasolla. Saman kohdan mukaan toimihenkilön katsotaan olevan esimiestehtävässä, mikäli toimeen kuuluu toisiin toimihenkilöihin tai työntekijöihin kohdistuvaa toimivaltaa.
 Työtuomioistuimessa kuullun Erityisalojen Toimihenkilöliitto ERTO:n työehtosopimusneuvotteluihin osallistuneen puheenjohtajan kertoman mukaan edellytyksenä toimihenkilön tehtävien luokittelulle hienoluokituksen tasolle C on tehtävien itsenäisyys ja esimiesasema. Myös jompikumpi edellä mainituista ominaisuuksista saattaa yksittäistapauksessa riittää toimihenkilön tehtävien luokittelemiseksi hienoluokituksen tasolle C kuuluviksi.
 Kanteessa on katsottu ajojärjestelijöiden työn itsenäisyyden lisääntyneen vuodesta 1986, koska ajojärjestelijät nykyään joutuvat aikaisempaa enemmän tekemään päätöksiä itsenäisesti. Kiitolinja Oy:n Tampereen toimipaikan luottamusmiehen laatiman muistion mukaan ajojärjestelijöillä on aikaisemmin ollut mahdollisuus syntyneissä ongelmatilanteissa saada neuvoa ajojärjestelijöiden esimiehenä toimivalta aluejohtajalta tai liikennöitsijöiden kuljetuspäälliköiltä. Todistajana kuullun Kiitolinja Oy:n Tampereen toimipisteen terminaalipäällikön kertoman mukaan ajojärjestelijöiden tehtävissä ei tässä suhteessa ole tapahtunut muutoksia, vaan ajojärjestelijöillä on edelleen ongelmatilanteissa mahdollisuus kääntyä hänen, paikallisen aluejohtajan tai aikaisemmin ajojärjestelytehtävissä toimineen työnjohtajan puoleen. Lisäksi ajojärjestelijöillä on samanlaiset mahdollisuudet kuin aikaisemminkin olla yhteydessä kuljetusliikkeiden kuljetuspäälliköihin.
 Kanteessa on edelleen esitetty, että ajojärjestelijöiden työssä on toteutettu vuoden 1986 jälkeen sellaisia muutoksia, jotka ovat lisänneet ajojärjestelijöiden vastuuta. Tästä esimerkkinä on mainittu määrättyjen liikennöitsijöiden määrättyjen linjojen keskittäminen tietylle ajojärjestelijälle. Terminaalipäällikön mukaan mainittu järjestely on toteutettu ajojärjestelijöiden töiden selkiyttämiseksi. Tällä järjestelyllä on pyritty siihen, että ajojärjestelijän ei tarvitsisi asioida kuin yhden tai kahden eri kuljetusliikkeen kuljetuspäällikön kanssa, kun ajojärjestelijä aikaisemmin on joutunut hoitamaan asioita useamman eri kuljetusliikkeen kuljetuspäällikön kanssa.
 Työtuomioistuimessa todistajana kuultu Kiitolinja Oy:n Tampereen toimipisteessä työskentelevä ajojärjestelijä on kertonut, että kuljetusten tallentaminen atk:ta hyväksi käyttäen on osaltaan lisännyt työn vaativuutta. Terminaalipäällikön mukaan tämä keväällä 1992 käyttöön otettu menettely on helpottanut ajojärjestelijöiden ja muiden kuljetusten kanssa tekemisissä olevien toimihenkilöiden mahdollisuuksia seurata kuljetuksia.
 Noutojakelussa liikennöivien autojen lukumäärän on selvitetty kasvaneen vuodesta 1986. Selvitystä ei kuitenkaan ole esitetty siitä, millä tavoin tämä seikka on vaikuttanut ajojärjestelijän tehtävien vaativuuden kasvuun. Näyttämättä on myös jäänyt, että luottamusmiehen muistiossa mainittu ajojärjestelijän käytössä olevien puhelimien lukumäärän kasvu aikaisemmasta yhdellä olisi vaikuttanut ajojärjestelijöiden tehtävien vaativuuden kasvuun tai että heidän tehtävissään muutoinkaan olisi tapahtunut sellaisia muutoksia, joiden perusteella vaativuuden voitaisiin katsoa lisääntyneen.
 Edellä esitetyillä perusteilla työtuomioistuin katsoo näyttämättä jääneen, että kanteessa tarkoitettujen ajojärjestelijöiden tehtävissä olisi tapahtunut sellaisia oleellisia muutoksia, että heidän palkkauksensa olisi tarkistettava vaativuusluokituksen tason 3C mukaiseksi.

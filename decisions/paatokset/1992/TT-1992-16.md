# TT:1992-16

## Suomeksi

Vastaajan myönnettyä pääkäsittelyssä kanteen oikeaksi vahvistettu paperiteollisuuden työehtosopimuksen voimassaolokauden päättyneen kanteessa vaaditun mukaisesti.
 Kantaja Metsäteollisuuden Työnantajaliitto r.y. Vastaaja Paperiliitto r.y.
TUOMIO

 TYÖEHTOSOPIMUKSEN MÄÄRÄYKSET
 Asianosaisten välillä 14.3.1990 allekirjoitetussa paperiteollisuuden työehtosopimuksessa on muun ohella seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =

 VIII SOPIMUKSEN VOIMASSAOLOMÄÄRÄYKSET

 35 § SOPIMUKSEN VOIMASSAOLO
 1. Tämä sopimus tulee voimaan 14.3.1990 ja on voimassa 29. päivään helmikuuta 1992 saakka ja senkin jälkeen vuoden kerrallaan, ellei sitä viimeistään kahta kuukautta ennen sen päättymistä irtisanota.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Asianosaisten välillä 9.12.1991 allekirjoitetussa pöytäkirjassa paperiteollisuutta koskevan työehtosopimuksen jatkamiseksi on muun ohella seuraavat määräykset:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 1 Keskusjärjestöjen saavutettua tulopoliittista sopimusta vuosille 1992 ja 1992 koskevan neuvottelutuloksen, jatketaan voimassa olevaa paperiteollisuutta koskevaa työehtosopimusta nykyisin ehdoin 31.10.1993 päättyväksi sopimuskaudeksi.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 KANNE
 Kanteen perustelut
 Metsäteollisuuden Työnantajaliitto on Paperiliittoa vastaan ajamassaan kanteessa lausunut, että liittojen välillä oli 9.12.1991 allekirjoitettu pöytäkirja paperiteollisuutta koskevan työehtosopimuksen jatkamiseksi. Pöytäkirjan 1. kohdassa oli todettu, että keskusjärjestöjen saavutettua tulopoliittista sopimusta vuosille 1991 - 1993 koskevan neuvottelutuloksen, jatketaan voimassa olevaa paperiteollisuutta koskevaa työehtosopimusta nykyisin ehdoin 31.10.1993 päättyväksi sopimuskaudeksi. Tällä määräyksellä oli uudistettu paperiteollisuutta koskevan työehtosopimuksen sisältö täydennettynä tulopoliittisesta sopimuksesta johtuvilla määräyksillä uudeksi työehtosopimukseksi 1.3.1992 alkaen sopimuskaudeksi, joka päättyy 31.10.1993. Pöytäkirjalla ei ollut muutettu 14.3.1990 allekirjoitetun työehtosopimuksen voimassaoloa koskevaa 35 §:n määräystä.
 Metsäteollisuuden Työnantajaliiton ja Paperiliiton välillä oli eräissä yhteyksissä syntynyt epäselvyyttä siitä, alkoiko uusi työehtosopimuskausi 1.3.1992. Paperiliitto oli katsonut, että 14.3.1990 allekirjoitettu työehtosopimus jatkuu sellaisenaan sopimuskauden välillä katkeamatta aina 31.10.1993 saakka. Metsäteollisuuden Työnantajaliitto oli katsonut, että 14.3.1990 allekirjoitetun työehtosopimuksen voimassaolo on päättynyt 29.2.1992.
 Asiasta oli neuvoteltu Metsäteollisuuden Työnantajaliiton ja Paperiliiton edustajien välillä 17.2.1992 alkaneella viikolla sekä 16.3., 20.3. ja 23.3.1992. Neuvotteluissa ei ollut saavutettu asiasta yksimielisyyttä. Neuvotteluista oli laadittu erimielisyyspöytäkirja 24.3.1992.
 Kanteessa esitetyt vaatimukset
 Metsäteollisuuden Työnantajaliitto on vaatinut työtuomioistuinta vahvistamaan, että 14.3.1990 allekirjoitetun paperiteollisuutta koskevan työehtosopimuksen voimassaolo on päättynyt 29.2.1992.

 VASTINE
 Paperiliitto on pääkäsittelyssä myöntänyt kanteessa esitetyn vahvistusvaatimuksen oikeaksi.

 OIKEUDENKÄYNTIKULUVAATIMUKSET
 Asianosaiset ovat vaatineet oikeudenkäyntikulujensa korvaamista 16 prosentin korkoineen tuomion julistamispäivästä lukien.

 TYÖTUOMIOISTUIMEN RATKAISU
 Metsäteollisuuden Työnantajaliitto on Paperiliittoa vastaan ajamassaan kanteessa vaatinut vahvistettavaksi, että 14.3.1990 allekirjoitetun paperiteollisuutta koskevan työehtosopimuksen voimassaolo on päättynyt 29.2.1992.
 Paperiliitto on myöntänyt kanteen oikeaksi.
 Tällä perusteella työtuomioistuin kanteen hyväksyen vahvistaa, että Metsäteollisuuden Työnantajaliiton ja Paperiliiton välillä 14.3.1990 allekirjoitetun paperiteollisuutta koskevan työehtosopimuksen voimassaolo on päättynyt 29.2.1992.
 Paperiliitto velvoitetaan korvaamaan Metsäteollisuuden Työnantajaliiton oikeudenkäyntikulut 3 000 markalla 16 prosentin korkoineen tuomion julistamispäivästä lukien.
 Asian ratkaisemiseen ovat osallistuneet Orasmaa puheenjohtajana sekä Iirola, Uski, Nouro, Leivo ja Hölttä jäseninä.
 Tuomio on yksimielinen.

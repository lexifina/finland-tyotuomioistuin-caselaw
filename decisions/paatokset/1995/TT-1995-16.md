# TT:1995-16

## Suomeksi

Työnantaja ei ollut menetellyt virkaehtosopimuksen määräysten vastaisesti, kun se oli palkkaluokittelumääräysten rajoissa alentanut viransijaisina toimineiden sairaanhoitajan ja kätilön palkkaluokkaa antaessaan heille viranhoitomääräysten päättymisen jälkeen välittömästi uudet viranhoitomääräykset samoihin virkoihin.
 Kuntayhtymä ei ollut tietensä rikkonut virkaehtosopimuksen määräyksiä eikä Kunnallinen työmarkkinalaitos ollut laiminlyönyt valvontavelvollisuuttaan.
 Kantaja Toimihenkilöiden Neuvottelujärjestö TNJ ry Vastaajat Kunnallinen työmarkkinalaitos Uudenmaan sairaanhoitopiirin kuntayhtymä

 II LUKU PALKKAUS
 = = = = = = = = = = = = = = = = = = = = = = = = =
 10 § Viranhaltijan/työntekijän oikeus palkkaan
 1 mom. Kunnan tai kuntainliiton palvelukseen otetulla on oikeus saada palkka siitä lukien, kun hän on ryhtynyt virantoimitukseen/tehtäviään hoitamaan.
 Soveltamisohje
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Palvelussuhteen ei katsota katkenneen, mikäli saman kunnan/kuntainliiton sisällä viranhaltija siirtyy ilman yhtään välipäivää virkasuhteesta toiseen virkasuhteeseen tai työntekijä työsuhteesta toiseen työsuhteeseen.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 A. TEHTÄVÄKOHTAINEN PALKKA
 = = = = = = = = = = = = = = = = = = = = = = = = =
 15 § Palkkaluokan määrääminen virkaa täytettäessä
 Viranhaltijat 1 mom. Virkaa täytettäessä kunnan/kuntainliiton ao. viranomainen päättää viranhaltijan palkkaluokasta tämän luvun ja palkkaluokittelumääräysten mukaisesti.
 Soveltamisohje
 Palkkaluokittelun mukainen palkkaus on viranhaltijakohtainen. Virkaa täytettäessä palkkaluokittelun asteikosta valitaan palkkaluokka siitä riippumatta, mihin palkkaluokkaan viran aikaisempi haltija oli sijoitettu.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 16 § Palkkaluokka-asteikon soveltaminen
 1 mom. Viranhaltijan/työntekijän palkkaluokkaa palkkaluokittelun rajoissa määrättäessä on noudatettava tarkoituksenmukaista palkkausporrastusta siten, että vaativampia ja/tai vastuullisempia kuten esimiestehtäviä suorittavat sijoitetaan asteikon rajoissa muita korkeampiin palkkaluokkiin. Samoin ne, joilla on muita sopivampi koulutus ja/tai perehtyneisyys asianomaisiin tehtäviin ja/tai pysyväisluontoisesti hankalammat työolosuhteet, pyritään sijoittamaan muita korkeampiin palkkaluokkiin. Johtavassa asemassa tai muutoin esimiestehtävissä toimivan palkkaluokkaa harkittaessa on lisäksi otettava huomioon asianomaisen kunnan/kuntainliiton ja yksikön koko.
 = = = = = = = = = = = = = = = = = = = = = = = = =

 Soveltamisohje
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Palkkaluokan valinta on pyritty yksilöimään asteikon puitteissa siten, että palkkaluokan valitseminen ei ole täysin vapaassa harkinnassa, vaan se on sidottu virkaehtosopimuksen määräyksillä. Sopimuksen mukaista ei ole, että ao. viranomainen tekisi yleispäätöksen esim. palkkaluokittelun asteikon ylä- tai alarajan käyttämisestä tai että palkkausperusteena käytetään pelkästään palvelusajan pituutta.

 IV LUKU VUOSILOMA
 = = = = = = = = = = = = = = = = = = = = = = = = =
 95 § Palvelussuhteessa tapahtuvien muutosten vaikutus vuosilomaan
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Soveltamisohje
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Mikäli viranhaltija siirretään tai siirtyy päävirasta välittömästi toiseen päävirkaan saman työnantajan palveluksessa taikka väliaikaisen viranhaltijan virkasuhdetta välittömästi jatketaan, virkasuhteen ei katsota katkenneen eikä lomakorvausta tästä syystä makseta. Vuosilomaedut määräytyvät tällöin kuten yhtenäisessä palvelussuhteessa.

 KANNE
 Vaatimukset
 Toimihenkilöiden Neuvottelujärjestö TNJ on vaatinut työtuomioistuinta vahvistamaan, että Uudenmaan sairaanhoitopiirin kuntayhtymällä ei ole ollut oikeutta alentaa väliaikaisen viranhaltijan palkkaluokkaa antaessaan viranhaltijalle uuden viranhoitomääräyksen samaan virkaan.
 Lisäksi Toimihenkilöiden Neuvottelujärjestö TNJ on vaatinut, että Uudenmaan sairaanhoitopiirin kuntayhtymä tuomitaan kunnallisen virkaehtosopimuslain 20 §:n nojalla virkaehtosopimuksen tieten rikkomisesta hyvityssakkoon ja että Kunnallinen työmarkkinalaitos tuomitaan kunnallisen virkaehtosopimuslain 11 ja 20 §:n nojalla valvontavelvollisuuden laiminlyönnistä hyvityssakkoon.
 Toimihenkilöiden Neuvottelujärjestö TNJ on vaatinut vastaajien velvoittamista yhteisvastuullisesti korvaamaan sen oikeudenkäyntikulut korkoineen.

 Perustelut
 Toimihenkilöiden Neuvottelujärjestö TNJ on Kunnallista työmarkkinalaitosta ja Uudenmaan sairaanhoitopiirin kuntayhtymää vastaan ajamassaan kanteessa lausunut, että Uudenmaan sairaanhoitopiirin kuntayhtymän Jorvin sairaalassa oli väliaikaiselle viranhaltijalle annettu useita peräkkäisiä viranhoitomääräyksiä samaan virkaan. Viranhoitomääräysten välillä ei ollut ollut yhdenkään päivän katkoa. Sijaisen määräyskirjaa uusittaessa tai jatkettaessa samassa virassa oli Uudenmaan sairaanhoitopiiri harkinnut palkkaluokan uudelleen. Harkinnan perusteella oli viranhaltijan palkkaluokka alentunut, vaikka viranhaltija oli jatkanut työntekoa samassa virassa kuin edellisen viranhoitomääräyksen aikana ja viranhaltijan tehtävät olivat pysyneet täysin samoina.
 Esimerkkinä edellä selostetusta menettelystä Toimihenkilöiden Neuvottelujärjestö TNJ on esittänyt sairaanhoitaja Virpi Jouslammen ja kätilö Anne Kivilompolon viranhoitomääräykset. Jouslampi oli saanut viranhoitomääräykset samaan sairaanhoitajan virkaan ajoille 1.9. - 31.12.1992 ja 1.1. - 30.6.1993. Hänen palkkaluokkansa oli viranhoitomääräyksen mukaan ollut 31.12.1992 asti Y 29 ja 1.1.1993 lähtien palkkaluokka oli ollut Y 28. Kivilompolo oli puolestaan saanut viranhoitomääräykset samaan kätilön virkaan ajoille 1.10. - 31.12.1992, 1.1. - 25.1.1993 ja 26.1. - 31.7.1993. Hänen palkkaluokkansa oli viranhoitomääräysten mukaan ollut 31.12.1992 asti Y 29 ja 1.1.1993 lähtien palkkaluokka oli ollut Y 28.
 Uudenmaan sairaanhoitopiirin kuntayhtymän Jorvin sairaalassa viransijaisten viranhoitomääräykset olivat olleet enintään vakinaisen viranhaltijan virkavapauden mittaisia, usein lyhyempiäkin. Tästä oli seurannut, että kun vakinaisen viranhaltijan virkavapautta oli jatkettu, viransijaiselle oli annettu uusi viranhoitomääräys edellisen jatkoksi siten, että viranhoitomääräysten väliin ei jäänyt yhtään päivää. Samoin oli toimittu silloin, kun sijaisen viranhoitomääräys oli annettu vakinaisen viranhaltijan virkavapautta lyhyemmäksi ajaksi.
 Toimihenkilöiden Neuvottelujärjestö TNJ on katsonut, että kun viransijaiselle oli edellä kuvatulla tavalla annettu uusi viranhoitomääräys, kysymyksessä oli tosiasiallisesti ollut jo syntyneen palvelussuhteen jatkaminen, eikä uuden palvelussuhteen aloittaminen.
 Kunnallisen yleisen virka- ja työehtosopimuksen sopijapuolten välillä oli jo aikaisemmin hyväksytty se tulkinta, että viranhaltijan siirtyessä virkasuhteesta toiseen ilman että virkasuhteiden väliin jäi yhtään päivää, palvelussuhteeseen liittyvien etujen ja oikeuksien mielessä ei palvelussuhteen katsottu katkenneen. Tämä periaate oli kirjattu kunnallisen yleisen virka- ja työehtosopimuksen 10 §:n 1 momentin soveltamisohjeeseen, jossa oli kysymys viranhaltijan oikeudesta palkkaan virantoimituksen alettua.
 Sama periaate oli kirjattu myös vuosilomaetuuksia koskevaan kunnallisen yleisen virka- ja työehtosopimuksen 95 §:n 2 momentin soveltamisohjeen kolmanteen kappaleeseen. Sen mukaan väliaikaisen viranhaltijan virkasuhdetta välittömästä jatkettaessa virkasuhde ei katkennut, eikä lomakorvauksia tästä syystä maksettu.
 Edelleen saman periaatteen oli Kunnallisen työmarkkinalaitoksen apulaisneuvottelupäällikkö Heikki Saipio todennut kirjassaan Kunnallisen viranhaltijan oikeusasema. Kirjassa esitetyn mukaan viranhaltijan siirtyessä kunnan virasta tai virkasuhteesta toiseen siten, että virantoimitus ei viranhoitomääräyksen mukaan välillä keskeytynyt, virkasuhteeseen liittyvät oikeudet säilyivät palvelussuhteen muutoksesta huolimatta (esim. oikeus palkkaan).
 Erään apuhoitajan sairausloma-ajan palkkaa koskevassa keskusneuvottelussa 22.9.1982 Kunnallinen työmarkkinalaitos, silloinen Kunnallisen sopimusvaltuuskunnan toimisto, oli tunnustanut, että viranhaltijan virkasuhde oli jatkunut keskeytymättä useista viranhoitomääräyksistä huolimatta.
 Kun kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin mukaan virkaa täytettäessä kuntayhtymän viranomainen sai päättää viranhaltijan palkkaluokan sopimuksen palkkausluvun ja palkkaluokittelumääräysten mukaisesti, oli tämä harkintaoikeus olemassa vain palvelussuhteen alkaessa. Palvelussuhteen jatkuessa yhdenjaksoisesti, vaikkakin uudella viranhoitomääräyksellä, oli työnantajan sidottu jo kerran suorittamaansa harkintaan, jollei sopimuksen mukaisia edellytyksiä uuteen harkintaan ollut.
 Palvelussuhteen jatkuessa viranhaltijan palkkaluokka voitiin alentaa palkkaluokittelun perusteella vain sopimuksessa määritellyistä syistä. Tällaisia syitä saattoivat kunnallisen yleisen virka- ja työehtosopimuksen 19 §:n 5 momentin mukaan olla vain olennaisen tehtäväkokonaisuuden jättäminen pois viranhaltijan tehtävistä tai siirto toiseen alempipalkkaiseen virkaan. Koska virkasuhteen jatkuminen uudella viranhoitomääräyksellä katsottiin virkasuhteeseen kuuluvien etujen ja oikeuksien kannalta samaksi virkasuhteeksi, ei työnantajalla ollut tälläkään perusteella ollut oikeutta alentaa viransijaisen palkkaa määräyskirjaa uusittaessa.
 Kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin soveltamisohjeen mukaan palkkaluokittelun mukainen palkkaus oli viranhaltijakohtainen. Määrätessään viranhaltijan palkkaluokan tietyssä virassa ensimmäisen kerran suoritti työnantaja samalla kunnallisen yleisen virka- ja työehtosopimuksen 16 §:n 1 momentin mukaisen harkinnan työtehtävien vaativuuden ja vastuullisuuden, henkilön koulutuksen ja perehtyneisyyden ja työolosuhteiden vaikutuksesta palkkaluokkaan. Viimeksi mainitun pykälän soveltamisohjeiden mukaan palkkaluokan valinta oli pyritty yksilöimään asteikon puitteissa siten, että palkkaluokan valitseminen ei ollut täysin vapaassa harkinnassa, vaan se oli sidottu virkaehtosopimuksen määräyksillä.
 Toimihenkilöiden Neuvottelujärjestö TNJ:n neuvottelijoiden käsityksen mukaan kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin soveltamisohjeen sanonnalla aikaisempi viranhaltija oli sopimusneuvotteluissa tarkoitettu kysymyksessä olevassa virassa ollutta muuta henkilöä. Muualla sopimuksessa tunnustetun käytännön vuoksi, jonka mukaan palvelussuhdetta välittömästi jatkettaessa palvelussuhteen ehdot säilyivät ennallaan, ja koska palkkaluokan alentamista ei ollut aiemmin esiintynyt, neuvottelijat eivät olleet voineet tietää Kunnallisen työmarkkinalaitoksen vastakkaista kantaa sopimuskohdan tulkinnasta.
 Kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin mukaan virkaa täyttäessään, joko vakinaisesti tai väliaikaisesti, kunta ja kuntayhtymä päättivät viranhaltijan palkkauksesta kunnallisen yleisen virka- ja työehtosopimuksen palkkausluvun ja palkkaluokittelumääräysten mukaisesti. Sopimuksen 15 §:n 1 momentissa oli sovittu, että aina virkaa täytettäessä työnantajan oli noudatettava myös kunnallisen yleisen virka- ja työehtosopimuksen 16 §:n määräyksiä.
 Palvelussuhdetta jatkettaessa uudella viranhoitomääräyksellä työnantaja oli sidottu jo kertaalleen suorittamaansa harkintaan palkkaluokasta, jos palkkaluokan määräämisen harkintaa sitovissa tekijöissä ei ollut tapahtunut muutosta. Kun sama henkilö jatkoi työntekoa samoissa tehtävissä ei työnantajalla ollut myöskään kunnallisen yleisen virka- ja työehtosopimuksen 16 §:n 1 momentin mukaan oikeutta alentaa viranhaltijan palkkaa.
 Kunnallisessa virka- ja työehtosopimuksissa oli jo vuodesta 1977 ollut terveydenhuoltoalan nimikkeissä käytössä palkka-asteikkoja. Uudenmaan sairaanhoitopiirin kuntayhtymässä oli järjestöjen kanssa käyty neuvotteluja palkkaasteikon soveltamisesta viimeksi vuonna 1991. Näissä neuvotteluissa oli nimenomaan neuvoteltu paikallisten järjestöjen kanssa siitä, miten työtehtävien vaativuus ja vastuullisuus vaikuttivat eri viranhaltijoiden ja työntekijöiden palkkaluokan määräämiseen. Lopullisen päätöksen palkkaluokkamuutoksista oli tehnyt työnantaja harkintansa mukaan, jota oli rajoittanut kunnallisen yleisen virkaja työehtosopimuksen 16 §:n 1 momentin mukaiset rajoitukset. Palkka-asteikon käytöstä ja siitä käydyistä neuvotteluista syntyneiden kokemusten perusteella oli Uudenmaan sairaanhoitopiirin kuntayhtymän täytynyt olla tietoinen kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin ja 16 §:n 1 momentin tarkoituksesta.

 VASTAUS
 Vaatimukset
 Kunnallinen työmarkkinalaitos ja Uudenmaan sairaanhoitopiirin kuntayhtymä ovat vaatineet kanteen hylkäämistä ja korvausta oikeudenkäyntikuluistaan korkoineen.

 Perustelut
 Kunnallinen työmarkkinalaitos ja Uudenmaan sairaanhoitopiirin kuntayhtymä ovat kanteeseen vastatessaan lausuneet, että Uudenmaan sairaanhoitopiirin kuntayhtymällä oli ollut oikeus muuttaa väliaikaisen viranhaltijan palkkaluokkaa antaessaan viranhaltijalle uuden viranhoitomääräyksen. Väliaikaisen viranhoitomääräyksen antaminen oli viran täyttämistä aivan samalla tavalla kuin vakinaisen viran täyttäminenkin. Se seikka, oliko kyseessä oleva henkilö hoitanut kyseessä olevaa virkaa aikaisemmin annetun väliaikaisen viranhoitomääräyksen nojalla ja jatkuiko hänen palvelussuhteensa mahdollisesti keskeytymättä, ei vaikuttanut asiaan.
 Kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin mukaan kuntayhtymän asianomainen viranomainen päätti virkaa täytettäessä viranhaltijan palkkaluokasta virkaehtosopimuksen määräyksen mukaisesti. Soveltamisohjeen mukaan palkkaluokittelun mukainen palkkaus oli viranhaltijakohtainen ja virkaa täytettäessä valittiin palkkaluokittelun asteikosta palkkaluokka siitä riippumatta, mihin palkkaluokkaan viran aikaisempi haltija oli sijoitettu.
 Sillä seikalla, oliko viran aikaisempi haltija sama kuin uusi, ei ollut merkitystä sopimusmääräyksiä sovellettaessa. Aina kun viranhoitomääräys päättyi, harkittiin viranhoidon järjestäminen uudelleen. Työnantajalla ei ollut velvollisuutta antaa viranhoitomääräystä entiselle väliaikaiselle viranhoitajalle, vaikka virkaan edelleenkin otettiin väliaikainen viranhaltija. Kysymyksessä oli aivan tyypillinen virkaanottamistilanne ja tällöin myös esimerkiksi palkkaus harkittiin uudelleen ottaen huomioon virkaehtosopimuksen määräykset, ylemmän viranomaisen mahdollisesti antamat hallinnolliset ohjeet ja muut asiaan vaikuttavat paikalliset olosuhteet kuten esimerkiksi työnantajan palkanmaksukyky. Viranhoitomääräyksen antaminen edellytti luonnollisesti viranhaltijan suostumusta ja sitä, että viranhaltijalle ilmoitettiin etukäteen palvelussuhteen ehdot, kuten esimerkiksi palkkausperuste. Viranhaltija saattoi kieltäytyä viran hoitamisesta ilmoitetuilla ehdoilla.
 Virkaehtosopimuksessa ei ollut sovittu mitään erityismääräyksiä niitä tapauksia varten, joissa viranhoitomääräys annettiin entiselle väliaikaiselle viranhaltijalle siten, että palvelussuhde ei keskeytynyt. Koska tällaisia poikkeusmääräyksiä ei ollut, noudatettiin kaikissa väliaikaisen viranhoitomääräyksen antamistapauksissa kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin määräyksiä, joiden mukaan viranhaltijalle aikaisemmin maksettu palkkaluokka ei rajoittanut viranomaisen harkintavaltaa.
 Kunnallisen työmarkkinalaitoksen yleiskirjeeseen A 34/1993 sisältyivät yhteiset soveltamisohjeet, jotka myös Toimihenkilöiden Neuvottelujärjestö TNJ:n edustajat olivat hyväksyneet. Soveltamisohjeiden 2.2 kohdan mukaan väliaikaista viranhaltijaa koskeva kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 3 momentin niin sanottu takuumääräys oli poistettu. Viranhaltijan palkkaus määräytyi väliaikaisen viranhoitomääräyksen yhteydessä kuten yleensäkin viranhaltijan palkkaus määrättiin virkaa täytettäessä eli 15 §:n 1 ja 2 momenttien mukaisesti. Soveltamisohjeissa oli edelleen mainittu, että viranhaltija, jolle oli ennen 1.1.1994 virkasäännön nojalla annettu määräys väliaikaisesti hoitaa yksinomaan muuta virkaa kuin omaansa ja hänelle oli annettu sitä varten hakemuksetta virkavapautta, oli kuitenkin oikeutettu takuupalkkaan niin kauan kuin väliaikainen viranhoito virkamääräyksellä jatkui.
 Edellä selostetuista yhteisistä soveltamisohjeista kävi ilmi, että kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momenttia sovellettiin väliaikaisiin viranhaltijoihin silloinkin, kun kysymyksessä oli tapaus, jossa entiselle väliaikaiselle viranhaltijalle annettiin uusi viranhoitomääräys ilman että palvelussuhde keskeytyi.
 Kunnallisen yleisen virka- ja työehtosopimuksen 19 §:n 5 momentin määräykset palkkaluokan alentamiskiellosta eivät tulleet sovellettaviksi virkaa täytettäessä. Se kävi ilmi itse määräyksen sisällöstä ja määräykseen liittyvistä soveltamisohjeista.
 Virkasuhteen jatkumista koskevat määräykset eivät vaikuttaneet tapaukseen, jossa entiselle väliaikaiselle viranhaltijalle annettiin uusi viranhoitomääräys ilman että palvelussuhde keskeytyi. Esimerkiksi kunnallisen yleisen virka- ja työehtosopimuksen 10 §:n 1 momentin soveltamisohjeilla tai 95 §:n 2 momentin soveltamisohjeilla ei ollut tässä asiassa merkitystä. Sen sijaan, jos jokin etuus liittyi virkasuhteen keskeytymättömään jatkumiseen tai virantoimituksen alkamiseen virkasuhteen aikana, oli näillä määräyksillä merkitystä. Esimerkkeinä voitiin mainita erilaiset karenssiajat ja viranhaltijan oikeus palkkaan virantoimituksen alkamisesta lukien. Tätä tapausta oli käsitellyt Heikki Saipio kanteessa mainitussa kirjassa. Kirjassa ei ollut kuitenkaan käsitelty taikka otettu kantaa väliaikaisen viranhaltijan palkan määrään virkasuhteen jatkuessa keskeytymättä uuden viranhoitomääräyksen perusteella.
 Kunnallisen yleisen virka- ja työehtosopimuksen 16 §:n 1 momentin määräykset koskivat palkkaluokan määräämistä palkkaluokittelun rajoissa. Se, että palkkaluokkaa oli muutettu, saattoi johtua muun muassa siitä, että tehtävät olivat muuttuneet tai että palkkaus oli aikaisemmin arvioitu tehtävät huomioon ottaen väärin tai että työnantajan palkkapoliittinen linja oli muuttunut.
 Sairaanhoitajien ja kätilöiden palkkaluokittelun mukainen palkkaluokka-asteikko oli Y 26-29. Osa saman yksikön vakinaisista sairaanhoitajista oli sijoitettu palkkaluokkaan Y 27. Väliaikaisia viranhoitajia oli palkkaluokissa Y 26-28. Aikaisemmin väliaikaiset viranhaltijat oli sijoitettu asteikon ylärajalle eli palkkaluokkaan Y 29, vaikka sopimusmääräykset ja soveltamisohjeet sekä viranhaltijoiden tehtävien vaativuus ja perehtyneisyys huomioon ottaen heidän palkkaluokkansa olisi pitänyt olla alempi.
 Uusia viranhoitomääräyksiä annettaessa kanteessa mainittujen väliaikaisten viranhaltijoiden palkkaluokitteluksi määrättiin Y 28 eli kaksi palkkaluokkaa yli alarajan ja yksi alle ylärajan. Tämän palkkaluokittelun katsottiin aikaisempaa paremmin vastaavan tehtävien vaativuutta ja sopimuksen tarkoitusta. Osaltaan uudelleenarviointiin vaikutti sairaalan huonon taloudellisen tilanteen vuoksi muuttunut palkkapolitiikka. Enää ei ollut varaa maksaa ylimitoitettuja palkkoja. Kunta saattoi palkkaluokittelumääräysten rajoissa muuttaa aikaisempaa palkkauspoliittista linjaansa siten, että uusissa viranhoitomääräyksissä noudatettiin aikaisempaa alhaisempia palkkoja.
 Annettaessa virkamääräys, jossa yleensä todettiin palkkausperuste eli palkkaluokka, suoritettiin yksipuolinen hallintotoimi. Virkasuhteen syntyminen edellytti kuitenkin viranhaltijan suostumusta. Viranhaltijan kanssa ei voitu sopia virkasuhteen ehdoista kuten esimerkiksi palkkauksesta. Sen sijaan viranhaltija saattoi kieltäytyä mielestään liian huonosti palkatusta virkasuhteesta. Palkkaluokan muutoksesta tuli ilmoittaa ennen viranhoitomääräyksen antamista asianomaisille henkilöille. Kanteessa tarkoitetussa tapauksessa palkkapolitiikan muuttumisesta oli tiedotettu eri yhteyksissä ja siitä oli pyritty ilmoittamaan henkilökohtaisesti niille, joita muutos koski. Vaikka ilmoitusta ei olisi tehtykään, muuttunut palkkaus ei tämän vuoksi olisi ollut sopimuksen vastainen.
 Vaikka Toimihenkilöiden Neuvottelujärjestö TNJ:n neuvottelijat olisivat ymmärtäneet soveltamisohjeen käsitteen "aikaisempi viranhaltija" tarkoittavan kyseessä olevassa virassa ollutta muuta henkilöä, ei tämä vielä osoittanut, että kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momenttia olisi tarkoitettu soveltaa vastoin sen sanamuotoa vain puheena olevaa virkaa ensimmäistä kertaa hoitavan henkilön palkkaukseen.

 TYÖTUOMIOISTUIMEN RATKAISU
 Perustelut
 Uudenmaan sairaanhoitopiirin kuntayhtymän Jorvin sairaalassa on vuonna 1992 annettu kanteessa tarkoitetuille viransijaisina toimiville viranhaltijoille määräaikaiset, vuoden lopussa päättyvät viranhoitomääräykset sairaanhoitajan ja kätilön virkoihin. Viranhoitomääräysten mukaan heidän palkkaluokkansa on ollut Y 29. Vuoden 1993 alusta lukien viranhaltijoille on annettu uudet määräaikaiset viranhoitomääräykset samoihin virkoihin. Tällöin heidän palkkaluokakseen on määrätty Y 28.
 Toimihenkilöiden Neuvottelujärjestö TNJ on kanteessaan katsonut, että Uudenmaan sairaanhoitopiirin kuntayhtymällä ei ole ollut oikeutta alentaa väliaikaisen viranhaltijan palkkaluokkaa antaessaan viranhaltijalle uuden viranhoitomääräyksen samaan virkaan. Kantajan mielestä uutta määräystä annettaessa on ollut kysymys tosiasiallisesti jo syntyneen palvelussuhteen jatkamisesta. Tämän vuoksi työnantaja on ollut sidottu samaan virkaan antamansa ensimmäisen virkamääräyksen yhteydessä suorittamaansa harkintaan palkkaluokasta. Edelleen kantaja on katsonut, että kun sama viranhaltija jatkaa työntekoa samoissa tehtävissä, työnantajalla ei ole myöskään virkaehtosopimuksen palkkaluokka-asteikon soveltamista koskevan 16 §:n 1 momentin määräysten mukaan oikeutta alentaa viranhaltijan palkkaa. Viranhaltijoiden palkkaluokan alentamiseen ei ole ollut kunnallisessa yleisessä virkaehtosopimuksessa tarkoitettuja perusteita.
 Kunnallinen työmarkkinalaitos ja Uudenmaan sairaanhoitopiirin kuntayhtymä ovat puolestaan katsoneet, että väliaikaisenkin viranhoitomääräyksen antamisessa on kysymys viran täyttämisestä ja että virkaa täytettäessä viranhaltijan palkkaus virkaehtosopimuksen mukaan harkitaan aina uudelleen. Virkaehtosopimuksessa ei ole erityismääräyksiä niitä tapauksia varten, joissa viranhoitomääräys annetaan entiselle väliaikaiselle viranhaltijalle siten, että palvelussuhde ei keskeydy.
 Virkaehtosopimuksen palkkausta koskevan luvun 15 §:n mukaan virkaa täytettäessä kunnan/kuntainliiton asianomainen viranomainen päättää viranhaltijan palkkauksesta tämän luvun ja palkkaluokittelumääräysten mukaisesti. Sopimusmääräystä koskevan soveltamisohjeen ensimmäisen kappaleen mukaan palkkaluokittelun mukainen palkkaus on viranhaltijakohtainen. Virkaa täytettäessä palkkaluokittelun asteikosta valitaan palkkausluokka siitä riippumatta, mihin palkkaluokkaan viran aikaisempi haltija oli sijoitettu.
 Virkaehtosopimuksen 16 §:ssä on määräykset palkkaluokkaasteikon soveltamisesta. Määräyksen ensimmäisen momentin mukaan viranhaltijan/työntekijän palkkaluokkaa palkkaluokittelun rajoissa määrättäessä on noudatettava tarkoituksenmukaista palkkaporrastusta siten, että vaativampia ja/tai vastuullisempia kuten esimiestehtäviä suorittavat sijoitetaan asteikon rajoissa muita korkeampiin palkkaluokkiin. Samoin ne, joilla on muita sopivampi koulutus ja/tai perehtyneisyys asianomaisiin tehtäviin ja/tai pysyväisluontoisesti hankalammat työolosuhteet, pyritään sijoittamaan muita korkeampiin palkkaluokkiin. Johtavassa asemassa tai muutoin esimiestehtävissä toimivan palkkaluokkaa harkittaessa on lisäksi otettava huomioon asianomaisen kunnan/kuntainliiton ja yksikön koko.
 Työtuomioistuimelle on esitetty selvitystä siitä, että kanteessa tarkoitettujen sairaanhoitajan ja kätilön tehtävissä tai työolosuhteissa ei kanteessa tarkoitetun yhdenjaksoisen palvelussuhteen aikana ole tapahtunut merkittäviä muutoksia.
 Toimihenkilöiden Neuvottelujärjestö TNJ on kanteensa tueksi vedonnut sopimuspuolten välillä aikaisemmin hyväksyttyyn palvelussuhteen yhdenjaksoista jatkumista koskevaan tulkintaan. Kanteen perusteluiden mukaan viranhaltijan siirtyessä virkasuhteesta toiseen ilman, että virkasuhteiden väliin jää yhtään päivää, palvelussuhteeseen liittyvien etujen ja oikeuksien mielessä palvelussuhteen ei katsota katkenneen.
 Toimihenkilöiden Neuvottelujärjestö TNJ on todennut, että sanottua tulkintaa koskeva periaate on sittemmin kirjattu virkaehtosopimuksen palkkausta koskevan luvun 10 §:n 1 momentin soveltamisohjeisiin. Sanotun soveltamisohjeen mukaan palvelussuhteen ei katsota katkenneen, mikäli saman kunnan/kuntainliiton sisällä viranhaltija siirtyy ilman yhtään välipäivää virkasuhteesta toiseen virkasuhteeseen.
 Asianosaiset ovat olleet yksimielisiä siitä, että palvelussuhteen yhdenjaksoisella jatkumisella on merkitystä eräisiin viranhaltijan etuihin ja oikeuksiin. Sellaisia ovat ainakin eräät sairausajan palkkaan ja vuosilomaan liittyvät oikeudet. Sen sijaan asianosaiset ovat erimielisiä siitä, koskeeko sanottu periaate myös palkkaluokan määräämistä virkaa edellä selostetulla tavalla väliaikaisesti täytettäessä.
 Asiassa on kuultu todistajina Suomen lähi- ja perushoitajaliitto SuPer ry:n neuvottelupäällikköä, Kunta-alan ammattiliitto KTV ry:n osastosihteeriä ja kahta Kunnallisen työmarkkinalaitoksen neuvottelupäällikköä.
 Suomen lähi- ja perushoitajaliitto SuPerin neuvottelupäällikön mukaan liiton lähtökohtana virkaehtosopimusneuvotteluissa on ollut sijaisten aseman parantaminen siten, että sijaiset rinnastetaan vakinaisiin viranhaltijoihin. Sopimusneuvotteluissa ei ole ollut esillä kysymys siitä, jatkuvatko sijaisen palkkaedut samanlaisina samaa virkaa koskevan uuden viranhoitomääräyksen antamisen jälkeen. Asiasta ei myöskään ole aikaisemmin esiintynyt erimielisyyttä. Neuvottelupäällikön käsitys palkkaetujen jatkumisesta on perustunut siihen, että osapuolet ovat olleet eräiden muiden etujen jatkumisesta yksimielisiä.
 Kunnallisen työmarkkinalaitoksen neuvottelupäällikön mukaan aikaisemmalla viranhoitomääräyksellä ei ole vaikutusta seuraavaan määräykseen palvelussuhteen ehtojen kannalta. Viranhoitomääräystä annettaessa palkka määrätään virkaehtosopimuksen rajoissa. Virkaehtosopimuksen 10 §:n 1 momentissa on määritelty ajankohta, josta alkaen viranhaltijalla on oikeus palkkaan. Tähän liittyvällä soveltamisohjeella ei neuvottelupäällikön mukaan ole vaikutusta siihen, miten viranhaltijan palkka on määrättävä, vaan sillä on merkitystä lähinnä siihen, miten sairausajan palkka ja vuosilomaetuudet on eräissä tapauksissa määrättävä.
 Kunnallisen työmarkkinalaitoksen toisen neuvottelupäällikön mukaan työnantajapuolella on aina 1970-luvulta alkaen pidetty selvänä, että viransijaisuusmääräystä voidaan jatkaa uudella määräyksellä ja palkka määritellä siinä yhteydessä uudelleen. Yhdenjaksoisella palvelussuhteella neuvottelupäällikön mukaan on merkitystä lähinnä niissä tapauksissa, joissa se on erikseen mainittu. Virka- ja työehtosopimuksen yhdistämisneuvotteluissa vuonna 1992 sopimukseen ei ole tehty asiallisia muutoksia.
 Työtuomioistuin toteaa, että väliaikaiselle viranhaltijalle määräaikaista virkamääräystä annettaessa on aina kyseessä viran täyttäminen, jonka perusteella viranhaltijan ja työnantajan välille syntyy virkasuhde. Sanamuodon mukaan kunnallisen yleisen virka- ja työehtosopimuksen 15 §:n 1 momentin ja 16 §:n 1 momentin nojalla työnantajalla on oikeus määritellä palvelussuhteen ehtona sovellettava palkkaluokka riippumatta siitä, onko kyseessä vakinainen virantäyttö tai väliaikainen viranhoitomääräys. Työtuomioistuin katsoo jääneen näyttämättä, että kunnallisen yleisen virka- ja työehtosopimuksen 10 §:n 1 momentin yhteyteen sijoitettu soveltamisohje, jossa on määräys yhdenjaksoisesta palvelussuhteesta, rajoittaisi työnantajan oikeutta päättää palkkaluokka edellisen viranhoitomääräyksen päättymisen jälkeen välittömästi uutta viranhoitomääräystä annettaessa.
 Työtuomioistuin katsoo, että Uudenmaan sairaanhoitopiirin kuntayhtymä ei ole menetellyt kunnallisen yleisen virkaehtosopimuksen 15 §:n 1 momentin ja 16 §:n 1 momentin määräysten vastaisesti alentaessaan väliaikaisen viranhaltijan palkkaluokkaa samaa virkaa koskevan uuden viranhoitomääräyksen yhteydessä.
 Uudenmaan sairaanhoitopiirin kuntayhtymä ei ole rikkonut virkaehtosopimuksen määräyksiä kunnallisen virkaehtosopimuslain 20 §:ssä mainitulla tavalla. Kunnallinen työmarkkinalaitos ei ole laiminlyönyt valvontavelvollisuuttaan.

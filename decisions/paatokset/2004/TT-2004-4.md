# TT:2004-4

## Suomeksi

Kanteessa tarkoitettu maalarin työ katsottiin urakkatyönä tehdyksi. Työnantaja oli rikkonut tietensä työehtosopimuksen urakkahinnoittelua koskevia määräyksiä laiminlyödessään kirjallisten urakkasopimusten tekemisen ja alentaessaan urakan kestäessä työn laatuun ja työvauhtiin vedoten urakkaennakon määrää ilman, että se olisi perustunut työn mittaamiseen ja urakka-ansion laskemiseen. Lisäksi työnantaja oli rikkonut tietensä työehtosopimusta jättäessään tehdyiltä ylityötunneilta ylityökorvaukset maksamatta.
Työnantajaliitto ei ollut laiminlyönyt valvontavelvollisuuttaan.

11.1. Yli- ja hätätyö määritetään ja korvataan työaikalain mukaisesti. Viikottaisesta ylityöstä maksetaan 8 ensimmäiseltä tunnilta 50 %:lla ja seuraavilta tunneilta 100 %:lla korotettu palkka. RAKENNUSTEN PINTAKÄSITTELYN URAKKAHINNOITTELU
URAKKATYÖN SUORITTAMISTA, MITTAUSTA JA URAKKA-ANSION MAKSAMISTA KOSKEVAT YLEISMÄÄRÄYKSET
1. Urakkatyö
1. Kaikki hinnoittelussa mainitut työt suoritetaan urakkatyönä.
2. Työ suoritetaan kuitenkin aina aikapalkalla, mikäli edellytyksiä urakkatyön suorittamiselle ei ole olemassa työnantajan ja tilaajan välisen sopimuksen luonteen, työn suorittamista kohtaavien ulkoisten esteiden, käsittelyissä käytettäville tuotteille soveltumattomien olosuhteiden, työkohteen pienen koon taikka muiden vastaavien syiden johdosta. Työkohdetta pidetään edellä tarkoitetulla tavalla pienenä, mikäli suoritettavan työn voidaan olettaa kestävän vähemmän kuin yhden työpäivän ajan. Osapuolten tulee yhteisesti todeta edellä tarkoitetun urakkatyön esteen olemassaolo ennen työn muutoin kuin urakkatyönä tapahtuvaa suorittamista.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
3. Urakkatyötä koskeva sopimus
1. Työsopimuksen osapuolet solmivat kustakin urakkatyökohteesta erikseen kirjallisen sopimuksen, josta tulee ilmetä
kohteen osoitetiedot,
kohteen laajuus
hinnoitteluperuste; työehtosopimuksen urakkahinnoittelu tai sen sijasta sovellettavaksi sovittu urakkahinnoittelun vähimmäistason täyttävä muu hinnoitteluperuste yksikkö- tai kokonaishinnoin
työn valmistumiselle asetettu tavoiteaika.
2. Urakkatyötä koskevassa sopimuksessa tai siihen liitettävään erilliseen asiakirjaan sisältyvässä työselityksessä tulee määritellä käsiteltävät rakennusosat sekä niiden osalta suoritettavat käsittelyt.

4. Työntekijä on oikeutettu saamaan TES 36 § 3. kappaleen määräyksen mukaista palkkaa siihen saakka, kunnes hänelle on annettu 1. kappaleessa mainittu kirjallisessa muodossa oleva työselitys, mikäli työselityksen puuttuminen on estänyt urakkatyön suorittamisen.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
6. Urakkatyön suorittaminen
1. Urakkatyötä koskevan sopimuksen käsittämät työt suorittaa se työntekijä tai ne urakkakunnan työntekijät, joiden kanssa työstä on sovittu.
2. Työnantajalla on kuitenkin sovittuaan asiasta ensin työntekijän tai urakkatyökunnan etumiehen kanssa oikeus tarvittaessa lisätä työvoimaa urakkatyökohteeseen.
7. Urakkatyöstä luopuminen
1. Työntekijä ja työkunta eivät ole oikeutettuja luopumaan urakasta ennen sen valmistumista ilman työnantajan suostumusta.
2. Mikäli työntekijä tai työkunta ilman työnantajan suostumusta luopuu urakasta kieltäytymällä suorittamasta urakkatyötä koskevan sopimuksen sisältämiä töitä loppuun, määräytyvät työntekijän ja vastaavasti kunkin työkunnan jäsenenä olleen työntekijän menettelyn seuraukset työsopimuslain työvelvoitteen laiminlyöntiä koskevien määräysten mukaan.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
14. Työn laatu
1. Työntekijän tulee urakkatyötä suorittaessaan noudattaa urakkatyökohdetta koskevan työselityksen käsittelyjä koskevia määräyksiä.
2. Työntekijän tulee välittömästi ilmoittaa työnantajalle tai tämän edustajalle, mikäli hän havaitsee jonkin seikan, joka vaarantaa työlle edellytetyn laatutason saavuttamisen tai sen valmistumisen urakkatyötä koskevassa sopimuksessa mainittuun tavoiteaikaan mennessä.
3. Työnantajan tulee tehdä työselityksen noudattamista tai työn laatua koskevat huomautuksensa kirjallisesti tai muutoin todisteellisesti asiaa koskevan puutteen tai virheen havaittuaan.
4. Työnantaja ei myöhemmin ole oikeutettu vetoamaan työssä olevaan puutteeseen tai virheeseen, joka on laadultaan niin ilmeinen, että työnantajan on täytynyt se havaita työn kuluessa suorittamassaan valvonnassa.
5. Työnantajan tulee tehdä urakkatyön suorittamista koskevat muistutuksensa viimeistään urakan mittaus- tai ennakkomittauksen tarkistustilaisuudessa.
15. Työn mittaus ja ennakkomittauksen tarkistaminen
1. Urakan mittaus suoritetaan, kun urakkatyötä koskevassa sopimuksessa tarkoitettu työ on kokonaisuudessaan valmis.
2. Työnantajalla on lisäksi oikeus määrätä välimittauksen toimittamisesta urakan kestäessä. Yli kuukauden kestävissä urakoissa on suositeltavaa, että välimittauksia suoritetaan noin kuukauden välein sopivien työvaiheiden valmistuttua. Välimittaukseen sovelletaan urakan mittausta, urakka-ansion laskemista ja urakka-ansion maksua koskevia määräyksiä.
3. Mikäli työnantaja on ennen työn suorittamista luovuttanut työntekijälle tai työkunnalle laskelman urakan käsittämien urakkahinnoittelun mukaisten yksiköiden lukumäärästä ja niihin perustuvasta urakka-ansiosta (urakkasummasta), ei mittausta suoriteta. Edellä mainitun estämättä työntekijä tai työkunta on kuitenkin työn valmistuttua oikeutettu vaatimaan ennakkomittauksen tarkistamista urakan mittausta koskevien määräysten mukaan.
4. Urakan mittaus tai ennakkomittauksen tarkistaminen on suoritettava työnantajan ja työntekijän tai työkunnan työntekijöiden kanssa ennakolta sovittuna aikana mahdollisimman pian, viimeistään 4 päivän kuluessa urakkatyötä koskeneen sopimuksen käsittämien töiden valmistumisesta.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
7. Mittauksesta laaditaan kahtena kappaleena pöytäkirja, jonka mittaustilaisuudessa saapuvilla olleet osapuolet allekirjoittavat.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
16. Urakka-ansion laskeminen
1. Kun urakkahinnoittelun mukaisten yksiköiden lukumäärät on edellä 15. kohdassa tarkoitetulla tavalla mitattu, lasketaan urakka-ansio kertomalla hinnoittelun mukaisten yksiköiden lukumäärä ao. työlajille vahvistetulla yksikköhinnalla.
2. Edellä tarkoitettu laskelma tulee laatia yhden viikon kuluessa työn valmistumisesta.
3. Urakka-ansion laskeneen osapuolen tulee luovuttaa laskelman toinen kappale allekirjoituksellaan varustettuna toiselle osapuolelle.

KANNE
Vaatimukset
Rakennusliitto on vaatinut ensisijaisesti vahvistettavaksi, että C:n tekemä työ on ollut aikapalkkatyötä ja että Maalausliike Pöntinen Ky on rikkonut maalausalan työehtosopimuksen määräyksiä jättäessään työehtosopimuksen edellyttämät ylitöiden korotusosat maksamatta, alentaessaan C:n sovittua tuntipalkkaa ja kuitattuaan C:n palkkaa perusteettomasti, mistä johtuen C:llä on oikeus työehtosopimukseen perustuviin 2 447,97 euron korvauksiin laillisine viivästyskorkoineen 15.3.2002 lukien.
Mikäli C:n tekemä työ katsotaan urakkatyönä tehdyksi, Rakennusliitto on vaatinut toissijaisesti vahvistettavaksi, että Maalausliike Pöntinen Ky on rikkonut maalausalan työehtosopimusta jättämällä maksamatta työehtosopimuksen 11 §:n mukaiset ylityökorvaukset, laiminlyömällä urakkatyötä koskevia määräyksiä ainakin urakkatyön suorittamista, mittausta ja urakka-ansion maksamista koskevien yleismääräysten 3. kohdan osalta jättämällä tekemättä kirjallisen sopimuksen väittämästään urakkatyöstä sekä laiminlyömällä edellä mainittujen yleismääräysten kohdissa 15. ja 16. asetettuja velvoitteita, jotka koskevat työn mittausta ja ennakkomittauksen tarkistamista, urakka-ansion laskemista sekä alentamalla sovittua tuntipalkkaa ja kuittaamalla työntekijän palkkaa ilman urakkamääräysten kohdassa 18.2. tarkoitettua urakka-ansiota koskevaa laskelmaa ja että yhtiö on velvollinen maksamaan C:lle edellä mainitut palkkasaatavat.
Rakennusliitto on vaatinut Maalausliike Pöntinen Ky:n tuomitsemista työehtosopimuslain 7 §:n nojalla hyvityssakkoon työehtosopimuksen tieten rikkomisesta sekä Suomen Maalarimestariliiton tuomitsemista työehtosopimuslain 8 ja 9 §:n nojalla valvontavelvollisuuden laiminlyönnistä hyvityssakkoon.
Rakennusliitto on lisäksi vaatinut Suomen Maalarimestariliiton, Maalausliike Pöntinen Ky:n ja sen vastuunalaisten yhtiömiesten A:n ja B:n velvoittamista yhteisvastuullisesti korvaamaan Rakennusliiton oikeudenkäyntikulut laillisine viivästyskorkoineen kuukauden kuluttua tuomion antopäivästä.

Perusteet
Maalausliike Pöntinen ja C olivat 2.1.2002 tehdyllä kirjallisella työsopimuksella sopineet työsuhteessa noudatettavaksi maalausalan työehtosopimuksen mukaisia tuntipalkkoja mahdollisine lisineen. C:lle oli maksettu 10,93 euroa tunnilta 11.2.2002 saakka, jolloin työnantaja oli alentanut palkan 8,29 euroon tunnilta. Palkan alentaminen oli tehty Horisontti -nimisellä työmaalla. C:lle ei ollut annettu työmaan mahdollista urakkaa koskevaa työselitystä eikä hän myöskään ollut omalta osaltaan tehnyt minkäänlaista urakkasopimusta. C:n tullessa työmaalle muut maalarit olivat tehneet jo yli puolet mahdollisesta urakasta, eikä C:llä siten ollut ollut mahdollisuutta vaikuttaa urakan menestymiseen.
C oli tehnyt edellä mainitulla työmaalla ylitöitä, joista hänelle ei ollut maksettu ylityökorvauksia. Työnantajapuolen mukaan kysymyksessä oli ollut vapaaehtoinen varsinaisen työajan ulkopuolella tapahtunut työskentely, josta ei tarvinnut maksaa korvausta.
Työehtosopimuksen urakkatyötä koskevien määräysten tarkoituksena on varmistaa se, että sovitusta urakkatyöstä olisi olemassa kirjallinen dokumentti, josta voitaisiin jälkikäteen selvittää urakkasopimuksen sisältö sovittuine töineen sekä työstä maksettava korvaus. Urakkamääräykset asettavat työnantajalle velvoitteen järjestää tarvittavat mittaukset, jotta urakan antama ansio olisi todettavissa riidattomasti. Työnantajalla on myös velvollisuus neuvotella työntekijän kanssa tilanteissa, joissa urakkaan kesken sen suorittamisen otetaan uusia työntekijöitä.
Koska C ei ollut ollut osallisena minkäänlaisessa urakkasopimuksessa, ei hänen tekemäänsä työtä voida katsoa urakalla tehdyksi varsinkaan, kun työnantaja puuttuvan urakkasopimuksen lisäksi oli jättänyt antamatta kaikki muutkin urakkatyössä tarvittavat asiakirjat kuten urakan loppuselvityksen sekä selvityksen tehdyksi väitetystä välimittauksesta. Työnantaja oli vedonnut urakan laatuvirheisiin, mutta pyynnöistä huolimatta työnantaja ei ollut antanut mitään selvitystä mahdollisista puutteista.
C:lle olisi tullut maksaa 504 tunnilta peruspalkkaa yhteensä 5 514,72 euroa (480 h x 10,93 euroa sekä 24 h x 11,18 euroa) sekä ylitöistä 1 584,85 euroa. Työnantajan olisi tullut maksaa näistä palkkamääristä lisäksi työajan lyhennysrahaa 255,58 euroa ja lomarahaa 1 360,70 euroa eli yhteensä 8 895,92 euroa. Työnantaja oli maksanut C:lle kuitenkin vain 6 447,95 euroa, mikä johtui siitä, että työnantaja oli jättänyt maksamatta työehtosopimuksen edellyttämät ylityökorvaukset sekä kuitannut työehtosopimuksen vastaisesti C:lle jo maksettuja palkkoja urakkaennakkoa alentamalla.
Muun muassa yrityksessä 20.3.2002 pidetyssä neuvottelussa Maalausliike Pöntinen Ky:tä oli vaadittu korjaamaan työehtosopimuksen vastainen menettely. Työnantaja ei ollut kuitenkaan suostunut maksamaan puuttuvia palkkoja.
Rakennusliiton ja Suomen Maalarimestariliiton välillä palkkauksesta syntyneestä erimielisyydestä oli neuvoteltu 31.5.2002. Suomen Maalarimestariliitto oli tukenut työnantajan menettelyä toteamalla, että kysymys oli ollut urakkatyöstä ja että palkan alentaminen oli perustunut työntekijän urakkatyön laadullisiin ja määrällisiin puutteisiin ja että ylityökorvauksia koskeva vaatimus oli perusteeton. Työnantajan selvistä työehtosopimusrikkomuksista huolimatta Suomen Maalarimestariliitto oli tukenut työnantajan toimintaa ja näin ollen laiminlyönyt valvontavelvollisuutensa.

VASTAUS
Vastaus kannevaatimuksiin
Suomen Maalarimestariliitto ja Maalausliike Pöntinen Ky ovat vastauksessa, johon kommandiittiyhtiön vastuunalaiset yhtiömiehet A ja B ovat osaltaan yhtyneet, kiistäneet kanteen ja vaatineet sen hylkäämistä.
Vastaajat ja kuultavat ovat lisäksi vaatineet Rakennusliiton velvoittamista korvaamaan vastaajien ja kuultavien oikeudenkäyntikulut laillisine viivästyskorkoineen kuukauden kuluttua tuomion antopäivästä lukien.

Kanteen kiistämisen perusteet
C:n työsuhteen aikana hänelle oli jokaisessa palkkalaskelmassa yli kahden kuukauden ajan maksettu urakkatuntipalkkaa urakkaennakon nimellä. C oli riitauttanut palkkausperusteen vasta irtisanouduttuaan 15.3.2002.
Työtä aloitettaessa urakkatyöstä oli sovittu suullisesti. Kirjallisen työselityksen puuttuminen ei estänyt urakkatyön tekemistä. Koska C:n urakka oli jäänyt kesken johtuen hänen omasta päätöksestään irtisanoutua yhtiön palveluksesta, työnantajalla ei ollut ollut velvollisuutta laatia pöytäkirjaa urakan mittauksesta. Myös kohteen muut työntekijät olivat pääsääntöisesti työskennelleet urakalla. C:lle oli palkkajaksossa 28.1. - 8.2.2000 maksettu niin sanottua pohjarahaa 57,18 euroa. Pohjarahaa maksetaan urakkatyöstä ja siitäkin vain silloin, kun ansaittu urakkasumma on suurempi kuin maksetut urakkaennakot.
Kun otetaan huomioon rakennusalan muuttuvat ja ajoittain hyvin nopeatahtiset työmaaolot sekä alan tavanomainen käytäntö tehdä urakkasopimukset suullisesti, ei työehtosopimuksen kirjallista urakkasopimusta ja työselitystä koskevia määräyksiä voida pitää sellaisina itsenäisesti sovellettavina työehtosopimusmääräyksinä, joiden laiminlyönti yksin muodostaisi työehtosopimuksen rikkomisen. Määräys urakoiden kirjallisista sopimisista on tarkoitettu selventämään urakkasopimuksia, eikä kirjallisen muotovaatimuksen täyttämättä jättäminen yksistään aiheuta työntekijälle oikeudenmenetystä.
Työnantaja oli toistuvasti huomauttanut C:tä työn virheistä ja puutteista. C oli laiminlyönyt ilmoitusvelvollisuutensa urakkansa laadun ja aikataulun vaarantumisesta. Urakan alkupuolella työnantaja oli maksanut C:lle 10,93 euroa tunnilta urakkaennakkoa. Palkkajaksossa 11.2. - 22.2.2002 työnantaja oli muuttanut C:n urakkaennakon 8,29 euroksi, mutta palkkajaksolla 11.3. - 22.3.2002 C:n urakkaennakko oli nostettu 8,54 euroon. Kuittaus oli johtunut siitä, että C:n urakka-ansio oli muun muassa työn hitauden, virheiden ja puutteiden vuoksi alittanut hänelle maksetut urakkaennakot. C:n palkka ei ollut alittanut työehtosopimuksen edellyttämää vähimmäistasoa. C:n työsopimuksessa oli sovittu työehtosopimuksen mukaisesta tuntipalkasta, joka oli ollut 8,29 euroa.
Urakkatyötä koskevia muotomääräyksiä on pidetty tavallaan menettelytapaohjeina, joilla pyritään ehkäisemään erimielisyyksiä. Muotomääräysten noudattamatta jättäminen ei vielä muodosta työehtosopimuksen rikkomista. Koska C oli tehnyt urakkatyötä ja koska työnantaja oli menetellyt työehtosopimuksen mukaisesti, ei myöskään Suomen Maalarimestariliitto ollut laiminlyönyt valvontavelvollisuuttaan.

TYÖTUOMIOISTUIMEN RATKAISU
Perustelut
Tapahtumat ja erimielisyys
C on työskennellyt Maalausliike Pöntinen Ky:n palveluksessa maalarina 2.1. - 15.3.2002. Kirjallisessa työsopimuksessa palkkauksessa on sovittu noudatettavaksi työehtosopimuksen mukaisia tuntipalkkoja mahdollisine lisineen. Työsuhteensa aikana C on työskennellyt pääkaupunkiseudulla muun muassa Mainari-, Horisontti- ja Taiteilijatalo -nimisissä työkohteissa.
C:lle on maksettu urakkaennakon nimellä 10,93 euron suuruista tuntipalkkaa 11.2.2002 saakka, jonka jälkeen työnantaja on muuttanut urakkaennakon määräksi 8,29 euroa tunnilta. Urakkaennakon määrä on 11.3.2002 alkaneen palkkajakson alusta korotettu 8,54 euroon. C:lle on maksettu niin sanottua pohjarahaa palkkajaksossa 28.1. - 8.2.2002. C:n työsuhteensa aikana tekemiltä ylityötunneilta työnantaja on maksanut hänelle perustuntipalkan ja osalta ylityötunneilta työehtosopimuksen mukaiset ylityökorotukset.
Asianosaisten välillä vallitsee ensiksi erimielisyys siitä, onko C:n kanssa sovittu urakkatyön tekemisestä vai onko kysymyksessä ollut aikatyö. Toiseksi asianosaisten välillä vallitsee erimielisyys siitä, onko C:llä oikeus työehtosopimuksen mukaisiin ylityökorotuksiin kaikilta tekemiltään ylityötunneilta. Kolmanneksi asianosaisten välillä vallitsee erimielisyys siitä, onko työnantajalla ollut oikeus alentaa C:lle maksettavan tuntipalkan määrää 11.2.2000 alkaen C:n työn laatuun vedoten.
Esitetty näyttö
Työtuomioistuimessa on kuultu todistelutarkoituksessa C:tä ja Maalausliike Pöntinen Ky:n toimitusjohtajaa A:ta, jotka ovat kertoneet työstä ja palkasta sopimisesta, ylitöiden tekemisestä ja työn laadusta. Muun muassa työehtosopimuksen urakkatyömääräysten tulkinnasta työtuomioistuimessa on kuultu todistajina Rakennusliiton työehtosihteeriä D:tä ja Suomen Maalarimestariliiton entistä toimitusjohtajaa, työmarkkinajohtajaa E:tä. Lisäksi C:n työn laadusta on kuultu todistajana työnjohtaja F:ää.
Kirjallisina todisteina kummaltakin puolen on esitetty C:n palkkalaskelmia ja tunti-ilmoituksia sekä työnantajan puolelta lisäksi urakan jakolistoja, luovutuskortteja ja valvojan puutelista.
Urakka- vai aikatyö
D:n mukaan vuoden 2003 alkuun asti maalausalan työehtosopimuksen määräykset ovat edellyttäneet, että työt tehdään urakkatyönä urakkahinnoittelun mukaisesti, mikäli esteitä urakkatyön tekemiselle ei ole. Maalausalalla työtä tehdään ainoastaan sopimustuntipalkalla tai urakkapalkalla. Palkkaustavasta sovitaan ennen työn aloittamista. Jos työ sovitaan urakalla tehtäväksi, tulee työehtosopimuksen mukaan laatia kirjallinen urakkasopimus. Työnantajan tulee antaa työntekijöille myös kirjallinen työselitys, jossa on selvitetty urakkaan kuuluvat työt. Maalausliike Pöntinen Ky:tä lukuun ottamatta käytäntö maalausalalla on D:n mukaan ollut se, että urakkasopimukset tehdään kirjallisesti.
E:n mukaan maalausalan työehtosopimuksen urakkamääräysten mukainen pääsääntö on ollut, että työt tehdään urakalla. Jos urakkahinnasta ei päästä sopimukseen, työ tehdään työehtosopimuksen mukaista urakkahinnoittelua noudattaen. Käytännössä joissakin alan yrityksissä urakkasopimukset tehdään aina kirjallisesti, mutta suurimmassa osassa yrityksiä urakkasopimukset tehdään suullisesti. Kirjallisen urakkatyösopimuksen tekemistä koskeva määräys on otettu työehtosopimukseen Rakennusliiton aloitteesta vuonna 1994. Tätä ennen työehtosopimus on edellyttänyt vain kirjallisen työselityksen tekemistä.
C on kertonut ennen työsuhteensa alkamista olleensa puhelimitse yhteydessä toimitusjohtaja A:han, jonka kehotuksesta hän on ottanut yhteyttä Horisontti -työmaan työnjohtajana toimineeseen G:hen. C on tiedustellut kummaltakin mahdollisuutta saada tehtäväksi urakkatyötä. Molemmat ovat ilmoittaneet, että tätä voidaan harkita myöhemmässä vaiheessa. Palkan määrästä ei kummankaan työnantajan edustajan kanssa ole keskusteltu. Työhöntulovaiheessa G on mahdollisesti ilmoittanut, että Horisontti -työmaalla tehdään urakkaa. Urakkasummasta tai urakkaan mahdollisesti kuuluvista töistä ei tuossa vaiheessa ole ollut puhetta eikä myöskään siitä, ovatko työmaalla jo aikaisemmin työssä olleet työntekijät mukana urakassa. C:n näkemyksen mukaan Horisontti -työmaalla ei olisi ollut mahdollisuutta tehdä urakkatyötä, koska työtä on joutunut tekemään kierrellen eri puolilla työkohdetta.
A:n mukaan C:tä palkattaessa on sovittu töiden tekemisestä urakkatyönä. Tästä on sovittu vielä erikseen C:n aloittaessa työskentelyn. Horisontti -työmaan urakasta sopimiseen C ei ollut osallistunut, vaan tästä oli sovittu aikaisemmin kahden työntekijän muodostaman työkunnan kanssa. C oli lisätty urakkatyökuntaan, koska alkuperäinen työkunta ei ollut pysynyt aikataulussa. C ei ollut työtä aloittaessaan ilmoittanut, että urakkatyön tekemiselle olisi esteitä. C:lle on kahdesta eri työvaiheesta maksettu myös pohjarahaa.
Työtuomioistuimelle jätetystä C:n aikaa 14.1. - 27.1.2002 koskevasta tunti-ilmoituksesta käy ilmi, että C on pyytänyt ilmoituksessa mainitsemistaan töistä pohjat maksuun. Seuranneen helmikuun 15. päivänä tapahtuneen palkanmaksun yhteydessä C:lle on maksettu pohjarahaa 57,18 euroa.
C:n ja työnantajan välillä ei ole ennen työn tekemisen aloittamista tai muussakaan vaiheessa työsuhteen kestäessä todettu, että edellytyksiä urakkatyön tekemiselle ei ole. C:n omasta kertomuksesta on käynyt ilmi, että hän on työnantajalle nimenomaisesti ilmoittanut toivovansa urakkatyöhön pääsemistä. Myöskään työsuhteensa kestäessä C ei ole ilmoittanut työnantajalle kantaansa, jonka mukaan hänen tekemänsä työ tulisi katsoa aikatyöksi. Siihen, että työ on sovittu tehtäväksi urakkatyönä, viittaa myös se, että C on tunti-ilmoituksessa pyytänyt pohjarahojen maksamista ja että hänelle yhden palkanmaksun yhteydessä on maksettu pohjarahaa. Edellä esitetyillä perusteilla työtuomioistuin katsoo, että C:n työ on ollut urakkatyötä.
Ylityöt
A:n mukaan C:tä ei ollut pyydetty tekemään ylitöitä. Siinä vaiheessa kun työnantaja oli C:n tunti-ilmoituksista todennut C:n tehneen työtä myös viikonloppuisin, C:tä oli nimenomaisesti kielletty tekemästä ylitöitä. C:n tunti-ilmoitukseen merkitsemiltä ylityötunneilta työnantaja on maksanut myös ylityön korotusosat siihen asti, kunnes kielto tehdä ylitöitä oli annettu. Rakennuttajan edustaja ei A:n mukaan ole voinut pyytää C:tä ylitöihin. A:lla on kertomansa mukaan tapana viedä tarvikkeita työkohteisiin aina niissä käydessään. Kaivokselassa sijainneeseen työkohteeseen hän oli saattanut viedä maalia myös viikonlopputyöskentelyä varten.
Vaikka työnantaja ei ole nimenomaisesti hyväksynyt C:n tunti-ilmoitukseen merkittyjä ylityötunteja ylityöksi, työnantaja on kuitenkin esitetyn selvityksen mukaan maksanut näiltä säännöllisen työajan ulkopuolelta tehdyiltä työtunneilta sovitun tuntipalkan. Kun työnantaja siten on katsonut C:n tehneen nämä työtunnit eikä työnantaja ole kiistänyt sitä, etteivätkö tunnit sinänsä olisi ylityötä, on C:llä oikeus kanteessa vaadittuihin ylitöihin liittyviin korvauksiin.
Palkkaennakon alentaminen ja kuittaus
C:lle aikaisemmin urakkaennakkona maksetun tuntipalkan alentamisen perusteeksi työnantaja on ilmoittanut C:n työn laadussa olleet puutteet sekä aikataulun vaarantamisen. Selvitykseksi työn laadussa olleista puutteista työnantajapuolelta on esitetty muun muassa Horisontin työkohteessa 24.1.2002 suoritettuun katselmukseen perustuva mallihuonetta koskeva laatusuunnitelma ja tähän liittyvä päiväämätön valvojan puutelista. Laatusuunnitelmaan kirjatun mukaan katselmukseen ovat osallistuneet urakoitsijan edustaja ja työnjohtaja G. Kirjallisiksi todisteiksi C:n työssä olleista puutteista työnantajapuolelta on lisäksi jätetty edellä mainittua työmaata koskevia 12.3.2002 päivättyjä luovutuskortteja sekä urakka-ansioiden ja työmaa-aikataulun toteutumista koskevat graafiset selvitykset.
C:n mukaan hänelle ei ole missään vaiheessa työsuhteen aikana huomautettu puutteista työssä. A:n mukaan C:n työn laadussa on ollut sellaisia huolimattomuusvirheitä, joita ei normaalissa maalaustyössä hyväksytä. C:n ja hänen työryhmänsä työn virheet käyvät ilmi luovutusta varten laadituista asiakirjoista.
D:n mukaan edellä mainituista asiakirjoista ilmenevät puutteet eivät poikkea siitä, mikä on käytännössä normaalia vastaavalla työmaalla. Koska työmaalla on C:n lisäksi työskennellyt useita muita maalareita, ei virheitä voida myöskään kohdistaa C:n työhön. D on edelleen kertonut, että työehtosopimuksen mukaan työnantajalla ei enää urakkaa laskettaessa ja mitattaessa ole oikeutta alentaa palkkaa työn laatuvirheiden perusteella, jotka olisi pitänyt heti huomata. Liikaa maksetun palkan alentaminen on mahdollista tehdä myöhemmissä tilivaiheissa, jos molemmat osapuolet ovat aiemmassa mittauksessa hyväksyneet, että maksetut ennakot ovat ylittäneet sovitun urakan. Myös todistaja E on kertonut oikean menettelyn olevan, että havaittaessa työn laadun vaarantuvan asia käydään työntekijän kanssa läpi ja oikaistaan liian suureksi sovittua urakkasummaa. Yksipuolisenkin kuittauksen on perustuttava välimittaukseen.
Edellä esitetty selvitys osoittaa maalaustyössä kysymyksessä olevassa työkohteessa olleen puutteita. Koska kysymyksessä olevassa työkohteessa on C:n lisäksi ollut työssä myös muita työntekijöitä, ei esitetyn selvityksen perusteella voida työtuomioistuimen mielestä yksilöidä, että virheet ja puutteet johtuisivat yksistään ja nimenomaan C:n työn laadusta.
Palkkasaatavien määrä
Asianosaiset ovat pääkäsittelyssä olleet yhtä mieltä siitä, että mikäli C:n työ katsotaan tehdyksi aikatyönä, on C:llä oikeus yhteensä 2 447,97 euron palkkasaataviin. Koska yksimielisyyden ei ole ilmoitettu koskevan palkkasaatavien määrää myös siinä tapauksessa, että C:n työ katsotaan urakkatyöksi, työtuomioistuin katsoo, että suoritusvelvollisuuden riitaiseksi jäänyttä määrää ei voida ratkaista tässä yhteydessä.
Työehtosopimuksen vastainen menettely
Maalausliike Pöntinen Ky on rikkonut tietensä työehtosopimusta jättäessään tekemättä urakkahinnoittelun yleismääräysten 3. kohdassa tarkoitetut kirjalliset urakkatyösopimukset ja jättäessään maksamatta C:lle ylitöiden korotukset sekä laiminlyödessään yleismääräysten 15. ja 16. kohdissa tarkoitetun työn mittauksen ja urakka-ansion laskemisen.
Kun asia tapahtumien osalta on ollut varsin epäselvä ja selvitystä asiaan on saatu vasta oikeudenkäynnin aikana, ei Suomen Maalarimestariliiton työnantajan menettelyn hyväksyessään voida katsoa syyllistyneen asiassa valvontavelvollisuuden laiminlyöntiin.
Oikeudenkäyntikulut
Jutun hävitessään Maalausliike Pöntinen Ky ja sen vastuunalaiset yhtiömiehet A ja B ovat velvolliset korvaamaan Rakennusliiton oikeudenkäyntikulut. Oikeudenkäyntikulujen määräksi Rakennusliitto on tässä sekä tämän asian kanssa yhtäaikaa käsitellyissä kahdessa muussa asiassa (R 50 ja 51/03) ilmoittanut 5 865 euroa, mitä työnantajapuoli on paljoksunut. Ottaen huomioon asioiden laatu on kuluerittelyssä yksilöityjä toimenpiteitä pidettävä asioiden hoitamiseksi tarpeellisina ja niistä samoin kuin asian selvittämisestä muutoin aiheutuneita kustannuksia kohtuullisina.
Asian laatu ja sen lopputulos huomioon ottaen saa Suomen Maalarimestariliitto vastata omista oikeudenkäyntikuluistaan.

Tuomiolauselma
Työtuomioistuin vahvistaa, että Maalausliike Pöntinen Ky on rikkonut maalausalan työehtosopimusta jättäessään maksamatta C:lle työehtosopimuksen 11 §:n mukaiset ylityökorvaukset sekä laiminlyödessään kirjallisten urakkatyösopimusten tekemisen ja urakkatyön mittaamisen ja urakka-ansion laskemisen.
Työtuomioistuin tuomitsee työehtosopimuslain 7 ja 10 §:n nojalla Maalausliike Pöntinen Ky:n maksamaan työehtosopimuksen tieten rikkomisesta hyvityssakkoa Rakennusliitolle 2 000 euroa.
Työtuomioistuimesta annetun lain 1 §:n 2 momentin nojalla työtuomioistuin osoittaa asianosaiset tarvittaessa ajamaan kannetta C:n palkkasaatavien määrästä toimivaltaisessa käräjäoikeudessa.
Maalausliike Pöntinen Ky ja sen vastuunalaiset yhtiömiehet A ja B velvoitetaan yhteisvastuullisesti korvaamaan Rakennusliiton oikeudenkäyntikulut 5 865 eurolla, jolle on maksettava viivästyskorkoa korkolain 4 §:n 1 momentissa tarkoitetun korkokannan mukaan siitä lähtien, kun kuukausi on kulunut työtuomioistuimen tuomion antopäivästä.
Suomen Maalarimestariliitto saa pitää oikeudenkäyntikulunsa vahinkonaan.
Kanne enemmälti hylätään.
Asian ratkaisemiseen ovat osallistuneet Saloheimo puheenjohtajana sekä Äimä, Niskanen, Lindahl, Palomäki ja Kolula jäseninä. Sihteeri on ollut Laurila.
Tuomio on yksimielinen.

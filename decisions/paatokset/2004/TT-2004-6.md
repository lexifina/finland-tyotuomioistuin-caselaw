# TT:2004-6

## Suomeksi

Kanteessa tarkoitettu maalarin työ katsottiin tehdyksi urakkatyönä. Työnantaja oli rikkonut tietensä työehtosopimuksen urakkahinnoittelua koskevia määräyksiä laiminlyödessään kirjallisen urakkasopimuksen tekemisen ja alentaessaan urakan kestäessä työn laatuun ja työvauhtiin vedoten urakkaennakon määrää ilman, että se olisi perustunut työn mittaamiseen ja urakka-ansion laskemiseen.
Työnantajaliitto ei ollut laiminlyönyt valvontavelvollisuuttaan.

TYÖEHTOSOPIMUKSEN MÄÄRÄYKSET
Asianosaisliittojen välillä 21.12.2000 allekirjoitetun maalausalan työehtosopimuksen urakkahinnoittelussa on muun ohella seuraavat määräykset:
RAKENNUSTEN PINTAKÄSITTELYN URAKKAHINNOITTELU
URAKKATYÖN SUORITTAMISTA, MITTAUSTA JA URAKKA-ANSION MAKSAMISTA KOSKEVAT YLEISMÄÄRÄYKSET
1. Urakkatyö
1. Kaikki hinnoittelussa mainitut työt suoritetaan urakkatyönä.
2. Työ suoritetaan kuitenkin aina aikapalkalla, mikäli edellytyksiä urakkatyön suorittamiselle ei ole olemassa työnantajan ja tilaajan välisen sopimuksen luonteen, työn suorittamista kohtaavien ulkoisten esteiden, käsittelyissä käytettäville tuotteille soveltumattomien olosuhteiden, työkohteen pienen koon taikka muiden vastaavien syiden johdosta. Työkohdetta pidetään edellä tarkoitetulla tavalla pienenä, mikäli suoritettavan työn voidaan olettaa kestävän vähemmän kuin yhden työpäivän ajan. Osapuolten tulee yhteisesti todeta edellä tarkoitetun urakkatyön esteen olemassaolo ennen työn muutoin kuin urakkatyönä tapahtuvaa suorittamista.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
3. Urakkatyötä koskeva sopimus
1. Työsopimuksen osapuolet solmivat kustakin urakkatyökohteesta erikseen kirjallisen sopimuksen, josta tulee ilmetä
kohteen osoitetiedot,
kohteen laajuus
hinnoitteluperuste; työehtosopimuksen urakkahinnoittelu tai sen sijasta sovellettavaksi sovittu urakkahinnoittelun vähimmäistason täyttävä muu hinnoitteluperuste yksikkö- tai kokonaishinnoin
työn valmistumiselle asetettu tavoiteaika.
2. Urakkatyötä koskevassa sopimuksessa tai siihen liitettävään erilliseen asiakirjaan sisältyvässä työselityksessä tulee määritellä käsiteltävät rakennusosat sekä niiden osalta suoritettavat käsittelyt.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
4. Työntekijä on oikeutettu saamaan TES 36 § 3. kappaleen määräyksen mukaista palkkaa siihen saakka, kunnes hänelle on annettu 1. kappaleessa mainittu kirjallisessa muodossa oleva työselitys, mikäli työselityksen puuttuminen on estänyt urakkatyön suorittamisen.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
6. Urakkatyön suorittaminen
1. Urakkatyötä koskevan sopimuksen käsittämät työt suorittaa se työntekijä tai ne urakkakunnan työntekijät, joiden kanssa työstä on sovittu.
2. Työnantajalla on kuitenkin sovittuaan asiasta ensin työntekijän tai urakkatyökunnan etumiehen kanssa oikeus tarvittaessa lisätä työvoimaa urakkatyökohteeseen.
7. Urakkatyöstä luopuminen
1. Työntekijä ja työkunta eivät ole oikeutettuja luopumaan urakasta ennen sen valmistumista ilman työnantajan suostumusta.
2. Mikäli työntekijä tai työkunta ilman työnantajan suostumusta luopuu urakasta kieltäytymällä suorittamasta urakkatyötä koskevan sopimuksen sisältämiä töitä loppuun, määräytyvät työntekijän ja vastaavasti kunkin työkunnan jäsenenä olleen työntekijän menettelyn seuraukset työsopimuslain työvelvoitteen laiminlyöntiä koskevien määräysten mukaan.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
14. Työn laatu
1. Työntekijän tulee urakkatyötä suorittaessaan noudattaa urakkatyökohdetta koskevan työselityksen käsittelyjä koskevia määräyksiä.
2. Työntekijän tulee välittömästi ilmoittaa työnantajalle tai tämän edustajalle, mikäli hän havaitsee jonkin seikan, joka vaarantaa työlle edellytetyn laatutason saavuttamisen tai sen valmistumisen urakkatyötä koskevassa sopimuksessa mainittuun tavoiteaikaan mennessä.
3. Työnantajan tulee tehdä työselityksen noudattamista tai työn laatua koskevat huomautuksensa kirjallisesti tai muutoin todisteellisesti asiaa koskevan puutteen tai virheen havaittuaan.
4. Työnantaja ei myöhemmin ole oikeutettu vetoamaan työssä olevaan puutteeseen tai virheeseen, joka on laadultaan niin ilmeinen, että työnantajan on täytynyt se havaita työn kuluessa suorittamassaan valvonnassa.
5. Työnantajan tulee tehdä urakkatyön suorittamista koskevat muistutuksensa viimeistään urakan mittaus- tai ennakkomittauksen tarkistustilaisuudessa.
15. Työn mittaus ja ennakkomittauksen tarkistaminen
1. Urakan mittaus suoritetaan, kun urakkatyötä koskevassa sopimuksessa tarkoitettu työ on kokonaisuudessaan valmis.
2. Työnantajalla on lisäksi oikeus määrätä välimittauksen toimittamisesta urakan kestäessä. Yli kuukauden kestävissä urakoissa on suositeltavaa, että välimittauksia suoritetaan noin kuukauden välein sopivien työvaiheiden valmistuttua. Välimittaukseen sovelletaan urakan mittausta, urakka-ansion laskemista ja urakka-ansion maksua koskevia määräyksiä.
3. Mikäli työnantaja on ennen työn suorittamista luovuttanut työntekijälle tai työkunnalle laskelman urakan käsittämien urakkahinnoittelun mukaisten yksiköiden lukumäärästä ja niihin perustuvasta urakka-ansiosta (urakkasummasta), ei mittausta suoriteta. Edellä mainitun estämättä työntekijä tai työkunta on kuitenkin työn valmistuttua oikeutettu vaatimaan ennakkomittauksen tarkistamista urakan mittausta koskevien määräysten mukaan.
4. Urakan mittaus tai ennakkomittauksen tarkistaminen on suoritettava työnantajan ja työntekijän tai työkunnan työntekijöiden kanssa ennakolta sovittuna aikana mahdollisimman pian, viimeistään 4 päivän kuluessa urakkatyötä koskeneen sopimuksen käsittämien töiden valmistumisesta.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
7. Mittauksesta laaditaan kahtena kappaleena pöytäkirja, jonka mittaustilaisuudessa saapuvilla olleet osapuolet allekirjoittavat.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
16. Urakka-ansion laskeminen
1. Kun urakkahinnoittelun mukaisten yksiköiden lukumäärät on edellä 15. kohdassa tarkoitetulla tavalla mitattu, lasketaan urakka-ansio kertomalla hinnoittelun mukaisten yksiköiden lukumäärä ao. työlajille vahvistetulla yksikköhinnalla.
2. Edellä tarkoitettu laskelma tulee laatia yhden viikon kuluessa työn valmistumisesta.
3. Urakka-ansion laskeneen osapuolen tulee luovuttaa laskelman toinen kappale allekirjoituksellaan varustettuna toiselle osapuolelle.

= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
2. Mikäli urakkatyöhön kohdistuvat maksetut etumaksut ylittävät yhteismäärältään urakka-ansion määrän, on työnantaja oikeutettu kuittaamaan myöhempien palkanmaksujen yhteydessä työntekijälle liikaa maksamansa määrän, siltä osin kun se ylittää kyseisen työntekijän perustuntipalkan, noudattaen työsopimuslain työnantajan kuittausoikeutta koskevia säännöksiä. Työnantaja on lisäksi oikeutettu suorittamaan edellä tarkoitetun kuittauksen työntekijän lukuun tilittämistään lomarahoista työsopimuslain säännöksiä noudattaen.

KANNE
Vaatimukset
Rakennusliitto on vaatinut ensisijaisesti vahvistettavaksi, että C:n Maalausliike Pöntinen Ky:n palveluksessa tekemä työ on ollut aikapalkkatyötä ja että C:llä on oikeus maksamatta jätettyyn 951,67 euron palkkaan laillisine viivästyskorkoineen 17.5.2002 lukien.
Mikäli C:n tekemä työ katsotaan tehdyksi urakkatyönä, Rakennusliitto on vaatinut toissijaisesti vahvistettavaksi, että Maalausliike Pöntinen Ky on rikkonut maalausalan työehtosopimuksen urakkamääräyksiä muun muassa urakkatyön suorittamista, mittausta ja urakka-ansion maksamista koskevien yleismääräysten 3. kohdan osalta jättäessään tekemättä kirjallisen sopimuksen väittämästään urakkatyöstä sekä laiminlyömällä urakkahinnoittelun yleismääräysten kohdissa 15. ja 16. asetettuja velvoitteita, jotka koskevat työnmittausta ja ennakkomittauksen tarkistamista sekä urakka-ansion laskemista, ja että yhtiö on velvollinen maksamaan C:lle yllä mainitut palkkasaatavat.
Rakennusliitto on vaatinut Maalausliike Pöntinen Ky:n tuomitsemista työehtosopimuslain 7 §:n nojalla hyvityssakkoon työehtosopimuksen tieten rikkomisesta ja Suomen Maalarimestariliiton tuomitsemista työehtosopimuslain 8 ja 9 §:n nojalla hyvityssakkoon valvontavelvollisuuden laiminlyönnistä.
Rakennusliitto on vaatinut vastaajien ja kuultavien velvoittamista yhteisvastuullisesti korvaamaan Rakennusliiton oikeudenkäyntikulut laillisine viivästyskorkoineen kuukauden kuluttua tuomion antopäivästä lukien.

Perusteet
C oli työskennellyt Maalausliike Pöntinen Ky:n Espoossa sijaitsevalla Trillatori -nimisellä työmaalla. Työmaan alussa osapuolten välillä ei ollut päästy sopimukseen urakkahinnasta, minkä vuoksi työ oli sovittu tehtäväksi aikapalkalla. Aikapalkan suuruudeksi oli sovittu 11,77 euroa tunnilta. Työnantaja oli kuitenkin katsonut kysymyksessä olevan työn urakkatyöksi. Tehdyistä tunneista C:lle oli maksettu palkka urakkaennakon nimikkeellä. Näin työnantaja oli menetellyt useiden muidenkin työntekijöiden kohdalla, vaikka työtä ei olisikaan tehty urakalla. C ei ollut missään vaiheessa saanut työehtosopimuksen edellyttämää kirjallista urakkasopimusta, vaikka työnantajalla rakennusten pintakäsittelyn urakkahinnoittelua koskevien määräysten kohdan 3. mukaan olisi ollut velvollisuus tehdä urakkatyötä koskeva sopimus. Työnantajan edustaja A oli 14.10.2002 todennut, että kirjallista sopimusta urakasta ei ollut tehty.
Työnantaja oli yksipuolisesti välimittaukseen viitaten alentanut C:n palkkaa 25.3.2002 lukien 3,23 eurolla tunnilta. Kun C oli 8.5.2002 ilmoittanut työnantajalle, että hän ei hyväksy yksipuolista palkan alentamista, oli työnantaja samana päivänä tehdyksi merkityssä tarkastuksessa todennut puutteita työn laadussa. Palkan alentaminen oli kuitenkin toteutettu jo yli kuukautta aikaisemmin. C:llä ei ollut ollut tietoa järjestetystä välimittauksesta, eikä kirjallista selvitystä sellaisesta ollut toimitettu työntekijäpuolelle myöskään asiasta neuvoteltaessa. Urakan loppuselvityksen/jakolistan työnantaja oli työehtosopimusmääräysten vastaisesti tehnyt yksipuolisesti vasta 14.10.2002 eli noin neljä kuukautta työmaan valmistumisen jälkeen. Huomioon ottaen työnantajan edellä mainitut työehtosopimusrikkomukset ei työtä voida pitää urakkatyönä tehtynä. Tämän vuoksi myös palkan alentaminen on ollut perusteetonta. Työnantaja on siten velvollinen maksamaan C:lle saamatta jääneen palkan.
Työn suorittaminen urakkatyönä edellyttää aina sopimusta työn tekemisestä urakkatyönä. Koska C:n kanssa ei ollut tehty sopimusta urakkatyöstä, ei kysymys voinut olla urakkatyöstä vain sillä perusteella, että työnantaja näin väittää. Koska urakkatyöstä ei ollut tehty kirjallista urakkasopimusta, ei sopimukseen ollut voitu kirjata myöskään työselitystä, josta olisi käynyt ilmi käsiteltävät rakennusosat ja niiden osalta suoritettavat käsittelyt siten kuin työehtosopimus edellyttää. Nyt esillä olevassa tapauksessa tämä olisi ollut ehdottoman välttämätöntä jo siitäkin syystä, että kohteessa oli työskennellyt yli 10 muutakin maalaria C:n lisäksi.
Maalausliike Pöntinen Ky:tä oli vaadittu maksamaan puuttuvat saatavat muun muassa 14.10.2002 käydyissä neuvotteluissa. Työnantaja ei ollut kuitenkaan suostunut maksamaan puuttuvia palkkoja.
Rakennusliiton ja Suomen Maalarimestariliiton välillä asiasta oli neuvoteltu 18.10., 6.11. ja 5.12.2002 sekä 3.1.2003. Työnantajaliitto oli tukenut neuvotteluissa työnantajaa toteamalla, että kysymys oli ollut urakkatyöstä ja että palkan alentaminen oli perustunut työntekijöiden urakkatyön laadullisiin ja määrällisiin puutteisiin. Kun Suomen Maalarimestariliitto oli työnantajan selvistä työehtosopimusrikkomuksista huolimatta tukenut työnantajan menettelyä, oli työnantajaliitto laiminlyönyt valvontavelvollisuutensa.

VASTAUS
Vastaus kannevaatimuksiin
Suomen Maalarimestariliitto ja Maalausliike Pöntinen Ky ovat vastauksessa, johon kommandiittiyhtiön vastuunalaiset yhtiömiehet A ja B ovat osaltaan yhtyneet, kiistäneet kanteen ja vaatineet sen hylkäämistä.
Vastaajat ja kuultavat ovat vaatineet Rakennusliiton velvoittamista korvaamaan vastaajien ja kuultavien oikeudenkäyntikulut laillisine viivästyskorkoineen kuukauden kuluttua tuomion antopäivästä lukien.

Kanteen kiistämisen perusteet
C oli työskennellyt Maalausliike Pöntinen Ky:n uutena työntekijänä As Oy Trillatorin työmaalla 17.12.2001 lukien. C oli irtisanoutunut ennen urakan valmistumista.
Työsuhteensa aikana C oli muutamia tunteja lukuun ottamatta tehnyt urakkatyötä. Työsuhteen alkaessa työnantajan ja C:n välillä oli todettu, että urakkatyön suorittamiselle ei ollut estettä. Urakkatyöstä oli sovittu osapuolten välillä suullisesti. Kirjallisen työselityksen puuttuminen ei estänyt urakkatyön tekemistä. C:n työsuhteen aikana hänen jokaisessa palkkalaskelmassaan oli usean kuukauden ajan maksettu urakkatuntipalkka urakkaennakon nimellä. C:lle oli lisäksi maksettu niin sanottua pohjarahaa muun muassa palkkajaksossa 31.12.2001 - 11.1.2002. Pohjarahaa maksetaan tilanteessa, jossa urakan aikana maksetut urakkaennakot alittavat työntekijälle kertyneen urakka-ansion. Koska C:n urakka oli jäänyt kesken hänen irtisanouduttuaan, työnantajalla ei ollut ollut velvollisuutta laatia pöytäkirjaa urakan mittauksesta. C oli riitauttanut palkkausperusteen vasta irtisanouduttuaan. Rakennusliitto oli vasta 6.11.2002 käydyssä muistioneuvottelussa vedonnut siihen, että C oli tehnyt urakkatyön asemesta aikapalkkatyötä.
Työnantaja oli työsuhteen aikana huomauttanut C:tä ja hänen työtoveriaan sekä suullisesti että kirjallisesti heidän tekemänsä urakkatyön virheistä ja puutteista. Työntekijät olivat laiminlyöneet velvollisuutensa ilmoittaa välittömästi työnantajalle työssään ilmenneistä urakan laadun ja aikataulun vaarantavista virheistä ja puutteista. C oli työtoverinsa kanssa tehnyt urakkatyötä yhteisvastuullisesti samassa urakkatyökunnassa. C:n tekemän urakan vuoksi työnantaja oli kärsinyt vahinkoa ja joutunut teettämään urakan valmiiksi muilla työntekijöillä. Suomen Maalarimestariliiton edustaja ja työnantaja olivat valokuvanneet C:n urakan virheitä ja puutteita.
Työnantaja oli vähentänyt C:n urakkaennakkoja, koska hänelle aikaisemmissa palkkajaksoissa maksetut urakkaennakot olivat ylittäneet hänen urakka-ansionsa. Urakan alkupuolen palkkajaksoilla C:lle oli maksettu urakkaennakkona 11,77 euroa. Palkkajaksolla 25.3. - 5.4.2002 työnantaja oli vähentänyt C:n urakkaennakon 8,54 euroksi ja 8.4.2002 alkaneesta palkkajaksosta lukien työsuhteen loppuajaksi 8,29 euroksi. Kuten yrityksessä ja yleensäkin maalausalalla on asianlaita, oli C:n palkka urakkatyössä ollut selvästi korkeampi kuin se olisi ollut aikapalkkatyössä. C:n palkka ei ollut alittanut työehtosopimuksen edellyttämää vähimmäistasoa.
Kun otetaan huomioon rakennusalan muuttuvat ja ajoittain hyvin nopeatahtiset työmaaolot sekä alan tavanomainen käytäntö tehdä urakkasopimukset suullisesti, ei työehtosopimuksen kirjallisia urakkasopimuksia koskevia määräyksiä voida pitää sellaisina itsenäisesti sovellettavina työehtosopimusmääräyksinä, joiden laiminlyönti yksin muodostaisi työehtosopimuksen rikkomuksen. Määräyksellä urakoiden kirjallisesta sopimisesta on tarkoitettu selventää urakkasopimuksia eikä kirjallisen muotovaatimuksen täyttämättä jättäminen yksistään aiheuta työntekijälle oikeudenmenetyksiä. C:n työ oli ollut urakkatyötä ja työnantaja oli menetellyt asiassa työehtosopimuksen mukaisesti. Näin ollen ei myöskään Suomen Maalarimestariliitto ollut laiminlyönyt asiassa valvontavelvollisuuttaan.

TYÖTUOMIOISTUIMEN RATKAISU
Perustelut
Tapahtumat ja erimielisyys
C on työskennellyt Maalausliike Pöntinen Ky:n palveluksessa maalarina Trillatori -nimisellä työmaalla ajan 17.12.2001 - 16.5.2002. Tässä työkohteessa C:lle on maksettu urakkaennakon nimellä 11,77 euron suuruista tuntipalkkaa 25.3.2002 alkaneeseen palkkajaksoon saakka. Viimeksi mainitun palkkajakson aikana urakkaennakon määrä on alennettu 8,54 euroksi. Seuranneelta palkkajaksolta alkaen työsuhteen päättymiseen asti C:lle on maksettu 8,29 euron mukaista urakkaennakkoa.
Asianosaisten välillä vallitsee ensiksi erimielisyys siitä, onko C:n edellä tarkoitettu työ katsottava urakka- vai aikatyöksi. Toiseksi asianosaisten välillä vallitsee erimielisyys siitä, onko työnantajalla ollut oikeus alentaa C:lle maksettua palkkaa työn huonon laadun perusteella.
Esitetty näyttö
Työtuomioistuimessa on kuultu todistelutarkoituksessa C:tä ja toimitusjohtaja A:ta, jotka ovat kertoneet työstä sopimiseen ja työn laatuun liittyvistä seikoista. Muun muassa työehtosopimuksen urakkatyömääräysten tulkinnasta todistajina on kuultu Rakennusliiton työehtosihteeriä D:tä ja Suomen Maalarimestariliiton entistä toimitusjohtajaa, työmarkkinajohtajaa E:tä. C:n työn laadusta todistajina on kuultu työnjohtaja F:ää ja työasiamies G:tä.
Kirjallisina todisteina asiassa on esitetty muun muassa palkkalaskelmia, urakanjakolistoja, urakan loppuselvitys, itselle luovutusta koskevia selvityksiä, 13.3.2002 päivätty laatusuunnitelma, valokuvia sekä työkohteen aikataulua ja kustannuksia koskeva selvitys.
Aika- vai urakkatyö
C on kertonut tulleensa Maalausliike Pöntinen Ky:n palvelukseen vuoden 2001 syksyllä Viidakkopolulla sijaitsevalle työkohteelle. Tuolloin hän oli sopinut työmaan työnjohtajana toimineen H:n kanssa tuntipalkan määrästä ja työn tekemisestä urakalla. Kesken urakkaa hänet oli siirretty Trillatorin työmaalle. Tässä yhteydessä C oli neuvotellut H:n kanssa koko työkohteen maalaustyöt käsittävästä urakasta. Työnantajan taholta oli esitetty urakkahinnaksi 100 000 markkaa ja työntekijäpuolen pyyntö on ollut 130 000 markkaa. Työnjohtajan kieltäydyttyä hyväksymästä viimeksi mainittua hintaa, C oli ilmoittanut, että työt tehdään tuntityönä. Palkan alentaminen oli toteutettu sen jälkeen, kun C oli ilmoittanut, että työnantajan esittämää urakkahintaa ei hyväksytä. Tämän jälkeen työnantaja oli vedonnut puutteisiin työn laadussa.
A:n mukaan Trillatorin maalaustöiden urakasta oli alun perin sovittu kahden työntekijän eli C:n ja hänen poikansa kanssa. Trillatorin työmaan aikana C oli myös tehnyt urakkaan kuulumatonta aikatyötä, josta hänelle oli maksettu aikapalkkaa.
D:n mukaan vuoden 2003 alkuun asti maalausalan työehtosopimuksen määräykset ovat lähteneet siitä, että työt tehdään urakkahinnoittelun mukaisesti, mikäli esteitä urakkatyön tekemiselle ei ole. Maalausalalla työt tehdään ainoastaan sopimustuntipalkalla tai urakkapalkalla. Palkkaustavasta sovitaan ennen työn aloittamista. Jos työ sovitaan urakalla tehtäväksi, tulee työstä laatia työehtosopimuksen mukaisesti kirjallinen urakkasopimus. Työnantajan tulee antaa työntekijöille myös kirjallinen työselitys, jossa on selvitetty urakkaan kuuluvat työt. Maalausliike Pöntinen Ky:tä lukuunottamatta käytäntö D:n tietojen mukaan on se, että urakkasopimukset tehdään kirjallisesti.
E:n mukaan maalausalan työehtosopimuksen urakkamääräysten mukainen pääsääntö on ollut, että työt tehdään urakalla. Jos urakkahinnasta ei erikseen sovita, noudatetaan työehtosopimuksen mukaista urakkahinnoittelua. Ellei urakkahinnasta päästä osapuolten välillä sopimukseen, saattaa tilanne käytännössä johtaa usein siihen, että työt tehdään aikatyönä, mikä ei kuitenkaan ole työehtosopimuksen tarkoitus. Käytännössä joissakin alan yrityksissä urakkasopimukset tehdään aina kirjallisesti, mutta suurimmassa osassa yrityksiä urakkasopimukset tehdään suullisesti. Kirjallisen urakkatyösopimuksen tekemistä koskeva määräys on otettu työehtosopimukseen Rakennusliiton aloitteesta vuonna 1994. Tätä ennen työehtosopimus on edellyttänyt vain kirjallisen työselityksen antamista.
Kanteessa tarkoitettuna ajankohtana voimassa olleiden työehtosopimusmääräysten mukaan lähtökohtana on ollut urakkahinnoittelun yleismääräysten 1.1 kohdassa sovituin tavoin, että kaikki hinnoittelussa mainitut työt suoritetaan urakkatyönä. Jos urakkahinnasta ei erikseen sovita, noudatetaan työehtosopimuksen mukaista urakkahinnoittelua. Siitä, missä tilanteessa ja millä edellytyksillä työ tehdään aina aikapalkalla, on sovittu yleismääräysten 1.2 kohdassa. Tällaisessa tilanteessa osapuolten tulee yhteisesti todeta työehtosopimuksessa tarkoitetun urakkatyön esteen olemassaolo ennen työn muutoin kuin urakkatyönä tapahtuvaa suorittamista. Yleismääräysten 1.3 kohdan mukaan osapuolet ovat kuitenkin aina oikeutettuja sopimaan aikapalkalla työskentelystä. Vaikka urakkasopimuksia käytännössä saatetaankin solmia myös suullisesti, on urakkahinnoittelun yleismääräysten 3 kohdassa kuitenkin nimenomaisesti sovittu siitä, että urakkatyökohteesta tehdään kirjallinen sopimus.
Palkkalaskelmien mukaan C:lle on maksettu palkka myös Trillatorin työmaalla urakkaennakon nimellä samansuuruisena kuin hänelle on maksettu edellisessä työkohteessa, jossa urakkatyön tekemisestä on sovittu. Palkkajaksolta 31.12.2001 - 11.1.2002 C:lle on myös maksettu pohjarahaa 84,09 euroa. Työsuhteensa aikana C ei ole ilmoittanut työnantajalle käsitystään, jonka mukaan työtä ei ole sovittu tehtäväksi urakkatyönä. Edellä esitetyillä perusteilla työtuomioistuin katsoo näyttämättä jääneen, että osapuolten välillä olisi sovittu työn tekemisestä aikapalkalla. Koska kysymys on ollut urakkahinnoittelussa mainitusta työstä, on työ siten katsottava tehdyksi urakkatyönä.
Palkkaennakon alentaminen
Sekä A:n että Trillatorin työmaalla työnjohtajana 1.5.2002 alkaen toimineen F:n mukaan maalaustyössä, jota C oli ollut tekemässä, on ollut vakavia puutteita. F:n mukaan tasoitetyön hionta ja välikittaus oli tehty huonosti ja valmiiksimaalaus oli tehty hiomattomien ja huonosti kitattujen paikkojen päälle. F oli havaintojensa perusteella laatinut kirjallisiksi todisteiksi jätetyt virhe- ja puutelistat, minkä jälkeen toiset työntekijät ovat tehneet korjaustyöt.
Puutteista on A:n mukaan ilmoitettu työntekijöille ensimmäisen kerran kirjallisesti 13.3.2002 ja ennen palkan alentamista myös suullisesti. Kirjalliseksi todisteeksi on jätetty 13.3.2002 päivätty työnjohtaja H:n ja C:n allekirjoittama C rapun kolmea kerrosta koskeva laatusuunnitelma, jossa on esitetty kolmea työvaihetta koskeva huomautus. Asiakirjaan merkityn mukaan virheet ja puutteet korjataan viikkoon 12 mennessä. A:n mukaan työssä olleita virheitä oli korjattu vielä toukokuussa, jolloin C ei ollut ollut enää työmaalla. C:n ja työkunnan toisen jäsenen työvauhdin hitaudesta johtuen myös työkohteen aikataulut olivat vaarantuneet, minkä vuoksi työmaalle oli toukokuun 2002 alusta alkaen jouduttu palkkaamaan lisää työntekijöitä.
A on kertonut palkan alentamisen perustuneen työnantajan urakka-ansioiden ja työaikataulujen toteutumista koskevaan seurantaan, jonka perusteena ovat työnantajan laatimat kirjalliset selvitykset. Työnantajan laatimat edellä mainittuja asioita koskevat graafiset selvitykset on luovuttu myös työntekijöille. Mitään markkamääräistä laskelmaa palkan alentamisen selvittämiseksi työnantaja ei A:n mukaan ole ennen palkan alentamista tehnyt.
G on kertomansa mukaan käynyt Trillatorin työmaalla touko-kesäkuun vaihteessa vuonna 2002 A:n pyynnöstä. Hän on tuolloin ottanut työmaalta todisteiksi jätetyt valokuvat. G:n mukaan valmiiksimaalausta ei olisi tullut tehdä, koska tätä työvaihetta edeltäviä silotustöitä ei ollut tehty. Valokuvista käy ilmi, kuinka paljon osittain silotustyötä oli jouduttu tekemään valmiiksimaalauksen jälkeen. G:n mukaan käytännössä on harvinaista, että valmiiksimaalauksen jälkeen joudutaan tekemään niin paljon jälkitöitä kuin kysymyksessä olevassa kohteessa oli jouduttu tekemään.
D:n mukaan 13.3.2002 päivätyssä laatusuunnitelmassa mainitut puutteet ovat normaalin rajoissa. Muissa F:n laatimissa todisteiksi jätetyissä asiakirjoissa mainituista virheistä osa on D:n mukaan tasoitemiesten työtehtäviin liittyviä. D on edelleen kertonut, että työehtosopimuksen mukaan työnantajalla ei enää urakkaa laskettaessa ja mitattaessa ole oikeutta alentaa palkkaa työn laatuvirheiden perusteella, jotka olisi heti pitänyt huomata. Liikaa maksetun palkan alentaminen on mahdollista tehdä myöhemmissä tilivaiheissa, jos molemmat osapuolet ovat aiemmassa mittauksessa hyväksyneet, että maksetut ennakot ovat ylittäneet sovitun urakan. Myös todistaja E on kertonut oikean menettelyn olevan, että havaittaessa työn laadun vaarantuvan asia käydään työntekijän kanssa läpi ja oikaistaan liian suureksi sovittua urakkasummaa. Yksipuolisenkin kuittauksen on perustuttava välimittaukseen.
F:n ja G:n sekä A:n kertomukset samoin kuin todisteiksi jätetyt kirjalliset selvitykset maalaustyössä olleista puutteista osoittavat työtuomioistuimen mielestä, että työn laatu ei kaikilta osin ole ollut sellaista kuin ammattitaitoiselta maalarilta voidaan edellyttää. Kysymys on kuitenkin ollut urakkakohteesta, jossa on urakan jakolistan mukaan ollut C:n lisäksi ollut 15 muutakin työntekijää. Työtuomioistuimelle jätetyistä graafisista selvityksistä tai allekirjoittamattomista puute- ja virheluetteloista ei ole yksilöitävissä, keiden työntekijöiden työn laadusta on kysymys. Ainoastaan 13.3.2002 päivätyssä, C:n allekirjoittamassa laatusuunnitelmassa on yksilöity kolme huomautusta.
Urakkahinnoittelun yleismääräysten 14. kohdassa on sovittu niistä velvoitteista, joita työnantajalla ja työntekijällä on työn laatuun ja työn aikataulun vaarantumiseen liittyvissä tilanteissa. Mainitussa kohdassa ei ole määräystä, jonka mukaan työn laadussa tai työvauhdissa mahdollisesti olevat puutteet ilman muuta oikeuttaisivat työnantajan urakkaennakon alentamiseen. Työnantajapuolen mukaan urakkaennakon alentamisella työnantaja on pyrkinyt kuittaamaan liikaa maksetun urakkaennakon määrää. Yleismääräysten 18. kohdassa sovittu työnantajan kuittausoikeus voi työtuomioistuimen mielestä tulla kysymykseen vain tilanteessa, jossa on tehty asianmukainen urakka-ansiota koskeva laskelma. Tällainen laskelma puolestaan edellyttää työn mittaamista ja urakka-ansion laskemista yleismääräysten 15. ja 16. kohtien määräysten mukaisesti. Palkan alentamisten ei ole kysymyksessä olevina ajankohtina näytetty perustuneen yleismääräysten edellä mainituissa kohdissa tarkoitettuun työn mittaamiseen ja urakka-ansion laskemiseen.
Palkkasaatavien määrä
Asianosaiset ovat pääkäsittelyssä olleet yhtä mieltä siitä, että mikäli C:n työ katsotaan tehdyksi sopimustuntipalkalla, on hänen saataviensa määrä 951,67 euroa. Koska yksimielisyyden ei ole ilmoitettu koskevan palkkasaatavien määrää myös siinä tapauksessa, että C:n työ katsotaan urakkatyöksi, työtuomioistuin katsoo, että suoritusvelvollisuuden riitaiseksi jäänyttä määrää ei voida ratkaista tässä yhteydessä.
Työehtosopimuksen vastainen menettely
Maalausliike Pöntinen Ky on rikkonut tietensä työehtosopimusta jättäessään tekemättä urakkahinnoittelun yleismääräysten 3. kohdassa tarkoitetun kirjallisen urakkatyösopimuksen ja laiminlyödessään yleismääräysten 15. ja 16. kohdissa tarkoitetun työn mittauksen ja urakka-ansion laskemisen.
Kun epäselvää on ollut, onko C:n kanteessa tarkoitettua työtä pidettävä urakkatyönä vai aikatyönä ja onko työnantajalla ollut oikeus palkan kuittaamiseen palkkaa alentamalla, ei Suomen Maalarimestariliiton työnantajan menettelyn hyväksyessään voida katsoa laiminlyöneen valvontavelvollisuuttaan.
Oikeudenkäyntikulut
Jutun hävitessään Maalausliike Pöntinen Ky ja sen vastuunalaiset yhtiömiehet A ja B ovat velvolliset korvaamaan Rakennusliiton oikeudenkäyntikulut sen mukaisesti kuin yhdessä tämän asian kanssa käsitellyssä asiassa R 49/03 annetussa tuomiossa on todettu.
Asian laatu ja sen lopputulos huomioon ottaen saa Suomen Maalarimestariliitto vastata omista oikeudenkäyntikuluistaan.

Tuomiolauselma
Työtuomioistuin vahvistaa, että Maalausliike Pöntinen Ky on rikkonut työehtosopimusta jättäessään tekemättä kirjallisen urakkatyösopimuksen ja laiminlyödessään urakkatyön mittaamisen ja urakka-ansion laskemisen.
Työtuomioistuin tuomitsee työehtosopimuslain 7 ja 10 §:n nojalla Maalausliike Pöntinen Ky:n maksamaan työehtosopimuksen tieten rikkomisesta hyvityssakkoa Rakennusliitolle 2 000 euroa.
Työtuomioistuimesta annetun lain 1 §:n 2 momentin nojalla työtuomioistuin osoittaa asianosaiset tarvittaessa ajamaan kannetta C:n palkkasaatavien määrästä toimivaltaisessa käräjäoikeudessa.
Suomen Maalarimestariliitto saa pitää oikeudenkäyntikulunsa vahinkonaan.
Kanne enemmälti hylätään.

Tuomio on yksimielinen.

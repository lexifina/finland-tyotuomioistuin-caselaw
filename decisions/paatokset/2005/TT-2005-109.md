# TT:2005-109

## Suomeksi

Kysymys ulkomaanliikenteen matkustaja-alussopimuksen mukaisessa vuorottelujärjestelmässä A työskentelevän osa-aikaisen työntekijän vuosiloman sijoittamisesta vuorottelujärjestelmään ja tällaisen työntekijän vuotuisen työajan pituudesta.
Kysymys myös siitä, oliko asiassa puolin ja toisin rikottu työehtosopimusta ja syyllistytty työrauhavelvollisuuden rikkomiseen.

Merimieseläkelain mukaiseen osa-aikaeläkkeeseen liittyvä osa-aikatyö toteutetaan liitteen mukaisesti.

Edellä tarkoitetussa ulkomaanliikenteen matkustaja-alussopimuksen osa-aikatyötä koskevassa liitteessä 9.2 on muun ohella seuraavat määräykset:
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
1. Osa-aikatyöntekijä
Osa-aikatyöntekijällä tarkoitetaan henkilöä, johon sovelletaan merityöaikalakia (296/76) ja jonka säännöllinen työaika on puolet samanlaista työtä tekevän kokoaikaisen työntekijän säännöllisestä työajasta ja joka on merimieseläkelain (72/56) tarkoittamalla osa-aikaeläkkeellä. Jäljempänä olevia määräyksiä sovelletaan ainoastaan tällaiseen työntekijään.
Osatyökyvyttömyyseläkkeellä olevaan työntekijään sovelletaan, mitä osa-aikaeläkkeellä olevan työntekijän osalta on sovittu.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
6. Vuosiloma
Osa-aikaisen työntekijän vuosiloman osalta noudatetaan merimiesten vuosilomalaissa (433/1984) sekä ulkomaanliikenteen matkustaja-alussopimuksessa olevia säännöksiä ja määräyksiä. Toinen kahden peräkkäisen lomanmääräytymiskauden lomista voidaan käyttää vuorotteluun ulkomaanliikenteen matkustaja-alussopimuksen kohdissa 5.9.2 ja 5.9.3 mainitulla tavalla. Toinen lomista on annettava yhdenjaksoisena toukokuun 2. päivän ja syyskuun 30. päivän välisenä aikana.

= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
4.5 Osa-aikatyö
Merimieseläkelain mukaiseen osa-aikaeläkkeeseen ja osatyökyvyttömyyseläkkeeseen liittyvä osa-aikatyö sekä merimieslain mukainen osittainen hoitovapaa toteutetaan liitteen 9.2 mukaisesti.

5.7 Vuorottelujärjestelmä
Vuorottelujärjestelmällä tarkoitetaan sellaista järjestelmää, jossa työ- ja vapaavuorot toistuvat mahdollisimman säännönmukaisesti.
Niin sanotulla 1:1 -vuorottelujärjestelmällä tarkoitetaan järjestelyä, jossa työ- ja vapaavuorot toistuvat yhtä pitkinä ja 2:1 -vuorottelujärjestelmällä järjestelmää, jossa työvuoro on kaksi kertaa niin pitkä kuin vapaavuoro.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
Työ- ja vapaavuorot tulisi toteuttaa siten, että ne ovat keskimäärin enintään kahden viikon pituisia jaksoja (2 viikkoa työtä ja 2 viikkoa vapaata), ellei asianosaisten työntekijöiden kesken toisin sovita. Työnantajan edustajan on kuitenkin vahvistettava tällainen järjestely.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
5.9 Eri vuorottelujärjestelmät
5.9.1 Järjestelmä A (1:1):
Takuupalkkaan sisältyvä vuorokautinen työaika: 10,5 tuntia.
Työpäivien lukumäärä vuodessa: 165.
Vuosiloma: kahden peräkkäisen lomanmääräytymiskauden aikana 35 päivää.
Vapaajaksot ja lomat annetaan siten, että työntekijä saa kahden peräkkäisen lomanmääräytymiskauden aikana vähintään kaksi yhdenjaksoista lomaa, joista toinen on 18 päivää ja toinen 17 päivää.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
Yllä mainitun työehtosopimuksen osa-aikatyötä koskevan liitteen kohdan 6. vuosilomaa koskeva määräys on samansisältöinen kuin aikaisemmassa sopimuksessa, mutta 1 kohtaa on muutettu muun muassa siten, että sen mukaan osatyökyvyttömyyseläkkeellä ja osittaisella hoitovapaalla olevaan työntekijään sovelletaan, mitä osa-aikaeläkkeellä olevan työntekijän osalta on sovittu.
Suomen Merimies-Unioni SM-U:n ja Viking Line Abp:n välillä 26.3.2003 tehdyssä matkustaja-alussopimuksen mukaisten aluskohtaisten sopimusten uudistamista koskevassa pöytäkirjassa on sovittu muun muassa seuraavaa:
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
a. Viking Line Abp palauttaa osa-aikatyötä tekevien palkanmaksun ja vuorottelun osalta käytännön, jota noudatettiin ennen 1.1.2002. Osapuolet käynnistävät Viking Line Abp:n aloitteesta neuvottelut, joiden päämääränä on selvittää osa-aikatyötä tekevien vuosilomaetuihin liittyvät kysymykset ja mahdolliset epäselvyydet.

SUOMEN MERIMIESUNIONI SM-U:N KANNE
Vaatimukset
Suomen Merimies-Unioni SM-U on vaatinut, että
Viking Line Abp tuomitaan maksamaan Suomen Merimies-Unioni SM-U:lle työehtosopimuslain mukaista hyvityssakkoa työehtosopimuksen tieten rikkomisesta ja työrauhavelvollisuuden rikkomisesta,

Ålands Redarförening tuomitaan maksamaan Suomen Merimies-Unioni SM-U:lle työehtosopimuslain mukaista hyvityssakkoa työehtosopimuslain mukaisen valvontavelvollisuuden laiminlyönnistä ja

Viking Line Abp ja Ålands Redarförening velvoitetaan yhteisvastuullisesti korvaamaan Suomen Merimies-Unioni SM-U:n oikeudenkäyntikulut korkolain mukaisine viivästyskorkoineen kuukauden kuluttua siitä, kun tuomio on annettu.

Perusteet
Viking Line Abp:n omistamilla aluksilla noudatetaan ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1 kohdan mukaista vuorottelujärjestelmää A. Tässä vuorottelujärjestelmässä takuupalkkaan sisältyvä vuorokautinen työaika on 10,5 tuntia ja vuorottelu toteutetaan 1:1-järjestelmällä, mikä pääsääntöisesti tarkoittaa sitä, että työntekijä on viikon työjaksolla ja viikon vuorotteluun kuuluvalla vapaajaksolla. Osa-aikaeläkkeeseen liittyvä osa-aikatyöjärjestely on tässä vuorottelujärjestelmässä toteutettu siten, että merimies on viikon työjaksolla, viikon vuorotteluun kuuluvalla vapaajaksolla ja sen jälkeen kaksi viikkoa eläkejaksolla. Työehtosopimuksen mukaan vapaajaksot ja lomat annetaan siten, että työntekijä saa kahden peräkkäisen lomanmääräytymiskauden aikana vähintään kaksi yhdenjaksoista lomaa, joista toinen on pituudeltaan 18 päivää ja toinen 17 päivää.
Ulkomaanliikenteen matkustaja-alussopimuksen liitteessä 9.2 on sovittu osa-aikatyötä koskevista erillismääräyksistä. Liitteen 6. kohdassa on sovittu siitä, että osa-aikaisen työntekijän vuosiloman osalta noudatetaan merimiesten vuosilomalain ohella ulkomaanliikenteen matkustaja-alussopimuksessa olevia määräyksiä. Mainitussa kohdassa on edelleen todettu, että toinen kahden peräkkäisen lomanmääräytymiskauden lomista voidaan käyttää vuorotteluun ulkomaanliikenteen matkustaja-alussopimuksen kohdissa 5.9.2 ja 5.9.3 mainitulla tavalla. Kysymyksessä olevat kohdat tarkoittavat vuorottelujärjestelmää B (1:1), jossa takuupalkkaan sisältyvä vuorokautinen työaika on 10 tuntia, sekä vuorottelujärjestelmää C (1:1), jossa takuupalkkaan sisältyvä vuorokautinen työaika on 9,5 tuntia.
Viking Line Abp oli noudattanut vuoden 2002 loppuun asti työehtosopimuksen mukaista käytäntöä, jonka mukaan osa-aikaeläkkeellä olevalle merimiehelle annettiin kaksi yhdenjaksoista lomaa kahden peräkkäisen lomanmääräytymiskauden aikana siten, että toinen lomista oli 18 päivää ja toinen 17 päivää. Tuolloin merimies oli saanut yhden viikon pituisen työjakson vapaaksi kummankin loman aikana eli kaksi kertaa vuodessa.
Viking Line Abp oli vuoden 2003 alussa muuttanut yksipuolisesti edellä mainittua lomakäytäntöä siten, että toinen ansaittu lomajakso oli sijoitettu vuorottelujärjestelmään niin, että osa-aikaeläkkeellä oleva työntekijä sai vain yhden viikon pituisen työjakson vapaaksi kerran vuodessa. Tämä käytäntö on ulkomaanliikenteen matkustaja-alussopimuksen määräysten vastainen.
Suomen Merimies-Unioni SM-U oli saanut 1.7.2003 pääluottamusmieheltä selvityksen, jonka mukaan Viking Line Abp oli palauttanut osa-aikaisten vuosilomakäytännön edellä mainitun sopimuksen mukaiseksi niiden työntekijöiden osalta, jotka olivat olleet osa-aikatyössä ennen 26.3.2003. Pääluottamusmiehen mukaan Viking Line Abp oli ilmoittanut, että uusien osa-aikatyöntekijöiden kohdalla varustamo tulee noudattamaan uutta käytäntöä.
Syksyllä 2003 oli käynyt ilmi, että Viking Line Abp kieltäytyi myöntämästä työntekijöilleen merimieslain 32 b §:n sekä ulkomaanliikenteen matkustaja-alussopimuksen 4.5 -kohdan mukaista osittaista hoitovapaata. Suomen Merimies-Unioni SM-U oli pyytänyt asiasta selvitystä Viking Line Abp:ltä ja Ålands Redarföreningiltä.
Viking Line Abp oli 30.10.2003 päiväämässään kirjallisessa vastauksessa todennut suhtautuvansa myönteisesti uusia osa-aikaeläkkeitä ja osittaista hoitovapaata koskeviin järjestelyihin, mikäli ne toteutetaan sen tulkinnan mukaisesti, mikä vastasi varustamon käsitystä työehtosopimusmääräysten sisällöstä. Kirjeessä oli viitattu siihen, että Suomen Merimies-Unioni SM-U ei ollut hyväksynyt Viking Line Abp:n esittämää tulkintaa, mistä syystä Viking Line Abp ei ollut valmis myöntämään uusia vapaita osa-aikaeläkettä tai osittaista hoitovapaata varten. Viking Line Abp oli todennut olevansa valmis myöntämään edellä mainittuja vapaita sen jälkeen kun ulkomaanliikenteen matkustaja-alussopimukseen osalliset ovat päässeet yhteisymmärrykseen osa-aikatyötä koskevan liitteen mukaisista laskentaperusteista.
Suomen Merimies-Unioni SM-U ja Ålands Redarförening olivat liittoneuvottelussa 13.11.2003 todenneet yhteisymmärryksessä, että Viking Line Abp:n tulee välittömästi ryhtyä myöntämään osittaista hoitovapaata sitä hakeneille. Lisäksi neuvotteluosapuolet olivat todenneet, että osittaista hoitovapaata myönnettäessä on noudatettava, mitä laissa ja ulkomaanliikenteen matkustaja-alussopimuksessa asiasta on tarkemmin sovittu.
Kun asiassa tämänkin jälkeen oli vielä esiintynyt ongelmia, oli samojen osapuolten välillä 23.1.2004 pidetyssä liittoneuvottelussa todettu seuraavaa:
Todettiin, että Viking Line on soveltanut vuosiloman sijoittamisen osalta erilaista käytäntöä osittaisella hoitovapaalla oleviin ja osa-aikaeläkkeellä tai osatyökyvyttömyyseläkkeellä oleviin työntekijöihin. Osittaisella hoitovapaalla olevien työntekijöiden vuosiloma on sijoitettu osittain sellaisille jaksoille, jotka eivät ole olleet työntekijää koskevan osa-aikatyösopimuksen mukaisia työ- tai vapaavuorojaksoja.
Sovittiin siitä, että Viking Line:a kehotetaan korjaamaan kaikkien osa-aikatyötä tekevien vuorottelulistat siten, että osittaisella hoitovapaalla olevien työntekijöiden osalta noudatetaan myös vuosiloman osalta samaa käytäntöä kuin osa-aikaeläkkeellä ja osatyökyvyttömyyseläkkeellä olevien kohdalla.
Sovittiin, että Viking Line selvittää miten työvuorolistat on korjattu ja että varustamo lähettää tästä tiedon Suomen Merimies-Unionille viikon 5/2004 aikana.
Ålands Redarförening oli lähettänyt 30.1.2004 edellä tarkoitetun liittoneuvottelussa sovitun selvityksen. Suomen Merimies-Unioni SM-U oli 4.2.2004 antamassaan vastauksessa todennut, että Viking Line Abp oli yhä soveltanut käytäntöä, jossa työntekijöiden vuosiloma oli sijoitettu siten, että se ei mahdollistanut esimerkiksi hoitovapaajaksojen toteutumista vuosiloman jälkeen. Kirjeessä oli edelleen todettu, että vuorottelulistoja ei ollut laadittu siten, että osittaisella hoitovapaalla olevien työntekijöiden kohdalla noudatettaisiin vuosiloman osalta samaa käytäntöä kuin osa-aikaeläkkeellä ja osatyökyvyttömyyseläkkeellä olevien kohdalla.
Ålands Redarförening oli tämän jälkeen 9.2.2004 päivätyssä kirjeessä pyytänyt Suomen Merimies-Unioni SM-U:n kannanottoa siitä, miten asianomaista sopimusmääräystä tulisi soveltaa. Suomen Merimies-Unioni SM-U oli vastannut tähän 13.2.2004 päivätyllä kirjeellä, jossa se edellytti, että Viking Line Abp palaa sovittuun laskentajärjestelmään.
Muuttaessaan yksipuolisesti vuoden 2003 alusta osa-aikaeläkeläisten vuosilomakäytäntöä Viking Line Abp oli rikkonut tuolloin voimassa olleen ulkomaanliikenteen matkustaja-alussopimuksen 4.5-kohdan osa-aikatyötä ja työehtosopimuksen osana noudatettavan liitesopimuksen 9.2 vuosilomaa koskevan 6. kohdan määräyksiä sekä ulkomaanliikenteen matkustaja-alussopimuksen 5.7- ja 5.9.1- kohdan määräyksiä.
Vaikka aluskohtaisten työehtosopimusten uudistamista koskevassa työehtosopimuspöytäkirjassa 26.3.2003 oli sovittu siitä, että Viking Line Abp palauttaa osa-aikatyötä tekevien palkanmaksun ja vuorottelun osalta käytännön, jota noudatettiin ennen vuoden 2003 alkua, ei Viking Line ollut menetellyt tämän mukaisesti. Viking Line Abp oli korjannut menettelyn pöytäkirjassa tarkoitetulla tavalla vain niiden työntekijöiden osalta, jotka olivat olleet osa-aikatyössä ennen 26.3.2003. Viking Line Abp oli siten tietensä rikkonut 1.3.2003 voimaan tulleen ulkomaanliikenteen matkustaja-alussopimuksen 4.5-kohdan osa-aikatyötä ja 5.7- ja 5.9.1-kohdan vuorottelujärjestelmää sekä työehtosopimuksen osana noudatettavan liitesopimuksen 9.2 vuosilomaa koskevan 6. kohdan ja 26.3.2003 tehdyn aluskohtaisten työehtosopimusten allekirjoituspöytäkirjan määräyksiä.
Liittoneuvotteluissa 13.11.2003 ja 23.1.2004 oli sovittu siitä, että Viking Line Abp:n on korjattava kaikkien osa-aikatyötä tekevien vuorottelulistat siten, että osittaisella hoitovapaalla olleiden työntekijöiden kohdalla noudatetaan myös vuosiloman osalta samaa käytäntöä kuin osa-aikaeläkkeellä ja osatyökyvyttömyyseläkkeellä olevien kohdalla. Viking Line Abp oli laiminlyönyt toimia osallisten yhdistysten yksimielisen kannan mukaisesti, joten tältä osin se edelleen rikkoo ulkomaanliikenteen matkustaja-alussopimuksen 4.5-kohdan osa-aikatyötä ja 5.7- ja 5.9.1-kohdan vuorottelujärjestelmää sekä liitesopimuksen 9.2 vuosilomaa koskevan 6. kohdan määräyksiä.
Toissijaisesti Viking Line Abp:n oli katsottava näillä toimillaan rikkovan tietensä työehtosopimuksen edellä mainittuja määräyksiä.
Ålands Redarförening rf oli laiminlyönyt valvoa, että Viking Line Abp toteuttaa liittoneuvotteluissa 13.11.2003 ja 23.1.2004 todetun osallisten yhdistysten yhteisen kannan osittaisella hoitovapaalla olevien työntekijöiden vuosilomakäytännön osalta. Ålands Redarförening ei ollut ryhtynyt asiassa tehokkaisiin toimenpiteisiin huolimatta siitä, että Suomen Merimies-Unioni SM-U oli tätä kirjeitse viimeisen liittoneuvottelun jälkeenkin edellyttänyt.
Ålands Redarföreningin olisi tullut lisäksi havaita Viking Line Abp:n 30.10.2003 päivätystä kirjallisesta vastauksesta, että varustamo syyllistyy työtaistelutoimenpiteeseen kieltäytymällä myöntymästä uusiin osa-aikaeläkeratkaisuihin ennen kuin Suomen Merimies-Unioni SM-U on tosiasiallisesti hyväksynyt varustamon esittämän tavan toteuttaa osa-aikaeläkkeisiin ja osittaiseen hoitovapaaseen liittyvät vuosilomien sijoittamiset vuorottelujärjestelmään. Ålands Redarförening on ollut myös tietoinen siitä, että tämä varustamon painostustarkoituksessa toteuttama uhkaus on edelleen voimassa ja että Viking Line Abp ei suostu tekemään uusia osa-aikaisia työsopimuksia osa-aikaeläkkeeseen oikeutettujen työntekijöiden kanssa noudattamalla samaa käytäntöä kuin ennen 26.3.2003 osa-aikaeläkkeelle jääneiden työntekijöiden kohdalla. Ålands Redarförening oli siten laiminlyönyt sille kuuluvan valvontavelvollisuuden.

VIKING LINE ABP:N JA ÅLANDS REDARFÖRENINGENIN VASTAUS
Vastaus kannevaatimuksiin
Viking Line Abp ja Ålands Redarförening ovat kiistäneet kanteen ja vaatineet sen hylkäämistä.
Viking Line Abp ja Ålands Redarförening rf ovat lisäksi vaatineet Suomen Merimies-Unioni SM-U:n velvoittamista korvaamaan Viking Line Abp:n ja Ålands Redarföreningin oikeudenkäyntikulut laillisine korkoineen.

Kanteen kiistämisen perusteet
Viking Line Abp soveltaa matkustaja-aluksillaan ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1 kohdan mukaista vuorottelujärjestelmää A. Tässä järjestelmässä työpäivien lukumäärä vuodessa on 165. Näin ollen työehtosopimuksen mukaan myös vastikevapaapäivien määrä on 165. Sen lisäksi lomapäiviä on 35. Sopimuksessa erotetaan lomat työajasta.
Työehtosopimuksen liitteen 9.2 kohdan 1. mukaan osa-aikatyöntekijällä tarkoitetaan henkilöä, johon sovelletaan merityöaikalakia ja jonka säännöllinen työaika on puolet samanlaista työtä tekevän kokoaikaisen työntekijän säännöllisestä työajasta ja joka on merimieseläkelaissa tarkoitetulla osa-aikaeläkkeellä. Mainitun määräyksen mukaan osa-aikaeläkkeellä olevan henkilön työaika muodostuu siten, että hänellä on työpäiviä puolet 165:stä eli 82,5 vuodessa. Suomen Merimies-Unioni SM-U pyrkii vaatimuksillaan tilanteeseen, jossa osa-aikatyötä tekevän työntekijän työpäivien lukumäärä olisi vuodessa vähemmän kuin 82,5. Viking Line Abp ei ole missään yhteydessä sopinut poikettavaksi tästä 82,5 päivän mukaisesta vuosittaisesta työajasta osa-aikaeläkkeellä olevien kohdalla.
Kaikki Viking Line Abp:n palveluksessa olevat osa-aikatyöntekijät ovat saaneet lomansa siten, että heillä on kahden toisiaan seuraavan lomanmääräytymiskauden aikana ollut vähintään kaksi yhtenäistä vapaata, joista toinen on ollut pituudeltaan 18 päivää ja toinen 17 päivää. Viking Line Abp ei ole 1.1.2003 muuttanut käytäntöään siten, että toinen lomista käytettäisiin vuorotteluun.
Vuoden 2003 alusta toteutettiin työaikaseuranta siten, että aikaisempi käytäntö, joka oli johtanut siihen, että osa-aikaisen henkilön työpäivien lukumäärä vuodessa oli 78, korjattiin niin, että vuosittaisten työpäivien lukumäärä nousi 82,5:een.
Mitään muutosta osa-aikatyöntekijöiden palkkauksessa ei ollut tapahtunut vuoden 2003 alussa, vaan osa-aikatyöntekijä sai saman palkan kuin ennen tätä ajankohtaa eli puolet siitä palkasta, mitä kokoaikaiselle työntekijälle maksettiin. Osa-aikatyötä koskevan liitteen 9.2. kohdan 1 määräys samoin kuin osa-aikatyöntekijöitä koskeva direktiivi (97/81/EY) lähtevät siitä, että nyt esillä olevassa tapauksessakin osa-aikaisen työntekijän työajan tulee olla puolet kokoaikaisen työntekijän työajasta.
Vuoden 2003 alussa ei myöskään ollut tapahtunut mitään muutosta lomien antamisessa osa-aikatyöntekijöille, vaan he olivat saaneet mainitusta ajankohdastakin lukien vuosilomansa ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1 kohdan mukaisesti eikä loma-aikaa ollut käytetty vuorotteluun.
Viking Line Abp oli menetellyt osittaisten hoitovapaiden ja osa-aikaeläkkeiden osalta voimassa olevan lainsäädännön ja työehtosopimuksen mukaisesti. Ensimmäistä kertaa osittaista hoitovapaata haettiin 30.8.2003, hoitovapaa myönnettiin 24.11.2003 ja se alkoi 1.1.2004. Yhtiö ei ole kieltäytynyt myöntämässä osittaisia hoitovapaita, vaikka henkilöstöosastolla työskentelevän henkilön kanteessa mainitusta kirjeestä tällaisen käsityksen on voinut saada.
Toinen asia on se, että osa-aikaeläkkeestä päättää varustamo. Vuorottelun järjestäminen edellyttää myös sitä, että on kaksi osa-aikaeläkkeellä olevaa työntekijää, sillä muuten vuorottelu ei toimi. Mitään sellaista painostusta, joka muodostaisi työtaistelutoimenpiteen ei työnantajan puolelta ollut esitetty. Varustamo ei ollut menetellyt ulkomaanliikenteen matkustaja-alussopimuksen tai varustamon ja Suomen Merimies-Unioni SM-U:n välillä 26.3.2003 laaditun pöytäkirjan vastaisesti. Joka tapauksessa Ålands Redarföreningin valvontavelvollisuus ei voi ulottua varustamokohtaiseen sopimukseen, jossa on sovittu toisin kuin Ålands Redarföreningin solmimassa työehtosopimuksessa.

VIKING LINE ABP:N JA ÅLANDS REDARFÖRENINGIN KANNE
Vaatimukset
Viking Line Abp ja Ålands Redarförening ovat vaatineet,
että työtuomioistuin vahvistaa ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1-kohdan sekä ulkomaanliikenteen matkustaja-alussopimuksen osa-aikatyötä koskevan liitteen 1 kohdan ja 26.3.2003 tehdyn pöytäkirjan a-kohdan oikeaksi tulkinnaksi, että osa-aikaisen työntekijän vuosittainen työaika on puolet 165:stä päivästä eli keskimäärin 82,5 päivää, ja

että Suomen Merimies-Unioni SM-U tuomitaan työehtosopimuslain nojalla hyvityssakkoon työehtosopimuksen rikkomisesta ja työrauhavelvollisuuden rikkomisesta.

Viking Line Abp ja Ålands Redarförening ovat lisäksi vaatineet, että Suomen Merimies-Unioni SM-U velvoitetaan korvaamaan Viking Line Abp:n ja Ålands Redarföreningin oikeudenkäyntikulut laillisine korkoineen.

Perusteet
Vahvistusvaatimuksen perustelujen osalta Viking Line Abp ja Ålands Redarförening ovat viitanneet edellä vastauksessa esitettyihin perusteisiin.
Suomen Merimies-Unioni SM-U:n kanne oli perustettu ainoastaan 26.3.2003 päivätyn pöytäkirjan a-kohdan ensimmäiseen virkkeeseen. Saman kohdan toisessa virkkeessä oli sovittu siitä, että Viking Line Abp:n aloitteesta käynnistetään neuvottelut osa-aikatyötä tekevien vuosilomaetuihin liittyvien kysymysten ja mahdollisten epäselvyyksien selvittämiseksi. Tältä osin sopimus ei ollut ymmärrettävissä, ellei otettu huomioon niitä kysymyksiä, joita työnantajapuolen 30.12.2002 annetussa ohjeessa oli tarkoitus määritellä eli kuinka vuorottelu ja lomat järjestetään, jotta osa-aikatyöntekijän työaika olisi 82,5 päivää vuodessa. Koska työnantajan edellytettiin luopuvan lomien antamisesta siten, että keskimääräinen työaika neljän vuoden jaksossa tasoittuu 82,5 päivään vuodessa, tuli mainitussa kohdassa edellytetyin tavoin käydä neuvottelut siitä, kuinka loma annetaan, jotta vuotuinen työaika olisi 82,5 päivää.
Suomen Merimies-Unioni SM-U:n ja Viking Line Abp:n välillä oli neuvoteltu asiasta 18.6.2003. Näissä neuvotteluissa ensimmäisenä asiana oli esillä mainitun pöytäkirjan a-kohdan toisessa virkkeessä tarkoitettu asia. Neuvottelusta laaditun pöytäkirjan mukaan Suomen Merimies-Unioni SM-U väitti, että Viking Line Abp jatkuvasti sovelsi ohjetta, joka pöytäkirjan a-kohdan mukaan tulisi peruuttaa. Tähän Viking Line Abp:n taholta oli vastattu, että ohje oli peruutettu jopa kirjallisesti. Suomen Merimies-Unioni SM-U esitti tämän jälkeen, että ellei Viking Line Abp voi neuvottelutilaisuudessa näyttää kirjallista peruutusta, tulkitsee Suomen Merimies-Unioni SM-U asian siten, että ohjetta ei ole peruutettu ja että Suomen Merimies-Unioni SM-U kieltäytyy neuvottelemasta pöytäkirjan a-kohdan toisessa virkkeessä tarkoitetusta asiasta siihen asti, kunnes kirjallinen selvitys peruutuksesta esitetään.
Edellä mainitussa pöytäkirjan kohdassa ei edellytetä, että Viking Line Abp selvittäisi kirjallisesti Suomen Merimies-Unioni SM-U:lle peruuttaneensa ohjeen. Tällaisen selvityksen ei ole sovittu olevan edellytys sille, että Suomen Merimies-Unioni SM-U neuvottelee a-kohdan toisessa virkkeessä tarkoitetuista asioista. Kieltäytyessään neuvotteluista Suomen Merimies-Unioni SM-U on rikkonut 26.3.2003 päivättyä pöytäkirjaa. Kieltäytymällä neuvottelemasta Suomen Merimies-Unioni SM-U pyrkii saamaan aikaan tilanteen, missä Viking Line Abp on pakotettu laatimaan osa-aikaisten vuorottelujärjestelmät siten, että vuosittainen työaika rajoittuu 77 tai 78 päivään. Tilanne, jossa vuosittainen työaika on edellä mainitun pituinen, on ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1-kohdan sekä liitteen 9.2. 1-kohdan vastainen.
Suomen Merimies-Unioni SM-U:n kieltäytyminen neuvotteluista muodostaa edellä mainittuihin työehtosopimusmääräyksiin kohdistuneen työtaistelutoimenpiteen.

SUOMEN MERIMIES-UNIONI SM-U:N VASTAUS
Vastaus kannevaatimuksiin
Suomen Merimies-Unioni SM-U on kiistänyt kanteen ja vaatinut sen hylkäämistä.
Suomen Merimies-Unioni SM-U on lisäksi vaatinut Viking Line Abp:n ja Ålands Redarföreningin velvoittamista korvaamaan Suomen Merimies-Unioni SM-U:n oikeudenkäyntikulut korkolain 4 §:n 1 momentin mukaisine viivästyskorkoineen kuukauden kuluttua siitä, kun tuomio on annettu.

Kanteen kiistämisen perusteet
Ulkomaanliikenteen matkustaja-alussopimuksen osa-aikatyötä koskevan liitteen 9.2.-kohdassa 1 todetaan osa-aikatyöntekijällä tarkoitettavan henkilöä, johon sovelletaan merityöaikalakia ja jonka säännöllinen työaika on puolet samanlaista työtä tekevän kokoaikaisen työntekijän säännöllisestä työajasta ja joka on merimieseläkelain tarkoittamalla osa-aikaeläkkeellä. Ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1-kohdan mukaan vuorottelujärjestelmässä A (1:1) takuupalkkaan sisältyvä vuorokautinen työaika on 10,5 tuntia ja työpäivien lukumäärä vuodessa 165.
Ulkomaanliikenteen matkustaja-alussopimuksen 3 kohdassa todetaan, että työehtosopimuksessa tarkoitetaan takuupalkalla palkkaa, joka sisältää korvauksen säännöllisenä työaikana tehdystä työstä ja sovitusta määrästä ylityötä sekä ikälisät ja jonka työntekijä on oikeutettu saamaan joka palkanmaksukausi siitä riippumatta, teetetäänkö hänellä sovittua ylityömäärää vai ei. Kokoaikaisen työntekijän säännöllinen työaika järjestelmässä A ei siten ole suinkaan 10,5 tuntia vuorokaudessa, eikä siten myöskään kokoaikaisen työntekijän työpäivien lukumäärästä 165 voida johtaa matemaattisesti kahdella jakaen osa-aikaisen työntekijän säännöllistä työaikaa. Asiaa on tarkasteltava työehtosopimuksen 5.9-kohdan eri vuorottelujärjestelmiin sisältyvänä kokonaisuutena, jossa tulee ottaa huomioon kuhunkin vuorottelujärjestelmään sisältyvät vuosilomia koskevat määräykset.
Työehtosopimuksen 5.9.1-kohdan mukaisessa järjestelmä A:ssa työntekijän vuosiloma kahden peräkkäisen lomanmääräytymiskauden aikana on 35 päivää ja vapaajaksot ja lomat on annettava siten, että työntekijä saa kahden peräkkäisen lomanmääräytymiskauden aikana vähintään kaksi yhdenjaksoista lomaa, joista toinen on 18 päivää ja toinen 17 päivää. Käytännössä tämä tarkoittaa sitä, että vuosiloma on sijoitettava vuorottelujärjestelmään siten, että vuosiloman alle jää yksi työviikko eli työntekijä saa vuosilomansa aikana yhden viikon pituisen työjakson vapaaksi. Näin on meneteltävä molempien vuosilomajaksojen osalta.
Työehtosopimuksen 5.9.2-kohdan järjestelmässä B vuosiloman pituus on myös 35 päivää, mutta vuorotteluun tästä voidaan käyttää 17 päivää. Työehtosopimuksen mukaan vapaajaksot ja vuosiloma annetaan siten, että työntekijä saa kahden peräkkäisen lomanmääräytymiskauden aikana vähintään yhden yhdenjaksoisen loman, joka on 18 päivää. Järjestelmässä B on siten toisen vuosilomista oltava yhdenjaksoinen (18 päivää). Tässä vuorottelujärjestelmässä tämä tarkoittaa sitä, että toisen vuosilomajakson aikana sen alle jää yksi viikon pituinen työjakso eli työntekijä saa vuosilomansa aikana yhden työjakson vapaaksi. Toinen vuosilomajakso voidaan käyttää vuorotteluun eli sijoittaa vuorottelujärjestelmään siten, että se sijoittuu vuorottelujärjestelmän mukaisille vapaapäiville.
Työehtosopimuksen 5.9.3-kohdan mukaisessa järjestelmässä C vuosiloma kahden peräkkäisen lomanmääräytymiskauden aikana on 35 päivää, jotka voidaan kaikki käyttää vuorotteluun. Toisin sanoen vuosilomapäivät voidaan sijoittaa vuorottelujärjestelmään päällekkäin vapaajaksojen kanssa, jolloin yhtään työjaksoa ei jää vuosiloman alle eikä työntekijä siten myöskään saa yhtään viikon pituista työjaksoa vapaaksi.
Työehtosopimuksessa mainitulla lomanmääräytymiskaudella tarkoitetaan merimiesten vuosilomalain 4 §:n 1 momentin mukaista lomanmääräytymiskautta. Mainitun lainkohdan mukaan työntekijällä on oikeus vuosilomaan kuuden täyden lomanmääräytymiskuukauden kuluttua työsuhteen alkamisesta ja tämän jälkeen aina kuuden kuukauden välein (lomanmääräytymiskausi) edellisen vuosilomaoikeuden syntymisestä.
Osa-aikatyötä koskevan työehtosopimusliitteen 9.2 vuosilomaa koskevassa kohdassa 6 todetaan, että osa-aikaisen työntekijän vuosiloman osalta noudatetaan merimiesten vuosilomalaissa sekä ulkomaanliikenteen matkustaja-alussopimuksessa olevia säännöksiä ja määräyksiä. Toinen kahden peräkkäisen lomanmääräytymiskauden lomista voidaan käyttää vuorotteluun ulkomaanliikenteen matkustaja-alussopimuksen kohdissa 5.9.2 ja 5.9.3 mainituilla tavoilla. Toinen lomista on annettava yhdenjaksoisena toukokuun 2. päivän ja syyskuun 30. päivän välisenä aikana.
Työehtosopimusmääräyksestä käy siten ilmi, että työehtosopimuksen 5.9.1-kohdan vuorottelujärjestelmää A käytettäessä työntekijälle on annettava molemmat yhdenjaksoiset lomajaksot.
Työehtosopimuksen 5.9.3 mukaisessa järjestelmässä C kokoaikaisella työntekijällä on 52 viikon (1 vuosi) aikana 26 työviikkoa ja 26 vapaaviikkoa. Tällöin vuosilomat annetaan vuorotteluun sisältyen vapaaviikkojen aikana. Tässä järjestelmässä osa-aikaisella työntekijällä on 13 työviikkoa ja 13 vapaajaksoviikkoa sekä 26 eläkejaksoviikkoa.
Työehtosopimuksen 5.9.2 vuorottelujärjestelmässä B kokoaikaisella työntekijällä 52 viikon aikana on lähtökohtaisesti myös 26 työviikkoa ja 26 vapaajaksoviikkoa. Kun järjestelmässä B ainoastaan toinen vuosilomajakso voidaan käyttää vuorotteluun eli sijoittaa vapaajaksoviikoille, johtaa tämä siihen, että toinen vuosilomajakso on vuorottelujärjestelmään sijoitettava siten, että työntekijä saa vuosiloman aikana yhden työjaksoviikon vapaaksi. Tällöin kokoaikaisen työntekijän työviikkojen lukumäärä vuodessa on 25 viikkoa.
Kun vuorottelujärjestelmässä B kokoaikaisen työntekijän työviikkojen lukumäärä lähtökohtaisesti on vuodessa 26 (vuosiloman alle jäävä yksi viikko huomioon ottaen 25), niin osa-aikaisen työntekijän työviikkojen lukumäärä tässä järjestelmässä on lähtökohtaisesti 13 vuodessa. Kun tästä 13 työviikosta vähennetään yksi vuosiloman alle jäävä työviikko, niin osa-aikaisen työntekijän työviikkojen lukumäärä vuodessa järjestelmässä B on 12.
Vastaavalla tavalla Viking Line Abp:llä noudatettavassa työehtosopimuksen 5.9.1-kohdan mukaisessa järjestelmässä A kokoaikaisen työntekijän työviikkojen lukumäärä vuodessa on lähtökohtaisesti 26. Kun tässä järjestelmässä ei kuitenkaan voida kumpaakaan yhdenjaksoisista vuosilomista käyttää vuorotteluun, niin vuosiloma on sijoitettava vuorottelujärjestelmään siten, että kummankin erillisen vuosiloman aikana työntekijä saa yhden työviikon vapaaksi.
Kun vastaavalla tavalla osa-aikaisen työntekijän työviikkojen lukumäärä vuositasolla on lähtökohtaisesti 13 ja kun vuosilomat on sijoitettava vuorottelujärjestelmään siten, että kummankin vuosilomajakson aikana työntekijä saa yhden viikon pituisen työjakson vapaaksi, niin osa-aikaisen työntekijän työviikkojen lukumääräksi jää 11 eli 77 työpäivää.
Asianosaisten välillä vallitsee yksimielisyys siitä, että osa-aikaisen työntekijän vuosiloman pituus on 35 päivää kahden peräkkäisen lomanmääräytymiskauden aikana. Viking Line Abp:n ja Ålands Redarföreningin esittämä tulkinta on työehtosopimuksen vuorottelujärjestelmään A sisältyvän vuosilomamääräyksen tarkoituksen vastainen. Esitetyn vahvistusvaatimuksen hyväksyminen johtaisi käytännössä siihen, että työntekijältä jäisi saamatta toisen vuosiloman aikana vapaaksi työehtosopimuksessa tarkoitettu yhden viikon työjakso.
Suomen Merimies-Unioni SM-U ei myöskään ollut ryhtynyt työehtosopimuslain 8 §:n vastaiseen työtaistelutoimenpiteeseen. Edellä tarkoitetun 26.3.2003 allekirjoitetun pöytäkirjamääräyksen tarkoituksena oli, että Viking Line Abp ensin palauttaa niin sanotun vanhan käytännön ja sen jälkeen mahdollisista epäselvyyksistä voidaan Viking Line Abp:n aloitteesta neuvotella. Suomen Merimies-Unioni SM-U oli toiminut tämän määräyksen mukaisesti, eikä se ollut millään tavoin syyllistynyt työtaistelutoimenpiteeseen eikä pyrkinyt painostamaan Viking Line Abp:tä hyväksymään ulkomaanliikenteen matkustaja-alussopimuksen kanssa ristiriidassa olevaa tulkintaa. Tähän Suomen Merimies-Unioni SM-U:llä ei ole ollut tarvettakaan, koska Viking Line Abp oli edellä mainitulla pöytäkirjalla sitoutunut palauttamaan niin sanotun vanhan käytännön.

TYÖTUOMIOISTUIMEN RATKAISU
Perustelut
1. Tausta ja erimielisyys
Suomen Merimies-Unioni SM-U:n riitautettua Viking Line Abp:n menettelyn oli järjestön ja varustamon välillä 26.3.2003 tehdyn matkustaja-alussopimuksen mukaisten aluskohtaisten sopimusten uudistamisen yhteydessä sovittu, että Viking Line Abp palauttaa osa-aikatyöntekijöiden palkanmaksun ja vuorottelun osalta käytännön, jota oli noudatettu ennen 1.1.2003. Samassa yhteydessä oli sovittu myös siitä, että osapuolet käynnistävät Viking Line Abp:n aloitteesta neuvottelut, joiden päämääränä on selvittää osa-aikatyötä tekevien vuosilomaetuihin liittyvät kysymykset ja mahdolliset epäselvyydet.
Osittaisella hoitovapaalla olevien vuosiloman sijoittamisesta oli sittemmin syntynyt erimielisyys, josta oli neuvoteltu työehtosopimukseen osallisten ja varustamon edustajien välillä 23.1.2004. Neuvottelussa oli sovittu, että varustamoa kehotetaan korjaamaan kaikkien osa-aikatyötä tekevien vuorottelulistat siten, että osittaisella hoitovapaalla olevien työntekijöiden osalta noudatetaan vuosiloman osalta samaa käytäntöä kuin osa-aikaeläkkeellä ja osatyökyvyttömyyseläkkeellä olevien kohdalla.
Suomen Merimies-Unioni SM-U on kanteessaan katsonut Viking Line Abp:n tietensä rikkoneen työehtosopimusta sen laatiessa osa-aikaisten työvuorolistat 1.1.2003 alkaen aikaisemmin noudatetusta poiketen ja jatkaneen menettelyä 26.3.2003 jälkeenkin sekä jättäessään oikaisematta osittaisella hoitovapaalla olevien työvuorolistat 23.1.2004 sovituin tavoin. Suomen Merimies-Unioni SM-U on lisäksi katsonut Viking Line Abp:n syyllistyneen painostustoimenpiteeseen tai työehtosopimuksen tieten rikkomiseen sen kieltäytyessä solmimasta uusia osa-aikaisia työsopimuksia osa-aikaeläkkeeseen oikeutettujen työntekijöiden kanssa ja edellyttäessään ehtona tällaisen työsopimuksen tekemiselle varustamon tulkinnan mukaista vuosiloman sijoittelua.
Ålands Redarförening ja Viking Line Abp ovat kanteessaan vaatineet vahvistettavaksi työehtosopimusmääräysten ja 26.3.2003 tehdyn pöytäkirjan oikeaksi tulkinnaksi sen, että osa-aikaisen työntekijän vuosittainen työaika on puolet 165 päivästä eli keskimäärin 82,5 työpäivää. Kanteessa on lisäksi katsottu Suomen Merimies-Unioni SM-U:n rikkoneen 26.3.2003 päivätyn sopimuksen määräystä sen kieltäytyessä käymästä pöytäkirjan mukaisia neuvotteluja ja tällä kieltäytymisellään myös syyllistyneen työtaistelutoimenpiteeseen.
2. Todistelu
2.1. Työehtosopimusmääräysten tulkinta
Työehtosopimusmääräysten ja 26.3.2003 tehdyn pöytäkirjan tulkinnasta ja asiaan liittyneistä neuvotteluista työtuomioistuimessa on kuultu Suomen Merimies-Unioni SM-U:n puolesta todistajana sopimussihteeri A:ta ja todistelutarkoituksessa puheenjohtaja B:tä. Samoista seikoista Ålands Redarföreningin ja Viking Line Abp:n puolesta on kuultu todistajana osastopäällikkö C:tä ja lisäksi henkilöstöpäällikkö D:tä erimielisyyteen liittyneistä neuvotteluista 26.3.2003 ja 18.6.2003. Kirjallisina todisteina asianosaiset ovat viitanneet todisteiksi jättämiinsä asiakirjoihin.
Uutta matkustaja-alussopimusta edeltäneessä työehtosopimuksessa oli sovittu säännöllisestä työajasta 8 tuntia vuorokaudessa ja 40 tuntia viikossa. Uuteen matkustaja-alussopimukseen otetut määräykset työpäivien lukumäärästä vuodessa ovat lähinnä ohjeelliset, koska vuorottelujärjestelmä 1:1 ei toimi kalenterin mukaan. Mainitussa vuorottelujärjestelmässä työntekijälle on taattu kummankin työehtosopimuksen mukaisen lomajakson aikana työviikko vapaaksi. Koska työpäivien pituus on erilainen eri vuorottelujärjestelmissä, on muiden kuin vuorottelujärjestelmä A:n osalta sovittu mahdollisuudesta käyttää vuosilomapäiviä vuorotteluun. Vuorottelujärjestelmää koskevissa määräyksissä tarkoitettu takuupalkka on eri vuorottelujärjestelmissä samansuuruinen samaa työtä tekevillä.
B on kertonut, että uuden matkustaja-alussopimuksen voimaantulon yhteydessä ei ollut tarkoitus puuttua osa-aikaisten asemaan millään tavoin. Uuden työehtosopimuksen laatimisen tavoitteena oli ollut luoda uusi palkkausjärjestelmä, jossa takuupalkka on kaikissa vuorottelujärjestelmissä yhtä suuri. Työvuorojen pituuden vaihtelu eri vuoroissa on vaikuttanut siihen, että joissakin vuorottelujärjestelmissä vuosilomaa on sovittu käytettäväksi vuorotteluun. Työehtosopimuksen 5.9. kohdissa mainitut työpäivien lukumäärät eri vuorottelujärjestelmissä ovat lähinnä esimerkinomaisia.
C on ollut Suomen Varustamoyhdistyksen edustajana niissä työehtosopimusneuvotteluissa, joissa on sovittu vuonna 1998 voimaantulleen työehtosopimuksen osa-aikatyötä koskevasta liitteestä samoin kuin 1.3.2001 voimaantullutta uutta ulkomaanliikenteen matkustaja-alussopimusta koskeneissa neuvotteluissa. Viimeksi mainituissa neuvotteluissa ei ollut käsitelty osa-aikatyöntekijöitä koskevia määräyksiä. Työehtosopimuksen vuorottelujärjestelmämääräyksistä sovittaessa tarkoituksena ei ollut, että osa-aikaisia ja kokoaikaisia työntekijöitä kohdeltaisiin eri tavoin. Eri vuorottelujärjestelmien takuupalkkaan sisältyvät vuorokautisen työajan pituudet vaihtelevat, mistä syystä eri vuorottelujärjestelmissä työpäivien lukumäärä vuodessa myös on erisuuruinen. Kaikissa vuorottelujärjestelmissä vuosittainen työtuntien lukumäärä on kuitenkin sovittu suunnilleen yhtä suureksi ja myös takuupalkka eri vuorottelujärjestelmissä on samansuuruinen.
Työehtosopimusneuvotteluissa ei ollut tullut esille se, että vuorottelujärjestelmässä A osa-aikaisten vuosilomat tulisi sijoittaa siten, että vuosiloma osuu vuorottelujärjestelmän työjaksoihin. Osa-aikatyötä koskevan liitteen 6 kohtaan vuonna 2001 otettu määräys toisen kahden peräkkäisen lomanmääräytymiskauden loman käyttämisestä vuorotteluun uuden matkustaja-alussopimuksen työehtosopimuksen 5.9.2 ja 5.9.3 mainituin tavoin, on C:n mukaan johtunut siitä, että näissä työehtosopimuskohdissa tarkoitetuissa vuorottelujärjestelmissä ei työehtosopimuksen mukainen työaika muutoin täyty. Työvuoroluettelon laadinnassa ensisijainen kysymys on C:n mukaan työehtosopimuksen mukaisen työajan toteutuminen, mikä ei voi riippua vuorottelun järjestämisestä.
2.2. Työehtosopimuksen vastainen menettely
B on kertonut, että Viking Line Abp:n ja Suomen Merimies-Unioni SM-U:n välillä oli vuoden 2003 maaliskuun jälkeen käyty 26.3.2003 pöytäkirjassa tarkoitettuja neuvotteluja osa-aikaisten työntekijöiden vuosilomiin liittyvistä epäselvyyksistä. Näissä neuvotteluissa varustamo oli pyrkinyt saamaan läpi oman tulkintansa, mikä oli Suomen Merimies-Unioni SM-U:n puolella koettu pyrkimykseksi muuttaa työehtosopimusta. Työehtosopimusosapuolten ja varustamon edustajien välillä 18.6.2003 käydyssä neuvottelussa Suomen Merimies-Unioni SM-U:n puolelta oli todettu, ettei se neuvottele työehtosopimusmuutoksista työnantajapuolen kanssa, ennen kuin Viking Line Abp ryhtyy noudattamaan aikaisempaa käytäntöä.
3. Arviointi ja johtopäätökset
3.1. Työehtosopimusmääräysten tulkinta
Työehtosopimuksen osa-aikatyötä koskevan liitteen 1 kohdasta ilmenevin tavoin osa-aikatyöntekijällä tarkoitetaan henkilöä, jonka säännöllinen työaika on puolet samanlaista työtä tekevän kokoaikaisen työntekijän säännöllisestä työajasta. Liitteen 2 kohdassa on osa-aikaisen työntekijän palkasta todettu, että osa-aikatyöntekijän päiväpalkka on ½ samanlaista työtä tekevän kokoaikaisen työntekijän päiväpalkasta.
Maaliskuun alussa 2001 voimaantulleesta uudesta matkustaja-alussopimuksesta sovittaessa ei osa-aikaisten asema ole ollut varsinaisesti esillä eikä sitä ole ollut tarkoitus asiallisesti muuttaa. Liitteen 2 kohdassa palkka-sana on tuolloin korvattu uuden matkustaja-alussopimuksen mukaisella takuupalkalla. Lisäksi liitteen vuosilomaa koskevaan 6 kohtaan on otettu myös nykyisin voimassa oleva määräys, jonka mukaan toinen kahden peräkkäisen lomanmääräytymiskauden lomista voidaan käyttää vuorotteluun ulkomaanliikenteen matkustaja-alussopimuksen kohdissa 5.9.2 ja 5.9.3 mainitulla tavalla ja toinen on annettava yhdenjaksoisena toukokuun 2. päivän ja syyskuun 30. päivän välisenä aikana.
Matkustaja-alussopimuksen 5.9.-kohdassa on sovittu eri vuorottelujärjestelmien osalta takuupalkkaan sisältyvästä vuorokautisesta työajasta, työpäivien lukumäärästä vuodessa, 35 päivän vuosilomasta sekä vapaajaksojen ja lomien antamisesta kussakin vuorottelujärjestelmässä. Uudesta työehtosopimuksesta sovittaessa tavoitteena on ollut luoda palkkausjärjestelmä, jossa takuupalkka on kaikissa vuorottelujärjestelmissä yhtä suuri. Eri vuorottelujärjestelmien kohdalla vuorokautisesta työajasta ja työpäivien lukumäärästä vuodessa on myös sovittu siten, että vuosittaisten työtuntien lukumäärä eri vuorottelujärjestelmissä on lähes samansuuruinen. Tähän nähden ei työtuomioistuimen mielestä voida pitää perusteltuna sitä kantaa, että sopimuksessa mainituille vuotuisten työpäivien lukumäärälle ei olisi tarkoitettu antaa merkitystä laadittaessa vuorottelujärjestelmän työvuorolistaa.
Esitetyn selvityksen mukaan sopiminen vuosiloman käyttämisestä vuorotteluun vuorottelujärjestelmissä B ja C on johtunut siitä, että muussa tapauksessa kokoaikaisen työntekijän kohdalla ei toteudu työehtosopimuksen mukainen vuosittainen työaika. Tätä tarvetta ei ole ollut Viking Line Abp:n käyttämässä vuorottelujärjestelmässä A, jossa työaika muutoinkin tasoittuu sovittuun 165 työpäivään vuodessa. Näin ollen pelkästään siitä, että osa-aikatyötä koskevan liitteen 6 kohdassa ei ole viitattu järjestelmään A (5.9.1.) määriteltäessä, millä tavalla toinen osa osa-aikaisen työntekijän vuosilomasta voidaan käyttää vuorotteluun, ei työtuomioistuimen mielestä voida päätellä tarkoitetun, etteikö osa-aikatyöntekijän vuorottelujärjestelmää laadittaessa myös tässä järjestelmässä olisi lähtökohtana työehtosopimuksessa sovittu vuotuisten työpäivien lukumäärä.
Osa-aikatyötä koskevan liitteen 1 kohdan mukaan osa-aikatyöntekijän työaika on puolet kokoaikaisen työntekijän työajasta, mikä vuorottelujärjestelmässä A merkitsee sitä, että osa-aikaisen työntekijän vuotuisten työpäivien lukumääräksi tulee 82,5. Sen sijaan Suomen Merimies-Unioni SM-U:n sovellettavaksi vaatiman järjestelmän mukaan vuotuisten työpäivien lukumääräksi tulisi 77 - 78 työpäivää. Kun takuupalkka työehtosopimuksessa todetuin tavoin on sidoksissa työaikaan, merkitsisi Suomen Merimies-Unioni SM-U:n tulkinta vuorottelujärjestelmässä A osa-aikaisten työntekijöiden saattamista kokoaikaisia työntekijöitä parempaan asemaan.
Mikäli työehtosopimusosapuolten tarkoituksena olisi ollut, että vuorottelujärjestelmän toteuttamisella osa-aikaisen työntekijän kohdalla vuotuinen työaika muodostuisi pienemmäksi kuin puolet kokoaikaisen työntekijän työajasta, olisi tämä työtuomioistuimen mielestä edellyttänyt nimenomaista sopimista asiasta. Näin ei kuitenkaan ole tapahtunut, eikä asia myöskään ole ollut esillä työehtosopimusneuvotteluissa.
Näin ollen työtuomioistuin katsoo ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1-kohdan sekä ulkomaanliikenteen matkustaja-alussopimuksen osa-aikatyötä koskevan liitteen 1 kohdan oikeaksi tulkinnaksi sen, että vuorottelujärjestelmässä A osa-aikaisen työntekijän vuosittainen työaika on puolet 165 päivästä eli keskimäärin 82,5 päivää. Viking Line Abp on siten voinut 1.3.2002 alkaen toteuttaa osa-aikaisten vuorottelujärjestelmän pitäen lähtökohtana sitä, että työpäivien lukumäärä on 82,5 vuodessa.
3.2. Työehtosopimuksen vastainen menettely
Suomen Merimies-Unioni SM-U:n kanteen johdosta työtuomioistuin toteaa, että esitetyn näytön perusteella epäselväksi on jäänyt, onko Viking Line Abp 26.3.2003 tehdyssä pöytäkirjassa sovitun mukaisesti oikaissut osa-aikaeläkkeellä ja osittaisella hoitovapaalla olevien osalta työvuorolistat aikaisemman käytännön mukaiseksi. Kun Viking Line Abp:n käytäntöä ei kuitenkaan ole katsottu työehtosopimuksen vastaiseksi, ei Viking Line Abp:n voida katsoa tietensä rikkoneen työehtosopimusta tai 26.3.2003 tehdyn pöytäkirjan määräyksiä. Näyttämättä on myös jäänyt, että Viking Line Abp olisi kieltäytynyt solmimasta uusia osa-aikaisia työsopimuksia tai edellyttänyt ehtona sopimisella varustamon tulkinnan hyväksymistä ja siten syyllistynyt työtaistelutoimenpiteeseen tai työehtosopimuksen tieten rikkomiseen. Näin ollen ei myöskään Ålands Redarförening ole laiminlyönyt asiassa valvontavelvollisuuttaan.
4. Oikeudenkäyntikulut
Asia on ollut siinä määrin epäselvä, että asianosaisilla puolin ja toisin on ollut aihe saattaa asia työtuomioistuimeen ratkaistavaksi. Tämän vuoksi työtuomioistuin siitä annetun lain 33a §:n nojalla katsoo, että Ålands Redarförening ja Viking Line Abp asian osittain voittaessaankin saavat pitää oikeudenkäyntikulunsa vahinkonaan.

Tuomiolauselma
Suomen Merimies-Unioni SM-U:n kanne hylätään.
Työtuomioistuin Ålands Redarföreningin ja Viking Line Abp:n kanteen siten hyväksyen vahvistaa, että ulkomaanliikenteen matkustaja-alussopimuksen 5.9.1-kohdan ja ulkomaanliikenteen matkustaja-alussopimuksen osa-aikatyötä koskevan liitteen 1 kohdan mukaan osa-aikaisen työntekijän vuosittainen työaika vuorottelujärjestelmässä A on puolet 165 päivästä eli keskimäärin 82,5 päivää.
Suomen Merimies-Unioni SM-U:ta vastaan esitetty hyvityssakkovaatimus hylätään.
Ålands Redarförening ja Viking Line Abp saavat pitää oikeudenkäyntikulunsa vahinkonaan.
Asian ratkaisemiseen ovat osallistuneet Orasmaa puheenjohtajana sekä Suviranta, Virtanen, Vannela, Vertanen ja Vuorio jäseninä. Sihteeri on ollut Laurila.
Tuomio on yksimielinen.

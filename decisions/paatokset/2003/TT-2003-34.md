# TT:2003-34

## Suomeksi

Kysymys siitä, oliko rajavartiolaitoksen yhteistoimintasopimusta rikottu virkamiehen siirtoa koskevassa asiassa.
Valtiovarainministeriö oli oikea vastaaja kanteeseen, jossa vaadittiin valtion tuomitsemista hyvityssakkoon sillä perusteella, että rajavartiolaitos oli rikkonut tietensä virkaehtosopimusta.
Kanne jätetty tutkimatta siltä osin kuin se kohdistui seikkaan, josta ei ollut käyty erimielisyysneuvotteluja. Ks. myös TT 2002-92.

YHTEISTOIMINTASOPIMUKSEN MÄÄRÄYKSET
Rajavartiolaitoksen esikunnan ja toiselta puolen muun muassa Rajavartioliitto ry:n välillä 12.12.2000 allekirjoitetussa virkaehtosopimuksena voimassa olevassa virastokohtaisessa sopimuksessa yhteistoiminnasta rajavartiolaitoksessa on muun ohella seuraavat määräykset:
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
1 § Sopimuksen tarkoitus
Rajavartiolaitoksen ja sen henkilöstön tässä sopimuksessa sovittavan yhteistoiminnan tarkoituksena on antaa henkilöstölle vaikutusmahdollisuus työhönsä ja työoloihinsa vaikuttavaan, rajavartiolaitoksen toimintaa koskevaan päätöksentekoon ja samalla edistää rajavartiolaitoksen toiminnan tuloksellisuutta ja taloudellisuutta.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
3 § Rajavartiolaitoksen velvollisuus edistää yhteistoimintaa
Rajavartiolaitoksen tulee järjestäessään organisaatiotaan, henkilöstön työtehtäviä ja johtamista, toimia siten, että järjestelyt edistävät myös henkilöstön ja esimiesten sekä henkilöstön keskinäistä yhteistoimintaa ja tuloksellista työskentelyä sekä antavat henkilöstön kuuluville mahdollisuuden vaikuttaa työnsä sisältöön ja työympäristöön ja saada tietoja työnsä tavoitteista, merkityksestä ja tuloksista.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
11 § Yhteistoimintamenettelyn piiriin kuuluvat asiat
1) henkilöstön asemaan vaikuttavat olennaiset muutokset työtehtävissä, työmenetelmissä ja tehtävien järjestelyssä sekä siirrot toisiin tehtäviin, toiseen valtion virkaan tai pysyvästi toiselle paikkakunnalle;
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
3) rajavartiolaitoksen ja sen osan lakkaaminen tai siirto toiselle paikkakunnalle, rajavartiolaitoksen tai sen osan tehtävien tai henkilöstön siirrosta taikka virkojen lakkaamisesta vapautuvien määrärahojen siirrosta toiseen virastoon aiheutuvat henkilöstövaikutukset luovuttavassa ja vastaanottavassa virastossa sekä viraston tai sen osan toiminnan laajentaminen tai supistaminen;
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
11) sisäisen tiedotustoiminnan periaatteet;
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
12 § Yhteistoimintamenettely
Rajavartiolaitoksen on ennen 11 §:ssä tarkoitetun asian ratkaisemista neuvoteltava valmisteilla olevan toimenpiteen perusteista, vaikutuksista ja vaihtoehdoista niiden virkamiesten ja työntekijöiden kanssa, joita asia koskee, tai heidän edustajiensa kanssa.
Neuvottelumenettely aloitetaan asian sellaisessa suunnittelu- ja valmisteluvaiheessa, jossa yhteistoiminnan tarkoituksena oleva vuorovaikutus sekä vaihtoehtoihin ja asiaan vaikuttaminen voi myös käytännössä toteutua.
Yhteistoimintamenettelyssä käsitellään yhdessä valmisteilla olevan toimenpiteen perusteita, vaikutuksia ja vaihtoehtoja. Menettelyn tarkoituksena on lisätä osapuolten tietoja sekä yhteneviä käsityksiä asiasta ja edistää yhteisymmärrykseen pääsyä.
Rajavartiolaitoksen tulee ennen yhteistoimintamenettelyn aloittamista antaa asian käsittelyn kannalta tarpeelliset tiedot asianosaisille virkamiehille tai työntekijöille sekä asianomaisille henkilöstön edustajille. Nämä tiedot, kuten tiedot suunnitellun vähentämisen perusteista, arvio vähentämisen kohteeksi joutuvien virkamiesten tai työntekijöiden lukumääristä eri ryhmissä, arvio ajasta, jonka kuluessa suunnitellut vähentämiset aiotaan toteuttaa, sekä tiedot periaatteista, joiden mukaan vähentämisen kohteena olevat virkamiehet tai työntekijät määräytyvät, on annettava kirjallisesti, jos virasto harkitsee vähintään kymmenen virkamiehen tai työntekijän osa-aikaistamista tai irtisanomista taikka lomauttamista yli 90 päiväksi.
Yksittäistä virkamiesta tai työntekijää koskeva asia käsitellään ensisijaisesti työnantajan ja tämän henkilön välillä. Milloin työnantaja taikka virkamies tai työntekijä häntä koskevassa kysymyksessä niin vaatii, on asiasta neuvoteltava myös työnantajan ja asianomaisen henkilöstön edustajan kanssa. Samoin työyksikkökokous voi vaatia, että siellä käsiteltävä asia käsitellään myös työnantajan ja asianomaisten henkilöstön edustajien kesken tai asianomaisessa yhteistoimintalautakunnassa.
Rajavartiolaitoksen siirtymisvelvollisuutta koskeviin säännöksiin perustuva virkamiehen tai työntekijän siirto toiseen tehtävään, toiseen valtion virkaan tai pysyvästi toiselle paikkakunnalle käsitellään kuitenkin vain työnantajan ja kysymyksessä olevan henkilön välillä.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
Jos yhteistoimintamenettelyssä käsiteltävän asian laajuus tai vaikeaselkoisuus sitä edellyttää, henkilöstön edustajille on varattava mahdollisuus kuulla rajavartiolaitoksessa työskentelevää asiantuntijaa. Jos rajavartiolaitos käyttää ulkopuolista asiantuntijaa sellaisessa tehtävässä, joka tämän sopimuksen mukaan kuuluu yhteistoimintamenettelyn piiriin, myös henkilöstön edustajille on varattava mahdollisuus kuulla kyseistä asiantuntijaa.
14 § Neuvottelumenettelyn päättyminen
Yhteistoimintamenettelyssä todetaan, milloin menettely on päättynyt.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
19 § Neuvottelujen kirjaaminen
Yhteistoimintamenettelyssä kuuluvasta neuvottelusta laaditaan pöytäkirja, johon kirjataan kokouksen ajankohta, osallistujat, neuvottelun tulos tai osapuolten kannanotot. Puheenjohtaja allekirjoittaa pöytäkirjan ja henkilöstön edustajat tarkastavat pöytäkirjan.
Pöytäkirja on lähetettävä tiedoksi yhteistoimintamenettelyyn osallistuneille sekä sille virkamiehelle, joka ratkaisee yhteistoimintamenettelyssä käsitellyn asian.
= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =
21 § Tiedottaminen yhteistoimintamenettelyssä
Yhteistoimintamenettelyn piiriin kuuluvassa asiassa tekemästään ratkaisusta rajavartiolaitoksen on viivytyksettä tiedotettava asianomaisille virkamiehille ja työntekijöille sekä heidän edustajilleen.
Rajavartiolaitoksen tulee ennen yhteistoimintamenettelyyn ryhtymistä antaa asianomaisille henkilöstöön kuuluville ja heidän edustajilleen asian käsittelyn kannalta tarpeelliset tiedot. Nämä tulee antaa sellaisessa vaiheessa ja siinä muodossa, että niihin perehtyminen ja 11 §:ssä tarkoitettu asiaan vaikuttaminen on mahdollista.
Edellä tarkoitetut tiedot annetaan kirjallisina, mikäli se on tarpeen ja mahdollista asian laatu ja laajuus huomioon ottaen. Luonnos rajavartiolaitoksen tulo- ja menoarvioehdotukseksi, toiminta- ja taloussuunnitelmaehdotus, tulossuunnitelmaehdotus, tulo- ja menosääntöehdotus (tarkistuksineen), ehdotukset henkilöstösuunnitelmaksi ja koulutussuunnitelmaksi sekä tilinpäätöstiedot annetaan kirjallisina.
Milloin tiedottamisen perusteltuna esteenä ovat rajavartiolaitoksen toiminnan vaarantuminen tai muut erittäin painavat syyt, rajavartiolaitoksen on tiedotettava asiasta viivytyksettä sen jälkeen, kun mainittuja esteitä ei enää ole.

KANNE
Vaatimukset
Palkansaajajärjestö Pardia ry on vaatinut, että työtuomioistuin
vahvistaa rajavartiolaitoksen esikunnan rikkoneen rajavartiolaitoksen yhteistoimintasopimusta vanhemman rajavartijan A:n siirtoa koskeneessa asiassa.
tuomitsee Suomen valtion virkaehtosopimuslain 19 §:n 1 momentin ja 20 §:n nojalla maksamaan kantajalle hyvityssakkoa virkaehtosopimuksen rikkomisesta ja
velvoittaa Suomen valtion korvaamaan kantajan oikeudenkäyntikulut laillisine korkoineen

Perusteet
Rajavartiolaitoksen esikunta on A:n siirtoa Suomenlahden merivartiostosta Pohjois-Karjalan rajavartiostoon koskeneessa asiassa rikkonut tahallaan rajavartiolaitoksen yhteistoimintasopimuksen edellä tarkoitettuja määräyksiä.
Rajavartiolaitoksen esikunta ei ole antanut A:lle mahdollisuutta vaikuttaa työtään ja työolosuhteitaan koskevaan, rajavartiolaitoksen toimintaan vaikuttavaan päätöksentekoon. Se on A:n työtehtäviä järjestäessään laiminlyönyt toimia siten, että järjestelyt edistävät henkilöstön ja esimiesten sekä henkilöstön keskinäistä yhteistoimintaa ja tuloksellista työskentelyä sekä antavat A:lle mahdollisuuden vaikuttaa työnsä sisältöön ja työympäristöön ja saada tietoa työnsä tavoitteista, merkityksestä ja tuloksista.
Rajavartiolaitoksen esikunta on myös laiminlyönyt velvoitteensa neuvotella ja käsitellä yhdessä A:n kanssa tämän siirron perusteita, vaikutuksia ja vaihtoehtoja ja niinikään laiminlyönyt aloittaa neuvottelut sellaisessa suunnittelu- ja valmisteluvaiheessa, jossa yhteistoiminnan tarkoitus voi myös käytännössä toteutua. Rajavartiolaitoksen esikunta ei ole antanut A:lle asian käsittelyn kannalta tarpeellisia tietoja. Se ei myöskään ole todennut, milloin yhteistoimintamenettely on päättynyt. Yhteistoimintamenettelystä ei ole laadittu asianmukaista pöytäkirjaa, sitä ei ole toimitettu A:lle tiedoksi eikä esikunta myöskään ole tiedottanut viipymättä A:lle siirtoasiassa tekemästään ratkaisusta.
Työnantajan menettely osoittaa yhteistoimintasopimuksen tahallista laiminlyöntiä. Sen vuoksi hyvityssakon tuomitseminen on välttämätöntä.
Rajavartiolaitoksen esikunnan ja Rajavartioliitto ry:n välinen paikallisneuvottelu 28.1.2002 on päättynyt erimielisenä.

VASTAUKSET
Vastaus kannevaatimuksiin
Valtiovarainministeriö on kiistänyt kanteen, vaatinut sen jättämistä tutkimatta siltä osin kuin siinä on vaadittu tuomitsemista hyvityssakkoon ja myös siltä osin kuin vaatimukset kohdistuvat aikaan ennen 11.4.2001 tehtyä siirtosuunnitelmaa, sekä muilta osin kanteen hylkäämistä ja oikeudenkäyntikulujen korvaamista laillisine korkoineen.

Oikeudenkäyntiväitteiden perusteet
Valtiovarainministeriötä ei voida tuomita hyvityssakkoon, mikäli rajavartiolaitoksen katsotaan rikkoneen yhteistoimintasopimusta. Työtuomioistuimesta annetun lain 13 §:n mukaan hyvityssakkoon tuomitseminen edellyttää, että väitettyyn rikkomiseen syyllistynyt, tässä tapauksessa rajavartiolaitos, haastetaan työtuomioistuimeen vastaajaksi.
Rajavartiolaitoksen esikunnan ja Rajavartioliiton välillä pidettiin 13.9.2001 paikallisneuvottelut vanhemman rajavartijan A:n siirrosta Suomenlahden merivartiostosta Pohjois-Karjalan rajavartiostoon. Neuvotteluista laaditusta pöytäkirjasta käy ilmi, että erimielisyyden kohteena on ollut A:n suunniteltu siirto Suomenlahden merivartiostosta Pohjois-Karjalan rajavartiostoon 1.8.2001 lukien. Myös Rajavartioliitto on yksilöinyt paikallisneuvotteluvaatimuksessaan erimielisyyden koskemaan Rajavartiolaitoksen esikunnan tekemää siirtosuunnitelmaa ja tähän liittyen rajavartiolaitoksen yhteistoimintasopimuksen määräyksien tulkintaa.
Erimielisyysneuvottelut on siten käyty ainoastaan 11.4.2001 tehdystä siirtosuunnitelmasta. Neuvotteluissa ei ollut vaadittu käsiteltäväksi eikä ollut käsitelty vuonna 2000 käynnistynyttä, mutta sittemmin keskeytynyttä siirtohanketta. Erimielisyys voidaan saattaa työtuomioistuimen käsiteltäväksi vain, jos erimielisyysneuvottelut on saatettu päätökseen. Sen vuoksi 11.4.2001 edeltäneillä tapahtumilla ei ole merkitystä tässä asiassa.

Kanteen kiistämisen perusteet
Rajavartiolaitoksen esikunnan siirtosuunnitelma on päivätty 11.4.2001. Sen mukaan A olisi siirretty Suomenlahden merivartiostosta Pohjois-Karjalan rajavartiostoon 1.8.2001 lukien. Suunnitelmassa on edelleen maininta velvollisuudesta käydä yhteistoimintaneuvottelut. A:n suunnitellun siirron yhteydessä työnantaja pyrki toteuttamaan yhteistoimintasopimuksen mukaisen neuvottelumenettelyn saattamalla aluksi A:lle tiedoksi toimistopäällikön allekirjoittaman pöytäkirjan siirron suunnittelusta. Ongelmaksi jäi, ettei A palauttanut hänelle toimitettua pöytäkirjaa tai häntä ei muutoin tavoitettu silloin, kun neuvotteluesitys mahdollisesta siirrosta olisi tullut tehdä.
Työnantaja yritti selvittää, mistä muualta A:ta voisi tavoittaa neuvottelujen käynnistämiseksi. A:n todettiin olevan Aslak-kuntoutuksessa Turussa 21.5. - 1.6.2001. Koska B:llä ja D:llä oli tuolloin työesteitä, B määräsi samaan kuntoutukseen osallistuvan yliluutnantti C:n käymään A:n siirtoa koskevan yhteistoimintaneuvottelun. C:n määrääminen tähän tehtävään on siirtomenettelystä annetun määräyksen mukaista. Henkilöstötoimistosta annettiin lisäksi C:lle tarvittavat tiedot ja ohjeet A:n siirron syistä, perusteista, vaikutuksista ja vaihtoehdoista.
A ei suostunut allekirjoittamaan neuvotteluesitystä, eikä myöskään käymään asiasta neuvotteluja C:n kanssa. C toimitti tämän jälkeen pöytäkirjan ja huomautuksensa rajavartiolaitoksen esikuntaan. Rajavartiolaitoksen esikunta teki 13.6.2001 päätöksen A:n siirtämisestä Pohjois-Karjalan rajavartiostoon. Siirtopäätöksen tiedoksianto annettiin kapteeniluutnantti D:n tehtäväksi. A:ta ei kuitenkaan saatu tavoitettua puhelimitse, ja postitse lähetetty tiedoksiantopäätös palautui ilmoituksin saaja/osoite tuntematon. Eräiden tietojen mukaan A olisi oleskellut heinäkuussa Joensuun lähistöllä, minkä vuoksi Suomenlahden merivartiosto pyysi virka-apua Pohjois-Karjalan rajavartiostolta tiedoksiannon perillesaamiseksi. Suomenlahden merivartioston palkkayhdyshenkilö E kertoi 20.7.2001 D:lle, että A oli soittanut hänelle 25.6.2001 ja hän oli lukenut siirtopäätöksen tuolloin A:lle. E oli kehottanut A:ta myös soittamaan D:lle siirtoasian takia. Laineen mukaan A oli täysin ymmärtänyt siirtopäätöksen.
A:n Suomenlahden merivartiostolle antamat osoitetiedot ovat olleet alusta asti väärät ja 29.3.2001 tapahtunutta muuttoaan hän ei ollut lainkaan ilmoittanut työnantajalle. Tästä johtuen kirjeitse tai puhelimitse tapahtunut yhteydenpito A:han ja siirtopäätöksen toimeksianto on ollut lähes mahdotonta. Pohjois-Karjalan rajavartiosto sai annettua siirtopäätöksen tiedoksi A:lle 2.8.2001.
Edellä mainitut olosuhteet huomioon ottaen Rajavartiolaitos on toiminut yhteistoimintasopimuksen mukaisesti. Neuvotteluesitys on pyritty antamaan A:lle tiedoksi sellaisessa vaiheessa, jossa A olisi voinut lausua kantansa siirtosuunnitelmaan sekä vaikuttaa asiaan. Neuvottelut on myös suunniteltu aloitettavaksi siten, että A:lla olisi tilaisuus vaikuttaa asiaan käytännössä. Rajavartiolaitos on pyrkinyt monin eri tavoin kuten telefaxilla, puhelimella ja kirjeitse antamaan A:lle tiedot yhteistoimintamenettelyn kannalta tarpeellisista tiedoista.
Rajavartiolaitos on pyrkinyt neuvottelemaan ja keskustelemaan A:n kanssa ennen asian ratkaisemista siirron syistä, perusteista, vaikutuksista ja vaihtoehdoista. A on kuitenkin itse kieltäytynyt käymästä yhteistoimintaneuvottelua siirrosta. Rajavartiolaitos on täyttänyt yhteistoimintasopimuksen mukaisen neuvottelumenettelyn. Neuvottelumenettelyn voidaan myös katsoa päättyneen. Yhteistoimintamenettelyyn kuuluvasta neuvottelusta laadittuun pöytäkirjaan ei A:sta johtuvasta syystä ole voitu kirjata hänen kantaansa asiaan.
Rajavartiolaitos on tehnyt siirtopäätöksen melko pian yhteistoimintaneuvottelun päättymisen jälkeen, koska rajavartiolaitoksen tietoon ei ollut tullut mitään sellaista syytä, jolla olisi voinut olla merkitystä asiassa. Rajavartiolaitos on myös pyrkinyt saattamaan siirtopäätöksen välittömästi tiedoksi A:lle. Päätöksen tiedoksiannossa on kuitenkin ollut edellä kuvattuja hankaluuksia. Tältäkin osin rajavartiolaitos on täyttänyt yhteistoimintasopimuksen mukaiset määräykset.
Yhteistoimintasopimuksen mukainen menettely edellyttää aktiivisuutta sekä työnantajalta että työntekijältä. A ei ole ollut halukas yhteistoimintasopimuksen mukaiseen neuvotteluun. A ei ole halunnut allekirjoittaa mitään yhteistoimintamenettelyä koskevia asiakirjoja. Hän ei ole kertonut työnantajalle käsitystään neuvottelumenettelyn kohteena olevasta siirrosta toiselle paikkakunnalle. A on salannut työnantajalta osoitteensa ja muut yhteystiedot tai antanut työnantajalle väärät yhteystiedot, mikä on haitannut merkittävästi työnantajan yrityksiä tavoittaa häntä neuvottelumenettelyn aloittamiseksi sekä antaa hänelle tiedoksi yhteistoimintamenettelyn jälkeen tehdyt päätökset. Mahdollista hyvityssakkoa arvioitaessa huomiota tulee joka tapauksessa kiinnittää A:n omaan käyttäytymiseen joko hyvityssakon kokonaan poistavana tekijänä tai ainakin sen määrää alentavana tekijänä.

TYÖTUOMIOISTUIMEN RATKAISU
Käsittelyratkaisut
Valtiovarainministeriö on vaatinut kanteen jättämistä siihen kohdistettuna tutkimatta ensinnäkin sillä perusteella, että kanne perustuu rajavartiolaitoksen työnantajana solmimaan virastokohtaiseen virkaehtosopimukseen. Koska kysymys ei ole tarkentavasta virkaehtosopimuksesta, kanne olisi tullut valtiovarainministeriön mukaan kohdistaa sopimuksen solmineeseen rajavartiolaitoksen esikuntaan. Työtuomioistuin on 31.12.2002 antamallaan päätöksellä nro 92 hylännyt valtiovarainministeriön oikeudenkäyntiväitteen.
Valtiovarainministeriö on edelleen vaatinut Suomen valtioon kohdistetun hyvityssakkovaatimuksen jättämistä tutkimatta. Työtuomioistuimesta annetun lain 13 §:n mukaan asianomainen taho, jota vastaan hyvityssakkovaatimus esitetään, on haastettava vastaamaan vaatimukseen. Kun rajavartiolaitoksen esikuntaa ei ole tässä tapauksessa haastettu työtuomioistuimeen vastaajaksi, ei hyvityssakkovaatimusta voida valtiovarainministeriön mukaan tutkia.
Väitteen johdosta työtuomioistuin toteaa, että työtuomioistuimesta annetun lain 13 §:n 3 momentin mukaan virkaehtosopimusta koskevaan kanteeseen vastaa sopimukseen osallinen omasta puolestaan ja niiden puolesta, jotka sen tekemän virkaehtosopimuksen johdosta ovat siihen sidotut. Se, jota vastaan kanteessa tehdään vaatimuksia, on kutsuttava myös itse asiassa kuultavaksi. Tässä tapauksessa sopimukseen osallinen ja myös väitetty sopimuksen rikkoja on Suomen valtio, jonka puhevaltaa käyttää valtiovarainministeriö valtion neuvotteluviranomaisena. Vaatimukset kohdistuvat lain tarkoittamassa mielessä Suomen valtioon siitä riippumatta, minkä valtion viranomaisen on väitetty sopimusta rikkoneen. Näin ollen valtiota vastaan vireille pantu kanne on myös tältä osin osoitettava valtionvarainministeriölle. Kun valtiovarainministeriö on siten oikea vastaaja myös hyvityssakkovaatimuksen osalta, työtuomioistuin hylkää oikeudenkäyntiväitteen perusteettomana.
Valtiovarainministeriö on edelleen vaatinut, että Palkansaajajärjestö Pardian kanne on jätettävä tutkimatta siltä osin kuin vaatimukset perustuvat 11.4.2001 edeltäneeseen aikaan. Asiassa käydyt erimielisyysneuvottelut ovat kohdistuneet vain 11.4.2001 päivättyyn siirtosuunnitelmaan ja sen jälkeiseen yhteistoimintamenettelyyn.
Yhteistoiminta-asioista johtuvista erimielisyyksistä on neuvottelumääräykset yhteistoimintamenettelyä koskevan sopimuksen 27 §:ssä. Jos sopimuksen soveltamisesta syntyy erimielisyyksiä, niistä tulee neuvotella samassa järjestyksessä kuin valtion virkaehtosopimusten neuvottelumenettelystä tehdyssä pääsopimuksessa on sovittu. Valtion virkaehtosopimusasioiden pääsopimuksen 7 §:n 2 momentin mukaan kanteen vireillepano työtuomioistuimessa edellyttää päätökseen saatettuja erimielisyysneuvotteluja.
Erimielisyysneuvotteluissa neuvottelukohteeksi on edellä todetun mukaisesti yksilöity kirjallisesti 13.6.2001 päätetty siirto ja sitä edeltänyt yhteistoimintamenettely. Neuvotteluja ei siten ole käyty 11.4.2001 edeltäneistä, toteutumatta jääneistä siirtohankkeista ja niihin liittyneistä menettelyistä. Tämän vuoksi työtuomioistuin hyväksyen valtiovarainministeriön oikeudenkäyntiväitteen jättää kanteen tutkimatta siltä osin kuin se perustuu 11.4.2001 edeltäneisiin tapahtumiin.
Pääasiaratkaisun perustelut
Neuvotteluvelvoitteen täyttäminen
Rajavartiolaitoksen yhteistoimintasopimuksen 11 §:n mukaan yhteistoimintamenettelyn piiriin kuuluu muun muassa henkilöstön siirto pysyvästi toiselle paikkakunnalle. Sopimuksen 12 §:n mukaan rajavartiolaitoksen on ennen 11 §:ssä tarkoitetun asian ratkaisemista neuvoteltava valmisteilla olevan toimenpiteen perusteista, vaikutuksista ja vaihtoehdoista virkamiehen kanssa, jota asia koskee.
Työtuomioistuimessa todistajana kuullun, aiemmin toimistopäällikkönä henkilöstöasioita hoitaneen ja myös A:n siirtoa valmistelleen kapteeniluutnantti D:n mukaan henkilöstön siirrot hallintoyksiköstä toiseen tapahtuvat rajavartiolaitoksessa pääsääntöisesti vapaaehtoisesti. Vuosittain hallintoyksiköiden välisiä siirtoja on kymmeniä. Siirtoja tapahtuu paljon myös pääkaupunkiseudulta maakuntaan.
D:n mukaan siirtomenettely edellyttää aina rajavartiolaitoksen tekemää siirtosuunnitelmaa, jonka jälkeen asia etenee hallintoyksikköön. Hallintoyksikkö käynnistää yhteistoimintaneuvottelut. Neuvottelualoite toimitetaan virkamiehelle tiedoksi pääsääntöisesti kirjallisesti. Siirroissa, jotka yleensä tapahtuvat vapaaehtoisesti, yhteistoimintaneuvottelut myös etenevät kirjallisesti. Vain poikkeustapauksissa työnantaja ja virkamies neuvottelevat henkilökohtaisesti. Siirtoperusteena voi olla esimerkiksi palveluksen asianmukainen järjestäminen tai virkamiehen lisäkoulutus, jolloin siirto tapahtuu vaativampiin tehtäviin. Koska vastaanottava yksikkö nimittää virkamiehen uuteen tehtävään, vielä yhteistoimintaneuvotteluvaiheessa ei välttämättä tiedetä, mihin yksikköön virkamies tullaan sijoittamaan.
D:n mukaan yhteistoimintaneuvottelut käydään tavallisesti siten, että neuvottelupöytäkirja lähetetään työpaikalle ja asianomainen esimies kuittauttaa päätöksen ja palauttaa sen henkilöstöhallinnon jatkokäsittelyyn. Neuvottelupöytäkirjan lähettämisellä virkamiehelle avataan keskusteluyhteys. Asioista on ollut aina mahdollista neuvotella, mutta tavanomaista kirjallista menettelyä laajempien yhteistoimintaneuvottelujen toteuttaminen on virkamiehen oman aloitteellisuuden varassa. Koskaan aikaisemmin rajavartiolaitoksessa ei ole riitautettu yhteistoimintamenettelyssä noudatettua käytäntöä.
A:n asiassa käydyistä yhteistoimintaneuvottelusta on kuultu todistajina yliluutnantti C:tä, luottamusmies F:ää, D:tä ja henkilöstötoimiston päällikköä B:tä.
A:n siirtosuunnitelmaa oli valmisteltu jo vuoden 2000 puolella. B oli tehnyt uuden neuvotteluesityksen edellisen neuvottelupöytäkirjan pohjalta. B:n mukaan toukokuussa 2001 ei enää erikseen keskusteltu siirron perusteista, koska jo aikaisemmin joulukuussa 2000 oli tehty A:ta koskeva siirtosuunnitelma, mutta A oli tuolloin jättänyt neuvotteluasiakirjat palauttamatta.
A:n sijoituspaikan eli lentoaseman rajavartioston henkilöstö ei ollut tavoittanut A:ta yhteistoimintaneuvottelujen käymiseksi. Työnantajan tiedossa oli, että sekä A että C osallistuisivat Aslak-kuntoutukseen Turussa 21.5. - 1. 6.2001. Koska B:llä itsellään ei ollut mahdollisuutta käydä yhteistoimintaneuvotteluja, tehtävään valittiin kuntoutukseen osallistunut C. Yhteistoimintaneuvotteluja varten B oli antanut C:lle kirjalliset ohjeet, jotka sisälsivät siirtosuunnitelman ja neuvottelupöytäkirjan. C:n oli määrä saada A:n allekirjoitus neuvottelupöytäkirjaan. C oli ilmoittanut A:lle tätä koskevasta siirtosuunnitelmasta ja yhteistoimintaneuvottelujen käymisestä 22.5.2001, jolloin he olivat sopineet yhteistoimintaneuvottelujen ajaksi 31.5.2001. B:n vaatimuksesta neuvotteluajankohtaa kuitenkin aikaistettiin ja neuvottelut käytiin 26.5.2001.
B on kertonut, että syynä yhteistoimintaneuvottelun varhentamiseen oli se, että kolmen kuukauden määräaika päätöksen tekemisestä siirtoajankohtaan ei olisi ehtinyt muutoin toteutua, ja rajavartiolaitoksen esikunta olisi joutunut tekemään taas uuden siirtosuunnitelman. Rajavartiolaitoksen ohjeiden mukaan virkamiehelle tulee antaa siirtopäätös tiedoksi kolme kuukautta ennen siirtopäätöksen toimeenpanemista. Jos aikarajoissa ei pysytä, virkapaikka muuttuu vasta sen jälkeen, kun kolmen kuukauden määräaika on kulunut. Tämä tarkoittaa sitä, että virkamies on virkamatkalla uudessa työpaikassaan niin kauan kuin kolmen kuukauden määräaika täyttyy ja työnantaja on velvollinen maksamaan virkamiehelle matkakustannukset ja päivärahat.
C oli yhteistoimintaneuvotteluissa ilmoittanut A:lle asiakirjoista ilmenevät päätöksen perusteet, mutta hän ei ollut osannut vastata A:n kysymykseen siirron tarkemmista perusteista. A ja C ovat kertoneet jossakin määrin eri tavoin neuvottelujen kulusta. Joka tapauksessa A oli kieltäytynyt allekirjoittamasta neuvottelupöytäkirjaa. Sen sisältö, C:n ja paikalla olleen todistajan merkinnät ja asiakirjan tuleva jatkokäsittely olivat kuitenkin tulleet A:n tietoon. Hän oli myös ilmaissut mahdollisesti palaavansa asiaan. A:n mukaan C oli kesken neuvottelun soittanut B:lle ja välittänyt A:n pyynnön neuvotella asiasta suoraan esimiehensä kanssa. C tai B eivät kuitenkaan ole työtuomioistuimessa kuultaessa muistaneet, että tällainen puhelinkeskustelu olisi tuolloin käyty.
C:n kertoman mukaan hän on esimiehenä myös aiemmin käynyt vastaavia neuvotteluja. Siirrettävät henkilöt ovat kirjanneet pöytäkirjaan kantansa perusteluineen. Jos kanta siirtoon on ollut kielteinen, henkilöön on otettu yhteyttä mahdollisia lisäneuvotteluja varten tai sen ilmoittamiseksi, että siirto tehdään joka tapauksessa. Jokainen siirto on tavallaan yksilöllinen, ja jos henkilö haluaa tietää tarkemmat siirron perusteet, hänen on otettava yhteyttä henkilöstötoimistoon tai aluepäällikköön. Esimiehellä ei näitä tietoja välttämättä ole käytettävissään. C:n mukaan aiemmin kukaan hänen alaisistaan ei ollut kieltäytynyt kirjoittamasta kantaansa siirtosuunnitelmaan.
Kun neuvottelupöytäkirja oli palautunut B:lle C:n merkinnöin, B oli lähettänyt sen eteenpäin laitoksen esikuntaan harkittavaksi. B:n tiedossa ei ollut, että A olisi pyytänyt saada tarkempia tietoja asiasta.
Yhteistoimintamenettely edellyttää, että yhteistoiminnan tarkoituksena oleva vuorovaikutus voi myös käytännössä toteutua. Menettelyn tarkoituksena on lisätä osapuolten tietoja sekä yhteneviä käsityksiä asiasta ja edistää yhteisymmärrykseen pääsyä. Rajavartiolaitoksessa neuvotteluvelvoitteen laajuuteen siirtotilanteissa vaikuttaa osaltaan se, että virkamies on suoraan lain perusteella velvollinen laissa säädettyjen perusteiden vallitessa siirtymään tehtävästä toiseen. Esitetty selvitys osoittaa, että siirtotapauksissa sopimuksen yhteisesti hyväksytyksi soveltamistavaksi on muodostunut, että neuvottelut aloitetaan ja useimmiten myös toteutetaan kirjallisesti. Siirtoa vastustavalla virkamiehellä on kuitenkin ollut käytännössä mahdollisuus saattaa siirto suullisesti neuvoteltavaksi ilmoittamalla vastustava kantansa siirron valmistelun yhteydessä laadittavaan pöytäkirjaan ja ilmaisemalla halukkuutensa neuvotella asiasta.
Kun kysymys on siirrosta, johon virkamies ei ole antanut suostumustaan tai jota hän vastustaa, yhteistoimintamenettelyssä voidaan yleensä edellyttää asian perinpohjaisempaa käsittelemistä kuin silloin, jos virkamies on antanut siirtoon suostumuksensa. Tässä tapauksessa työnantaja on pyrkinyt noudattamaan rajavartiolaitoksen yhteistoimintasopimuksen vakiintunutta soveltamistapaa. A:lle on esitetty neuvotteluja siirtoasiassa ja hän on saanut tarpeelliset tiedot asian käsittelemiseksi yhteistoimintamenettelyssä. A:n omasta asenteesta työnantajan esittämiä neuvotteluja kohtaan on osaltaan johtunut, että neuvottelut ovat jääneet lähinnä muodollisiksi ja vuorovaikutus näiltä osin vastaavasti toteutumatta. Samasta syystä myös pöytäkirja yhteistoimintamenettelystä on jäänyt puutteelliseksi. Tässä tilanteessa ei voida katsoa, että työnantaja olisi kanteessa väitetyllä tavalla rikkonut virkaehtosopimusta.
Siirtoratkaisusta tiedottaminen
Rajavartiolaitoksen yhteistoimintasopimuksen 21 §:n mukaan rajavartiolaitoksen on viivytyksettä tiedotettava yhteistoimintamenettelyn piiriin kuuluvassa asiassa tekemästään ratkaisusta asianomaisille virkamiehille ja työntekijöille sekä heidän edustajilleen. Kanteessa on katsottu työnantajan laiminlyöneen sopimuksen mukaisen velvollisuutensa tiedottaa viivytyksettä A:lle siirtoa koskeneesta ratkaisusta.
A:n siirtoa koskevan päätöksen ja neuvottelupöytäkirjan tiedoksiantamisesta on kuultu todistelutarkoituksessa A:ta itseään ja todistajina palkkayhteyshenkilö E:tä, D:tä ja B:tä.
A on kertonut soittaneensa 25.6.2001 Suomenlahden merivartioston palkkahallintoon E:lle kysyäkseen sairausajan vaikutuksesta palkkaukseensa. A:n mukaan E oli ihmetellyt, kun A ei ollut maininnut mitään siirtymisestään Pohjois-Karjalan rajavartiostoon, vaikka siirtopäätös oli ollut jo palkkahallinnon tiedossa. E on puolestaan kertonut, että kaikki siirtopäätökset tulevat hänelle tiedoksi palkanmaksua varten. E oli kertomansa mukaan puhelimessa todennut kyseisestä päätöksestä A:lle, että siirto Pohjois-Karjalan rajavartiostoon tapahtuu 1.10.2001 lukien. A oli puhelimessa todennut, ettei ollut vielä nähnyt päätöstä. E oli sattumoisin kuullut joskus heinäkuun puolella, että A:ta ei ollut tavoitettu. Tuolloin hän oli kertonut D:lle A:n kanssa käymästään keskustelusta.
B oli antanut kesäkuussa 2001 siirtopäätöksen tiedoksiannon D:n huolehdittavaksi. D oli lähettänyt päätöksen A:n osoitteeseen, mutta kirje oli palautunut takaisin lähettäjälle. Ennen tätä A:n yhteystiedot oli tarkastettu työnantajan omasta henkilörekisteristä ja hälytyslistoilta. D oli useaan otteeseen myös yrittänyt tavoittaa A:ta puhelimitse siinä kuitenkaan onnistumatta. A:n osoitetietoja selvitettiin väestörekisteristä, jolloin todettiin, että rajavartiolaitoksen rekistereissä olleet tiedot eivät pitäneet paikkaansa. Kun A:n saatiin tietää mahdollisesti oleskelevan Pohjois-Karjalassa, päätöksen tiedoksianto annettiin Pohjois-Karjalan rajavartioston tehtäväksi. Se antoi päätöksen A:lle tiedoksi 2.8.2001.
Esitetty selvitys osoittaa, että A oli saanut tietää rajavartiolaitoksen esikunnan tehneen 13.6.2001 päätöksen hänen siirtämisestään Pohjois-Karjalan rajavartiostoon 1.10.2001 lukien ensimmäisen kerran puhelimitse 25.6.2001. Päätös kokonaisuudessaan on kuitenkin annettu tiedoksi A:lle vasta 2.8.2001. Rajavartiolaitoksen yhteistoimintasopimuksessa ei ole tarkasti määrätty, missä ajassa tiedottamisen tulee tapahtua. Määräystä voidaan yleisen kielenkäytön valossa tulkita niin, että tiedottamiseen on ryhdyttävä heti kohta päätöksen tekemisen jälkeen. Tässä tapauksessa työnantaja, jonka omankin edun mukaista on ollut päätöksen nopea tiedoksiantaminen, on esitetyn selvityksen mukaan pyrkinyt tiedottamaan siirtopäätöksestä A:lle välittömästi. Vaikka tiedoksianto ei työtuomioistuimen mielestä ole lopulta onnistunut yhteistoimintasopimuksessa tarkoitetulla tavalla viivytyksettä, työnantajan ei vallinneissa olosuhteissa ole katsottava rikkoneen rajavartiolaitoksen yhteistoimintasopimusta.
Hyvityssakkovaatimukset
Edellä todetuilla perusteilla työtuomioistuin on katsonut jääneen näyttämättä, että rajavartiolaitoksen esikunta A:n työnantajana olisi A:n siirtoasiassa rikkonut rajavartiolaitoksen yhteistoimintasopimusta. Näin ollen myös sopimuksen tieten rikkomiseen perustettu hyvityssakkovaatimus on perusteeton.

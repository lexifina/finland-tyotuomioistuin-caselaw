# TT:1990-111

## Suomeksi

Työnantaja oli laiminlyödessään työntekijäin lomapalkkojen lomakorvausten tilittämisen määräajassa rikkonut tietensä työehtosopimusta.
TUOMIO
Kantaja, Rakennustyöläisten Liitto r.y.
Vastaaja, Liikkeenharjoittaja Rauno Olavi Peitso

TYÖEHTOSOPIMUKSEN MÄÄRÄYKSET
Suomen Maalarimestariliiton ja Rakennustyöläisten Liiton välillä 30.3.1988 tehdyssä maalarialan työehtosopimuksessa on muun muassa seuraavat määräykset:
= = = = = = = = = = = = = = = = = = = = = = = = =
26 §
= = = = = = = = = = = = = = = = = = = = = = = = =
2. Lomapalkka- ja lomakorvaus lasketaan siten kuin rakennusalan työntekijäin vuosilomia koskevassa työehtosopimuksessa sanotaan.
= = = = = = = = = = = = = = = = = = = = = = = = =
Työnantaja toimittaa työntekijälle tämän vuosilomapalkkaa koskevan tilitysjäljennöksen vuosineljänneksittäin.
= = = = = = = = = = = = = = = = = = = = = = = = =
Edellä tarkoitetussa rakennusalan työntekijäin vuosilomia koskevassa työehtosopimuksessa on muun muassa seuraavat määräykset:
= = = = = = = = = = = = = = = = = = = = = = = = =
5 §
Työnantaja maksaa kunkin kalenterivuosineljänneksen aikana lopputilin saaneen työntekijäin lomakorvauksen ja muun työntekijän lomapalkan kultakin kalenterivuosineljännekseltä viimeistään kalenterivuosineljänneksen päättymistä seuranneen kuukauden 25 päivänä Postipankin Suomen Rakennusteollisuusliiton siirtotilille n:o 160-1.
Lomapalkkakortin päättämisen yhteydessä työnantajan on maksettava lomakorvaukset ja lomapalkat mainitulle tilille huhtikuussa viimeistään 25 päivänä.
Maksaminen tapahtuu tämän sopimuksen mukaisesti, jos se suoritetaan johonkin rahalaitokseen tai postitoimipaikkaan edellä tässä pykälässä tarkoitettuna 25 päivänä tai rahalaitosten taikka postitoimipaikkojen ollessa kiinni kyseisenä 25 päivänä ensimmäisenä kiinniolon jälkeisenä rahalaitosten aukiolopäivänä.
= = = = = = = = = = = = = = = = = = = = = = = = =
Suomen Rakennusteollisuusliiton ja Rakennustyöläisten Liiton välillä 4.11.1988 allekirjoitetussa ja 1.4.1989 voimaan tulleessa työehtosopimuksessa on muun muassa seuraavat määräykset:
= = = = = = = = = = = = = = = = = = = = = = = = =
4 § Lomaraha
Tässä sopimuksessa lomarahalla tarkoitetaan lomapalkan, lomakorvauksen ja lomaltapaluurahan muodostamaa kokonaisuutta.
Lomarahan määrä on 18,5 % työssäolon ajalta maksetusta tai maksettavaksi erääntyneestä palkasta yli- ja hätätyöstä maksettu korotus mukaan lukien.
Työajan lyhennyksestä 29.3.1988 allekirjoitetussa sopimuksessa mainittu työajan lyhennysraha otetaan huomioon lomarahaa laskettaessa.
Työntekijällä, joka työsuhteensa kestäessä on ollut työssä vähemmän kuin neljätoista (14) päivänä, ei ole oikeutta lomarahaan, jos hän itse päättää työsuhteensa tai jos työnantaja purkaa hänen työsuhteensa työsopimuslain 43 §:n nojalla.
Lomanmääräytymisvuoden vaihtuessa lomarahan viimeisen erän laskentaperusteisiin otetaan lähimpänä joko ennen tai jälkeen lomanmääräytymisvuoden vaihtumista päättyvän palkanmaksukauden loppuun mennessä maksettu palkka ja uuden lomanmääräytymisvuoden ensimmäisen erän laskentaperusteisiin seuraavan palkanmaksukauden alusta maksettu palkka. Kesken olevassa urakassa toimitetaan väliarvio.
5 §
Lomarahojen tilitykset
Työnantajan on tilitettävä lomarahat Postipankkiin Suomen Rakennusteollisuusliiton tilille n:o 160-1 erikseen kultakin vuosineljännekseltä.
Tilitettävä määrä on kunkin vuosineljänneksen aikana tämän sopimuksen soveltamispiiriin kuuluville työntekijöille maksetuista palkoista edellä 4 §:n mukaisesti määräytyvä lomarahan kokonaismäärä.
Tilitys suoritetaan maksamalla lomarahan kokonaismäärä johonkin rahalaitokseen tai postitoimipaikkaan viimeistään vuosineljänneksen päättymistä seuraavan kalenterikuukauden 25 päivänä taikka, jos tilityskuukauden 25 päivä ei ole rahalaitosten tai postitoimipaikkojen aukiolopäivä, viimeistään lähinnä seuraavana aukiolopäivänä.

KANNE
Kanteen perustelut
Tilitysten viivästymisestä oli Rakennustyöläisten Keski-Suomen aluejärjestön toimitsija ilmoittanut Maalausliike R. Peitsolle ja Suomen Maalarimestariliitolle 30.5.1989 päivätyllä kirjeellä. Laiminlyöntien edelleen jatkuttua oli huomautus uusittu kirjeellä 29.11.1989.
Suomen Maalarimestariliitto oli aluejärjestön kirjeiden johdosta kehottanut Maalausliike R. Peitsoa korjaamaan tilanteen.
Asiassa oli liittojen välillä 13.9.1989 ja 9.2.1990 käyty neuvottelut, jotka eivät olleet johtaneet tulokseen.
Koska laiminlyönnit olivat olleet jatkuvia eikä tilannetta oltu kehotuksista huolimatta korjattu, oli maalausliike R. Peitso jatkuvasti tietensä rikkonut rakennusalan työntekijäin vuosilomia koskevaa työehtosopimusta.
Kanteessa esitetyt vaatimukset
Rakennustyöläisten Liitto on vaatinut työtuomioistuinta vahvistamaan, että Maalausliike R. Peitso on menetellyt rakennusalan työntekijäin vuosilomia koskevan työehtosopimuksen 5 §:n vastaisesti ja tuomitsemaan Maalausliike R. Peitson työehtosopimuksen tahallisesta rikkomisesta työehtosopimuslain 7 §:n nojalla hyvityssakkoon. Lisäksi Rakennustyöläisten Liitto on vaatinut oikeudenkäyntikulujensa korvaamista korkoineen.

VASTINE
Liikkeenharjoittaja Rauno Olavi Peitso on lausunut, että kantajan ilmoittamat lomapalkkojen Postipankkiin tilittämisen myöhästymiset pitivät paikkansa muuten paitsi, että lomanmääräytymisvuoden 1.4.1988 - 31.3.1989 ensimmäisen vuosineljänneksen tilitys ei ollut tapahtunut 28.8.1988 vaan 23.8.1988, ja että lomanmääräytymisvuoden 1.4.1988 - 31.3.1990 toisen vuosineljänneksen tilitys on tapahtunut 24.11.1989.
Peitso on lisäksi lausunut, että syynä viivästyksiin olivat olleet yrityksen maksuvalmiudessa olleet häiriöt. Yritys on erikoistunut julkisivutöiden suorittamiseen ja tämä on edellyttänyt huomattavia investointeja teline- ja nostokalustoon, minkä johdosta yrityksellä ei aina esimerkiksi tilaajien maksusuoritusten viivästyessä ole ollut riittäviä käyttövaroja omien suoritusten oikea-aikaiseen tekemiseen. Viivästykset ovat olleet lyhyitä, enimmillään alle kahden kuukauden pituisia. Nyttemmin yrityksen taloudellinen tila on vakiintunut niin, ettei se enää kuluneen vuoden aikana ole joutunut kanteessa tarkoitetun laatuisiin maksuviivästyksiin. Yhtiössä työskentelee 5 - 8 työntekijää.

TYÖTUOMIOISTUIMEN RATKAISU
Perustelut
Liikkeenharjoittaja Rauno Olavi Peitso on Maalausliike R. Peitson toiminimen haltijana suorittanut työntekijöidensä vuosilomapalkkoja myöhästyneinä siten, että lomanmääräytymiskauden 1.4.1988 - 1.3.1989 ensimmäisen vuosineljänneksen lomapalkat on tilitetty 23.8.1988, kun suorituksen eräpäivä olisi ollut 25.7.1988, toisen neljänneksen lomapalkat on tilitetty 22.12.1988, kun suorituksen eräpäivä olisi ollut 25.10.1988, kolmannen neljänneksen lomapalkat oli tilitetty 16.3.1989, kun suorituksen eräpäivä olisi ollut 25.1.1989, neljännen neljänneksen lomapalkat on tilitetty 16.5.1989, kun suorituksen eräpäivä olisi ollut 25.4.1989 sekä lomanmääräytymiskauden 1.4.1989 - 31.3.1990 toisen vuosineljänneksen lomapalkat on tilitetty vasta 24.11.1989, kun suorituksen eräpäivä olisi ollut 25.10.1989.
Rauno Olavi Peitso on menettelyllään rikkonut tietensä rakennusalan työntekijäin vuosilomia koskevan työehtosopimuksen 5 §:n määräyksiä.

Tuomiolauselma
Työtuomioistuin vahvistaa, että Rauno Olavi Peitso on edellä selostetuin tavoin toimiessaan menetellyt rakennusalan työntekijäin vuosilomia koskevan työehtosopimuksen 5 §:n 1 momentin vastaisesti.
Työtuomioistuin tuomitsee työehtosopimuslain 7 ja 10 §:n nojalla Rauno Olavi Peitson maksamaan Rakennustyöläisten Liitolle hyvityssakkoa työehtosopimuksen tieten rikkomisesta 9 000 markkaa.
Rauno Olavi Peitso velvoitetaan korvaamaan Rakennustyöläisten Liiton oikeudenkäyntikulut 1 500 markalla 16 prosentin korkoineen tuomion antopäivästä lukien.
Jäsenet: Orasmaa, puheenjohtaja, Iirola, Äimälä, Rautiainen, Hölttä ja Kolula.
Tuomio oli yksimielinen.

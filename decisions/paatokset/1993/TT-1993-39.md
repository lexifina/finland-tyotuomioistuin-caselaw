# TT:1993-39

## Suomeksi

Määräajaksi tai määrättyä työtä varten tehty työsopimus voitiin työehtosopimuksen mukaan solmia vain kerran, ellei työnantajan ja ammattiosaston välillä ollut toisin sovittu. Tarkoituksena oli työehtosopimuksen mukaan estää tilapäisluontoisten työsuhteiden jatkettu käyttö. Paperitehdas oli sopinut määräaikaisia työsopimuksia niin, ettei ensimmäisen määräaikaisen työsopimuksen tekemisen jälkeen seuranneista työsopimuksista ollut sovittu ammattiosaston kanssa.
 Määräyksen soveltamisen ulkopuolelle jäivät ainakin ne tilanteet, joissa määräaikaisen työsopimuksen päättymisen ja sitä seuranneen sopimuksen alkamisen välillä oli kulunut pitkähkö aika.
 Sopimusmääräystä ei ollut tulkittava niin, että se koskee vain toisiaan välittömästi seuraavia työsopimuksia.
 Niissä tapauksissa, joissa oli kysymys tilapäisluontoisten työsuhteiden jatketusta käytöstä, uuden määräaikaisen työsopimuksen solmimisesta olisi siten tullut sopia ammattiosaston kanssa siitä riippumatta olivatko työsopimukset välittömästi seuranneet toisiaan.
 Työnantaja ei ollut rikkonut tieten työehtosopimusta.
 Kantaja Paperiliitto r.y. Vastaajat Metsäteollisuus ry Myllykoski Oy

 VASTINE
 Vastineen perustelut
 Metsäteollisuus ry ja Myllykoski Oy ovat lausuneet, että tulkittava määräys oli otettu ensimmäistä kertaa vuoden 1970 työehtosopimukseen seuraavan sisältöisenä:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Jos on nimenomaisesti sovittu määräajasta, jonka työsopimus kestää tai määrätyn työn suorittamisesta, ei työsopimusta saa irtisanoa päättyväksi kesken sopimuskauden. Jos työ jatkuu sovitun kauden jälkeenkin, katsotaan työsopimuksen jatkuvan toistaiseksi tehtynä ja työsuhteen kestoaika luetaan työn alkamisesta.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Sanotun määräyksen soveltamisohje kuului seuraavasti:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Nykyinen käytäntö muuttuu siis siten, että määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran. Jos työ jatkuu edelleen, on irtisanomisaikaa noudatettava tavanomaisin edellytyksin. Tarkoituksena on ollut estää tilapäisluontoisten työsuhteiden jatkettu käyttö.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Määräyksellä pyrittiin estämään määräaikaisten työsopimusten työehtosopimuksen vastainen käyttö. Selvästä sanamuodosta "jos työ jatkuu edelleen" ilmeni määräyksen tarkoitus. Määräys ei ollut soveltunut käytäntöön sopimuksessa tarkoitetulla tavalla, koska usein oli tarkoituksenmukaisempaa jatkaa määräaikaista työsuhdetta kuin palkata uusi työntekijä samaan työhön. Tästä syystä oli vuonna 1980 solmittuun sopimukseen lisätty soveltamisohjeen muutos, jonka mukaan paikallisesti voitiin sopia työsopimuksen jatkamisesta. Muutettu kappale kuului seuraavasti:
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran, ellei työnantajan ja ammattiosaston välillä toisin ole sovittu. Jos työ jatkuu sovitun määräajan jälkeen edelleen, on irtisanomisaikoja noudatettava tavanomaisin edellytyksin.
 = = = = = = = = = = = = = = = = = = = = = = = = =
 Kanteessa oli lueteltu nimeltä 34 työntekijää, joiden kanssa Myllykoski Oy oli eri aikoina sopinut kaksi tai useampia eripituisia määräaikaisia työsopimuksia 2.6.1986 - 28.2.1991 välisenä aikana. Kaikkien kanteessa lueteltujen työntekijöiden työsopimusten välillä oli eri pituisia aikoja, jotka olivat vaihdelleet muutamista päivistä lähes 32,5 kuukauteen.
 Vuosilomista, äitiyslomista ja vuorovapaista johtuen Myllykoski Oy solmi vuosittain sijaisina toimivien työntekijöiden kanssa uusia työsopimuksia sopimatta siitä erikseen ammattiosaston kanssa. Käytäntö oli yhtenäinen koko paperiteollisuudessa. Vastaajien tiedossa ei ollut tapauksia, joissa Myllykoski Oy tai joku muu työnantaja olisi sopinut asiasta luottamusmiehen kanssa. Tiedossa ei ollut myöskään kanteen tarkoittamien tapausten ohella muita tapauksia, joissa olisi vaadittu vastaavassa tilanteessa neuvotteluja ammattiosaston puolelta.
 Vastaajat olivat samaa mieltä Paperiliiton kanssa sopimisvelvoitteesta ammattiosaston kanssa silloin, kun kyseessä oli määräaikaisen työsopimuksen välitön jatkaminen uudella määräaikaisella työsopimuksella. Myllykoski Oy:ssä oli esimerkkejä tällaisissa tilanteissa sopimisesta. Kanteessa luetelluissa tapauksissa ei ollut yhtään tällaista tapausta.
 Eräiden kanteessa mainittujen työntekijöiden kanssa oli syksyllä 1989 tehty uudet määräaikaiset työsopimukset loppukesällä päättyneiden sopimusten jatkoksi. Tämä oli johtunut siitä, ettei keväällä 1989, kun kesää koskevat työsopimukset tehtiin, ollut vielä voitu tietää, että myös syksyllä tarvittaisiin eri syistä määräaikaisia työntekijöitä. Syksyllä 1989 asia oli otettu paikallisesti käsiteltäväksi pääluottamusmiehen toivomuksesta. Työnantaja oli selvittänyt perusteensa määräaikaisiin sopimuksiin. Asia oli selvitetty yhteisesti ja sovittu kuuden työntekijän työsuhteiden vakinaistamisesta sekä siitä, ettei asia antanut aihetta muihin toimenpiteisiin. Tästä huolimatta pääluottamusmies oli halunnut tammikuussa 1991 tehdä asiasta erimielisyysmuistion, joka oli kanteen pohjana.
 Vastineessa esitetyt vaatimukset
 Vastaajat ovat vaatineet kanteen hylkäämistä.

 PAPERILIITON VASTASELITYS
 Paperiliitto on lausunut, että työehtosopimuksen 5 §:n 4. kohdan toisen kappaleen ensimmäisessä lauseessa oli määräys, joka sinänsä oli työoikeudessa itsestään selvä. Määräaikaista työntekijää ei saanut irtisanoa. Toisen kappaleen toinen lause koski työsuhteen niin sanottua hiljaista pidennystä.
 5 §:n 4. kohdan kolmannen kappaleen mukaan määräajaksi tai määrättyä työtä varten tehty työsopimus voitiin solmia vain kerran, ellei työnantajan ja ammattiosaston välillä ollut toisin sovittu. Tarkoituksena oli estää tilapäisluonteisten työsuhteiden jatkettu käyttö. Työehtosopimusosapuolten tarkoituksena ei ollut ollut sitoa 5 §:n 4. kohdan kolmatta kappaletta saman kohdan toiseen kappaleeseen tulkinnallisesti eikä muutenkaan. Sopimuksen 5 §:n 4. kohdan kolmatta kappaletta oli sovellettu ja sovellettava itsenäisenä määräyksenä, joka sisälsi määräaikaisia työsopimuksia koskevan erillisen oikeusohjeen.
 Vastaselityksessä on viitattu työtyötuomioistuimen tuomioihin n:ot 173/1987, 53/1990, 101/1990, 46/1991 sekä 67/1991.
 Pääluottamusmies oli tehnyt asiasta erimielisyysmuistion, koska määräaikaisten työsopimusten käyttö oli laajasti ja tietoisesti ollut työehtosopimuksen 5 §:n 4. kohdan kolmannen kappaleen vastaista. Pääluottamusmies ei missään vaiheessa ollut sitoutunut olemaan erimielisyysmuistiota tekemättä.

 TYÖTUOMIOISTUIMEN RATKAISU
 Perustelut
 Paperiteollisuuden kanteessa tarkoitettujen työehtosopimusten työsuhteen syntymistä ja lakkaamista koskevan 5 §:n 4. kohdan kolmannen kappaleen mukaan määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran, ellei työnantajan ja ammattiosaston välillä ole toisin sovittu. Sopimuskohdan mukaan tarkoituksena on estää tilapäisluontoisten työsuhteiden jatkettu käyttö.
 Paperiliitto on vaatinut työtuomioistuinta vahvistamaan, että Myllykoski Oy on rikkonut sanottua työehtosopimusmääräystä, kun se ei ole sopinut paikallisen ammattiosaston kanssa kanteessa lueteltujen 34 työntekijän ensimmäistä määräaikaista työsopimusta seuranneiden toisen, kolmannen tai neljännen määräaikaisen työsopimuksen solmimisesta. Lisäksi Paperiliitto on vaatinut Myllykoski Oy:n tuomitsemista tämän laiminlyönnin vuoksi hyvityssakkoon työehtosopimuslain 7 §:n nojalla.
 Metsäteollisuus ry ja Myllykoski Oy ovat pitäneet kannetta kaikkien siinä tarkoitettujen 34 työntekijän osalta perusteettomana. Työnantajapuolen mukaan työehtosopimuksen 5 §:n 4. kohdan kolmannen kappaleen määräys koskee vain saman pykälän 4. kohdan toisessa kappaleessa tarkoitetun määräaikaisen työsopimuksen jatkamista niin, että sitä seuraa välittömästi uusi määräaikainen työsopimus. Sitä vastoin määräystä ei työnantajapuolen mukaan voi tulkita siten, että se koskisi tapauksia, joissa määräaikaiset työsopimukset eivät välittömästi seuraa toisiaan, kuten kaikkien kanteessa mainittujen työntekijöiden kohdalla on kysymys.
 Työsopimuslain alkuperäisessä 2 §:ssä ei ollut rajoituksia määräaikaisen työsopimuksen tekemiselle. Pykälän 2 momentin mukaan, sellaisena kuin lainkohta on 3.2.1984 annetussa, 1.9.1984 voimaan tulleessa laissa, määräaikainen työsopimus voidaan tehdä, jos työn luonne, sijaisuus, harjoittelu tai muu näihin rinnastettava määräaikaista sopimusta edellyttävä seikka on siihen syynä tahi jos työnantajalla on muu yrityksen toimintaan tai suoritettavaan työhön liittyvä, perusteltu syy määräaikaisen työsopimuksen solmimiseen. Jos määräaikainen työsopimus on tehty muussa kuin edellä mainituissa tapauksissa tai jos määräaikaisia työsopimuksia on ilman pätevää syytä toistuvasti solmittu peräkkäin, pidetään sopimusta lainkohdan mukaan toistaiseksi voimassa olevana työsopimuksena.
 Määräaikaiselle työsopimukselle toistaiseksi voimassa olevaan työsopimukseen verrattuna on ominaista erityisesti kaksi seikkaa. Sopimus päättyy sovitun työkauden kuluttua ja yleensä ilman irtisanomista. Toiseksi määräaikaiseen työsopimukseen ei liity ainakaan pääsääntöisesti irtisanomissuojaa, joka kohdistuu vain toistaiseksi voimassa olevaan työsopimukseen. Työsopimuslain 1.9.1984 voimaan tulleen muutoksen valmisteluasiakirjoissa on todettu nimenomaan, ettei lailla ole tarkoitus rajoittaa osapuolten oikeutta käyttää määräaikaista työsopimusta laissa tarkoitetuissa tapauksissa aina, kun käytännön työelämän tarpeet sitä edellyttävät. Määräaikaisen työsopimuksen käyttö tulee yleisimmin kysymykseen tapauksissa, joissa jo ennalta tiedetään, että työ loppuu määrätyn ajan kuluttua tai määrätyn tehtävän tultua suoritetuksi.
 Tulkintaohjeena on kirjallisuudessakin korostettu, ettei määräaikaisen työsopimuksen solmimiseen saa työnantajan puolelta liittyä pyrkimystä irtisanomissuojan kiertämiseen. Rajatapauksissa on kiinnitettävä huomiota ensisijaisesti siihen, voidaanko katsoa, että toistuvilla määräaikaisilla sopimuksilla onkin itse asiassa pyritty toistaiseksi jatkuvaan työsuhteeseen. Muodostuakseen työsopimuslain 2 §:n 2 momentin nojalla toistaiseksi voimassa olevaksi työsopimukseksi toistuvien määräaikaisten työsopimusten ei kirjallisuudessa esitettyjen kannanottojen mukaan tarvitse jatkua täysin yhtenäisenä ketjuna.
 Työsopimuslain 2 §:n 2 momentissa toisaalta luetellaan ne edellytykset, joilla määräaikainen työsopimus voidaan tehdä, ja toisaalta kielletään solmimasta määräaikaisia työsopimuksia ilman pätevää syytä toistuvasti peräkkäin. Lainkohdan mukaan sopimusta pidetään toistaiseksi voimassa olevana työsopimuksena sekä silloin, kun määräaikainen työsopimus on tehty muussa kuin siinä mainituissa tapauksissa, että silloin, kun määräaikaisia työsopimuksia on ilman pätevää syytä toistuvasti solmittu peräkkäin.
 Työsopimuslain 2 §:n 2 momentin säännös on niin sanottua pakottavaa oikeutta. Säännöksestä ei voi sopia työntekijän vahingoksi edes työehtosopimuksin. Tästä syystä työehtosopimuksen tulkittavana oleva määräys ei ainakaan oikeuta solmimaan sellaisia määräaikaisia työsopimuksia, jotka eivät täytä lainkohdassa asetettuja edellytyksiä. Tällaisia työsopimuksia ei nimittäin saa tehdä ammattiosaston suostumuksellakaan. Lisäksi työtuomioistuin on tuomionsa 67/1991 perusteluissa lausunut, ettei työnantaja ollut voinut puheena olevaa työehtosopimusmääräystä syrjäyttää, vaikka se olisi ollut oikeutettu työsopimuslaissa säädettyjen perusteiden mukaan tekemään työntekijän kanssa määräaikaisen työsopimuksen. Tuomiossaan 101/1990 työtuomioistuin on katsonut, ettei se seikka, että työnantaja ei olisi saanut lainkaan solmia määräaikaista työsopimusta, ollut voinut vapauttaa työnantajaa, joka tosiasiassa oli tehnyt tuollaisen sopimuksen, määräyksessä tarkoitetusta velvollisuudesta sopia asiasta ammattiosaston kanssa.
 Paperiteollisuuden työehtosopimukseen vuonna 1970 otettu määräys määräaikaisesta työsopimuksesta on kirjoitettu muotoon: "Jos on nimenomaisesti sovittu määräajasta, jonka työsopimus kestää tai määrätyn työn suorittamisesta, ei työsopimusta saa irtisanoa päättyväksi kesken sopimuskauden. Jos työ jatkuu sovitun kauden jälkeenkin, katsotaan työsopimuksen jatkuvan toistaiseksi tehtynä ja työsuhteen kestoaika luetaan työn alkamisesta." Työehtosopimuksen soveltamisohjeissa on todettu: "Nykyinen käytäntö muuttuu siis siten, että määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran. Jos työ jatkuu edelleen, on irtisanomisaikaa noudatettava tavanomaisin edellytyksin. Tarkoituksena on ollut estää tilapäisluontoisten työsuhteiden jatkettu käyttö." Määräys on ollut työehtosopimuksissa sanotun sisältöisenä 1970-luvun ajan eikä siitä ole esiintynyt tulkintaerimielisyyksiä. Määräaikaisia työsopimuksia on käytetty yleensä sijaisia lomitustehtäviin palkattaessa.
 Paperiliiton mukaan määräys on otettu työehtosopimukseen tilanteessa, jossa hallitus oli antanut eduskunnalle esityksen uudeksi työsopimuslaiksi. Määräys oli liiton mukaan heijastuma lakiehdotuksen sopimussuhteen hiljaista pitennystä koskevasta 39 §:n säännöksestä.
 Työnantajapuoli on jättänyt tammikuun 1980 työehtosopimusneuvotteluissa Paperiliitolle esityksen, jossa tähdättiin siihen, että työnantajan ja ammattiosaston välisin sopimuksin voitaisiin saada joustoa aikaisempaan määräykseen, joka oli estänyt määräaikaisen sopimuksen uusimisen. Esityksen mukaan soveltamisohjeiden edellä tarkoitettu kohta olisi saanut sanamuodon: " Määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran. Jos työ jatkuu edelleen, on irtisanomisaikaa noudatettava tavanomaisin edellytyksin, ellei työnantajan ja ammattiosaston välillä toisin ole sovittu. Tarkoituksena on ollut estää tilapäisluontoisten työsuhteiden jatkettu käyttö."
 Kun Paperiliiton neuvotteluedustajat eivät ole hyväksyneet ehdotettua sanamuotoa sen vuoksi, että heidän mielestään se olisi mahdollistanut irtisanomisaikojen paikallisen sopimisen laista poikkeavasti, soveltamisohjeiden kohta on otettu vuosina 1980-1981 voimassa olleeseen työehtosopimukseen työnantajapuolen ehdotuksesta seuraavan sisältöisenä: "Määräajaksi tai määrättyä työtä varten tehty työsopimus voidaan solmia vain kerran, ellei työnantajan ja ammattiosaston välillä toisin ole sovittu. Jos työ jatkuu sovitun määräajan jälkeen edelleen, on irtisanomisaikaa noudatettava tavanomaisin edellytyksin. Tarkoituksena on estää tilapäisluontoisten työsopimusten jatkettu käyttö."
 Tämän jälkeen määräys sai vuoden 1983 työehtosopimuksessa sen muodon, jossa se puheena olevilta osin sisältyy tulkittaviin vuosien 1986, 1988 ja 1990 työehtosopimuksiin eli soveltamisohjeen määräys on sisällytetty työehtosopimusmääräykseen. Määräys on siis saanut nykyisen muotonsa jo ennen työsopimuslain 2 §:n edellä selostettua muutosta. Oikeuskäytännössä oli kuitenkin jo sitä ennen rajoitettu mahdollisuutta solmia määräaikaisia työsopimuksia (KKO 1978 II 45).
 Tulkittavan sopimusmääräyksen syntyhistoriasta esitetty selvitys osoittaa näin ollen, että sillä on tarkoitettu tehdä mahdolliseksi poiketa ammattiosaston ja työnantajan välisin sopimuksin aikaisemmin voimassa olleesta ehdottomasta kiellosta uusia määräaikainen työsopimus.
 Paperiliitto on kanteensa tueksi vedonnut työtuomioistuimen edellä mainittuihin tuomioihin 101/1990 ja 67/1991 sekä tuomioihin 173/1987, 53/1990 ja 46/1991, joissa kaikissa on katsottu työnantajan rikkoneen puheena olevaa sopimusmääräystä. Näissä tuomioissaan työtuomioistuin ei kuitenkaan ole suoranaisesti ottanut kantaa siihen, koskeeko sopimusmääräys tilanteita, joissa määräaikaiset työsopimukset eivät välittömästi seuraa toisiaan.
 Työehtosopimuksen 5 §:n 4. kohdan kolmannen kappaleen ensimmäisen virkkeen sanamuoto näyttäisi tukevan sitä Paperiliiton kantaa, että työnantaja voi solmia saman työntekijän kanssa määräaikaisen työsopimuksen vain kerran sopimatta asiasta ammattiosaston kanssa. Määräyksen syntyhistoriasta esitetty, edellä selostettu selvitys samoin kuin kolmannen kappaleen toisessa virkkeessä mainittu sopimusmääräyksen tarkoitus eivät kuitenkaan tue sitä, että tällainen tulkinta olisi sopimusosapuolten tarkoitusta vastaava.
 Koska sopimusmääräys ei sovellu tapauksiin, joissa ei voi katsoa olevan kysymys tilapäisluontoisten työsuhteiden jatketusta käytöstä, määräyksen soveltamisen ulkopuolelle jäävät ainakin ne kanteessa tarkoitetut tilanteet, joissa aikaisemman määräaikaisen työsopimuksen päättymisen ja sitä seuraavan sopimuksen alkamisen välillä on kulunut pitkähkö aika. Kanne on siten perusteeton työntekijä Koposen (n:o 16) osalta, jonka kahden määräaikaisen työsopimuksen välillä on kulunut aikaa noin puolitoista vuotta, työntekijä Salosen (n:o 18) kolmannen työsopimuksen osalta, jonka alkamiseen on edellisen työsopimuksen päättymisestä kulunut aikaa noin puolitoista vuotta, ja työntekijä Kujalan (n:o 19) toisen työsopimuksen osalta, jonka alkamiseen on ensimmäisen sopimuksen päättymisestä kulunut aikaa lähes kolme vuotta.
 Koska niissä kanteessa tarkoitetuissa tapauksissa, joissa työnantaja on tehnyt saman henkilön kanssa määräaikaisen työsopimuksen eri kalenterivuosien vuosilomien ajaksi, ei työtuomioistuimen mielestä voi katsoa olevan kysymys tilapäisluontoisten työsuhteiden jatketusta käytöstä, kanne on perusteeton myös työntekijöiden Ala-Turkian (n:o 1) toisen, Langin (n:o 11) toisen ja kolmannen, Ylätalon (n:o 14) toisen ja kolmannen, Kinnusen (n:o 15), Setälän (n:o 17) toisen, Salosen (n:o 18) toisen, Brandelinin (n:o 22) toisen ja Sipiläisen (n:o 31) toisen työsopimuksen osalta.
 Kanteessa tarkoitettujen muiden kuin edellä mainittujen työsopimusten kohdalla edellisen sopimuksen päättymisestä seuraavan sopimuksen alkamiseen on kulunut aikaa yhdestä päivästä runsaisiin kolmeen kuukauteen. Syyksi useiden niistä solmimiselle on työtuomioistuimelle esitetty, että Myllykoski Oy on joutunut vuosilomien jälkeen syksyllä 1989 käyttämään lomittajia sen mukaan kuin vakinaisille työntekijöille on kertynyt lisävuorovapaita asianosaisliittojen sovittua ensikertaa tehtaiden käymisestä sanotun vuoden helluntaina. Tämän selvityksen mukaan on osa kanteessa tarkoitetuista työntekijöistä, jotka ovat olleet kesäajan 1989 lomittajina, palkattu uudelleen lomittajiksi seuranneeksi syksyksi. Tällaista tilannetta ei työnantajaliiton mukaan ollut voitu ennakoida kesäajan lomittajista kevättalvella 1989 sovittaessa.
 Työnantajaliitto on perustellut kantaansa, että työehtosopimuksen 5 §:n 4. kohta koskee vain tilanteita, joissa määräaikaiset työsopimukset välittömästi seuraavat toisiaan, erityisesti sillä, että pykälän 4. kohdan toinen ja kolmas kappale muodostavat toisiaan täydentävän kokonaisuuden, joten kolmannen kappaleen sopimusvelvoite koskee vain toisessa kappaleessa tarkoitetun määräaikaisen työsopimuksen jatkamista. Paperiliitto on pitänyt tätä tulkintaa sopijapuolten tarkoitusta vastaamattomana.
 Harkitessaan, koskeeko työehtosopimuksen 5 §:n 4. kohdan kolmannen kappaleen määräys vain tilanteita, joissa määräaikaiset työsopimukset välittömästi seuraavat toisiaan, työtuomioistuin toteaa, että 4. kohdan toisen kappaleen ensimmäisestä virkkeestä ilmenee se määräaikaista työsopimusta yleensä muutoinkin koskeva periaate, ettei sitä voi irtisanoa päättyväksi kesken sopimuskauden. Toisessa virkkeessä taas on sovittu sopimussuhteen hiljaisesta pitennyksestä eli samasta asiasta, josta on säädetty työsopimuslain 39 §:ssä. Näillä määräyksillä ei työtuomioistuimen mielestä ole muodollista eikä asiallista yhteyttä 4. kohdan kolmannen kappaleen määräykseen. Määräysten sanamuoto enempää kuin myöskään niiden syntyhistoriasta esitetty selvitys eivät tue työnantajapuolen kantaa.
 Tehdessään vuoden 1980 työehtosopimusneuvotteluissa ehdotuksen aikaisemman määräaikaisten työsopimusten toistuvan solmimisen ehdottomasti kieltävän sopimusmääräyksen muuttamisesta työnantajapuolen, jos sen tarkoituksena on ollut määräyksen tulkitseminen nyt esittämällään tavalla, olisi tullut ottaa se neuvotteluissa esille. Kun näin ei ole tapahtunut eikä työntekijäpuolikaan ole esitetyn selvityksen mukaan ymmärtänyt tällaista tarkoitetun, sopimusmääräystä ei ole työtuomioistuimen mielestä tulkittava niin, että se koskee vain toisiaan välittömästi seuraavia määräaikaisia työsopimuksia.
 Näillä perusteilla työtuomioistuin katsoo, että niissä kanteessa tarkoitetuissa tapauksissa, joissa on kysymys tilapäisluontoisten työsuhteiden jatketusta käytöstä, uuden määräaikaisen työsopimuksen solmimisesta olisi tullut sopia ammattiosaston kanssa siitä riippumatta, ovatko työsopimukset välittömästi seuranneet toisiaan.
 Koska työntekijä Kinnusen (n:o 15) aikaisemman työsopimuksen ajankohtaa ei ole ilmoitettu, on jäänyt näyttämättä, että hänen kanteessa mainitusta määräaikaisesta työsopimuksestaan olisi pitänyt sopia ammattiosaston kanssa.

 Tuomiolauselma
 Kanteen enemmälti hyläten työtuomioistuin vahvistaa, että Myllykoski Oy on vastoin työehtosopimuksen 5 §:n 4. kohdan kolmannen kappaleen määräystä sopimatta siitä ammattiosaston kanssa tehnyt Tero Ala-Turkian, Timo Espoon, Pekka Haapasen, Jari Hyrkäksen, Manne Kautan, Ulla Leskisen, Kari Niemisen, Juha Nybergin, Jukka Piepposen, Jani Sihvolan, Tommi Langin, Petri Parkkisen, Juha Turusen, Tuomas Ylätalon, Markus Setälän, Kimmo Kujalan, Kimmo Kääriän, Markku Seppisen, Nina Brandelinin, Marja Hasselin, Marja Pieksemän, Merja Ruokosuon, Sari Timosen, Kirsi Wahlmanin, Päivi Lammin, Heli Laurbärin, Riitta Matulan, Tanja Sipiläisen, Päivi Tissarin, Kimmo Koskelaisen ja Sanna Mäistin kanssa edellä perustelujen viimeisessä kappaleessa tarkoitetut työsopimukset.
 Jutun näin päättyessä ja sen laatuun katsoen saavat asianosaiset puolin ja toisin pitää oikeudenkäyntikulunsa vahinkonaan.
 Asian ratkaisemiseen ovat osallistuneet Huopaniemi puheenjohtajana sekä Iirola, Äimälä, Uski, Pohja ja Korpela jäseninä.
 Tuomio on yksimielinen.
